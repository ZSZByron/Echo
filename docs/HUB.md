> **读文档从这里进，其他导航页可以不看。**
> 五大类：进度 / 决策 / 架构系统 / 治理体系 / 问题证据——每类只列**当前有效**文件（一行说明 + 何时读），历史版本一律在 `archive/`。
>
> **Obsidian 用法（一个文件夹看所有内容）**：推荐把**仓库根**（H:\UGC）作为 Vault 打开——PROJECT_STATE、证据库、代码全部进关系图谱；嫌 node_modules 噪音就把 vault 设为 `docs/`（vault 外文件以路径链接兜底，点击前两级跳转）。本页链接规范：vault 内 = `[[文件名]]` 双链（按文件名全库解析、移动不断链、图谱/反链可见）；vault 外 = 普通路径链接。
>
> **维护纪律**：新文件落盘 → 本页登记；版本升位 → 本页改行；旧版归档 → 本页移除。本页不承载内容，只做索引。
