- A1模块数据架构与映射
  - 前端
    - A1Workspace.tsx (单页三态流主容器)
      - 态①: SeedSelector (8种子卡片/自定义输入)
      - 态②: GuidedChat + StructuredFilePanel + DimensionProgress (对话与实时Diff渲染)
        - 支持会话恢复按status路由
      - 态③: 内嵌IP展板
    - IPPoster.tsx (/a1/poster)
      - 纯展板页面
      - 提供【继续修改】入口，回退工作台定位板块重新定稿
  - 后端API (a1_routes.py)
    - GET /api/a1/seeds
      - 响应：种子列表 {seeds:[{id,name,genre,description,dimension_defaults}]}
    - POST /api/a1/session/start
      - 请求：{user_id, seed_id?|custom_idea?}
      - 响应：{session_id, file_id, ip_code, first_question, file} (IP序号此时分配)
      - 错误：400 二选一缺失
    - POST /api/a1/chat
      - 请求：{session_id, message}
      - 响应：{reply, next_question, file_diff, progress, phase, classification_proposal?}
    - POST /api/a1/file/{id}/finalize
      - 响应：{graph_id, graph_code, warnings} (文件→图谱转换，触发下游stale标记)
      - 错误：409 + {missing_sections:[...]} 10板块未齐
    - GET /api/a1/file/{id}/poster
      - 响应：{panels, ai_image_prompt, ai_image_status}
      - 错误：409 未定稿
    - GET /api/a1/file/{id}/graph
      - 响应：KnowledgeGraph (须已定稿)
      - 错误：409 pending_finalize
  - 后端核心模块
    - preset_loader.py / seed_generator.py
      - 职责：加载8预设为运行时种子JSON，含10板块默认值预填
    - a1_question_tree.py
      - 职责：定义10板块问题树与状态机，AI不发明问题
    - guide_engine.py
      - 职责：引导状态机引擎，限制用户不自由跳板块，LLM仅措辞/追问
    - innovation_capture.py
      - 职责：创新语句捕获，先匹配现有类别→AI提案→用户确认→落盘
    - semantic_compiler.py (断点A修复)
      - 职责：语义编译器，执行三级匹配(种子库级→词典规则级→LLM级)
      - 产出：标签=枚举值 写入结构化文件
    - ip_poster.py
      - 职责：生成氛围史诗图prompt及展板浮层数据
    - finalize 挂点 (断点F修复接入)
      - 职责：定稿时将结构化文件转换为图谱节点+基础边+约束建边
  - 公用底座
    - StructuredFileStore
      - 职责：文件快照Store，图谱=事实源，文件单向导出
    - GraphStore
      - 职责：图谱事实源，追加status/parent_graph_code/change_set字段
    - GraphCodeIssuer
      - 职责：四层编码原子发号器 (IP{序号}-{阶段路径}-v{版本})
    - stale_marker
      - 职责：stale横切机制，上游变旧自动标记下游，只标记不删除不阻断
  - 核心规则约束
    - 引导规则
      - 不自由跳跃，AI不发明问题，仅做措辞与追问
    - 创新落盘规则
      - 必须二选一确认，防止AI幻觉污染结构化数据，“其他”仅存不一致内容
    - 语义编译三级匹配规则
      - 种子库级 → 词典规则级 → LLM级 (前两级零LLM成本)
    - 定稿与409规则
      - 10板块未齐阻断定稿，返回409及缺失清单
    - 编码与版本规则
      - 永不覆盖只追加，重新定稿产出W1-v2，旧版保留
    - stale横切规则
      - 上游重新定稿产出v2，自动标记下游v1为stale，留痕使用(used_stale=true)
  - 前后端映射一致
    - 态① SeedSelector映射
      - 前端卡片渲染 <- 后端GET /seeds
      - 前端启动会话 <- 后端POST /session/start
    - 态② GuidedChat映射
      - 前端对话及Diff更新 <- 后端POST /chat (含file_diff, progress, proposal)
    - 态② 定稿按钮映射
      - 前端按钮点亮逻辑 <- 后端progress完成度
      - 前端定稿请求 <- 后端POST /finalize (处理409缺失清单)
    - 态③ 展板/Poster映射
      - 前端展板渲染 <- 后端GET /poster (处理409未定稿)
      - 前端图谱获取 <- 后端GET /graph
    - 重新定稿修改分支映射
      - 前端回退修改 <- 后端POST /chat
      - 前端重新定稿 <- 后端POST /finalize (产出W1-v2)
      - 前端版本列表 <- 后端GET /graphs (status及倒序保持一致)
