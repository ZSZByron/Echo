## §1 构想全文留痕（产品方 2026-09-28 原话要点）

### 1.1 核心转向

> "不以增值为逻辑，而以人的解放为逻辑。"

原链条：灵感 → AI 辅助 → 内容生产 → 社区复用 → 集体创作 → 文化产品。
新链条：**冲动 → 自我发现 → 表达 → AI 赋能 → 创造 → 连接 → 共创 → 自主实现**（八环）。

最重要的一条：**"AI 不是替用户创造，而是把用户原本没有能力实现的东西释放出来。"**

### 1.2 产品重定义

- 不是"AI 世界观/故事生成平台"，而是：**"一个帮助普通人把内在想象转化为可表达、可创造、可连接、可继续发展的文化作品的空间。"**
- 核心不是 AI Story Generator，而是：人的想象力 → 作品 → 社区文化；"让一个人的想象，拥有被看见、被实现、被连接和继续生长的可能。"

### 1.3 第一阶段 = 自我发现

- 传统工具问"你想生成什么？"→ AI 接管创造；本产品反问**"你为什么突然想讲这个故事？"**
- 系统不马上生成，先轻追问（最先想到的是什么 / 为什么这件事重要 / 希望读者感受到什么），再形成：**情感核心 → 冲动 → 主题 → 人物 → 冲突 → 世界 → 故事**。
- AI 的角色："帮助你听见自己在想什么"，不是"替你想"。

### 1.4 AI 原则

> **"用户决定灵魂，AI 负责扩展可能性。"**（AI 补足能力，不替代灵魂）

AI 可以做：找漏洞 / 世界观可能性 / 人物关系建议 / 知识图谱 / 背景 / 结构 / 一致性检查 / 剧本 / 模组 / 资产需求。
始终从用户身上来：为什么寻找母亲 / 故事想说什么 / 角色真正害怕什么。

### 1.5 成长阶梯（创造能力成长系统）

```
模糊冲动 → 故事种子 → 人物 → 关系 → 冲突 → 大纲 → 剧本 → 世界观 → 模组 → 可运行作品
```

用户第一次来"突然有个奇怪的想法"，几个月后：会写人物 / 会构建世界 / 会设计剧情 / 会设计游戏 / 会合作 / 能独立做出作品。**不是内容消费，是创造能力的成长。**

### 1.6 社区 = 想象力公共空间（不是内容平台）

- 传统社区：人 → 发帖 → 点赞 → 关注 → 注意力竞争 → 流量 → 焦虑 → 头部化。
- 本社区：**人 → 创作 → 开放资产 → 被别人使用 → 产生新作品 → 回流原作者** = 文化的再生产系统。
- 例：用户 A 造"永远下雨的城市" → B 写走其中角色 → C 做 TRPG 模组 → D 画它 → E 写它的历史 → 新作品 → 新世界 → 更多人继续创作。

### 1.7 多维宇宙 = 文化基因库

- 世界观/剧情/事件/资产/文化/约束六维不再只是后台技术架构，而是：**用户创造的文化被拆解成可复用的基本单元。**
- 例：世界 W001 内含人物 A / 地点 B / 神话 C / 道具 D / 历史 E / 规则 F；他人获授权后用 A+D 写故事、用 B+C+F 做模组、用整个世界写长篇。
- **"不是内容库，而是文化基因库。"**

### 1.8 自主实现

- 平台定位 = 基础设施 + 创作工具 + 社区 + IP 孵化器 + 指导者；**不是把作者变成平台的内容生产者**。
- 作品成熟后分岔：平台继续运营（文化产品）∥ 作者自主发展（众筹 / 出版 / 游戏 / 工作室 / 影视 / 商业化）。
- **"商业不是把人困在平台里，而是帮助一个人走得更远。"** 理想状态：用户因平台开始创作，最终成长到能建立自己的项目、工作室甚至文化产品。

### 1.9 商业四层

| 层 | 内容 | 卖什么 |
|---|---|---|
| 一 | 自由探索（免费/低门槛：玩→想→创作→发现自己） | 公共空间，不卖 |
| 二 | AI 创作工具（高级 AI / 世界观构建 / 长文本 / 图谱 / 模组 / 多模态） | **能力**，不是焦虑 |
| 三 | 创作者服务（IP 整理 / 世界观顾问 / 模组设计 / 商业化指导 / 众筹策划 / 孵化） | 专业支持 |
| 四 | 文化产品（众筹 / 游戏 / TRPG / 小说 / 插画 / 周边 / 影视 / 联合开发） | 平台参与收益 |

原则：**"作者因为平台获得更多可能，而不是平台因为作者获得更多控制。"**

### 1.10 商业氛围的产品表达（制度而非视觉）

产品机制应处处在说：你不用急 / 可以先不知道自己想做什么 / 很小的念头也值得认真对待 / AI 不会抢走你的故事 / 可以慢慢成长 / 作品可以被别人接着创造 / **最终可以带着自己的作品离开平台**。
结论："不需要把慢、温暖、安心当营销口号——产品机制真这样设计，用户自己会感受到。这是商业制度本身的风格，不是 UI 风格。"

## §3 现状对照——差距六项

### 差距 1：自我发现层缺失——访谈问 WHAT，不问 WHY

- 现行访谈（impulse spec v1.3.2 §5.4 两阶段生命周期）问的是 **WHAT**：35 字段、配方模块序、自由流程细化对象是 KG tier 深度——不是 **WHY**。
- 构想的生成序是"情感核心 → 冲动 → 主题 → 人物 → 冲突 → 世界 → 故事"；现行是配方模块路由序。两者不同构。
- 冲动卡 = **路由器**（分类 → 配方 → 队列前移），不是**镜子**；无"你最先想到的是他的死亡，还是他继续生活？"类追问。
- D21"说人话"是措辞纪律，不是对话哲学。
- D1 北极星 = "外部真实用户走完全流程并产出可用模组"——**任务完成框架**，非"用户看见自己"框架。

### 差距 2：用户成长纵轴缺失——产物在长，用户不在长

- D22 让**产物**分层了（B/C/O + M 专业层），但系统没有用户能力画像、没有跨会话成长轨迹——系统不知道用户"会了什么"。

### 差距 3：连接环 = 零

- 无用户体系：MockUserStore + /register 为未接线占位、JWT_SECRET 占位、SQLite 单机、session 级（探索取证 2026-09-28）。
- 多用户 / 社区 / UGC 平台化在全部文档库（含 archive）零实质机制设计。**项目名 Echo UGC 的 U 从未开工。**

### 差距 4：共创环 = 零

- 跨用户资产复用 / 授权 / 开放资产 / 共创协作：文档库零覆盖（同上取证）。
- 数据形态有正确胚子（GraphNode 三 id 形态 / EdgeType / StageCode 四层发号与血缘 / stale 只标记不删除），但全部只活在单会话内；血缘只挂"产物 → 图谱"，不挂"会话 → 会话"，更不挂"用户 → 用户"。
- D21 裁决"不建新会话"为**会话级**裁决（同会话改天继续），与用户级成长不构成冲突但须分层表述（见张力 B）。

### 差距 5：自主实现 = 反向差距（最尖锐）

- 构想："作者可以带着自己的作品离开平台。"
- 现状：仅主模组 doc 线有 md/json 导出（D15② 当时裁决"文档导出端点 = doc"，范围即此）；**图谱 / 展板 / TD 骰子 / TC 角色卡四产物线无文件导出端点**（09-27 拍板回写批行号级查证在案）；数据在单机 SQLite。
- 性质注记：这是**范围裁决的时序差，非遗漏**——D15② 裁决时"可携带性"不是议题；新构想把导出从"范围外"重新定义为"原则问题"。未来若立项补齐，须在台账说明与 D15② 的关系（范围扩展，非翻案）。

### 差距 6：商业模式只有成本侧

- 现行功能分级是**成本视角**（三级 × 每会话 ¥X），对应构想第一、二层。
- 第三层（创作者服务）与第四层（文化产品：众筹/出版/影视/联合开发）文档零覆盖；第四层"平台在零锁定下靠什么获利"从未被思考——现有付费墙三结论全部服务于第二层。

## §4 两个张力（表述框架，非裁决）

### 张力 A：体验层"删除世界观感" vs 资产层"世界观 = 文化基因库"

- D19 把世界观从故事线**体验**里赶出去（配方内零世界观模块）；构想把世界观作为社区**资产**的核心复用单元。
- 调和表述 = **双层结构**：体验层无世界观感（故事线自由引导）/ 资产层世界观是基因（设定线产物成为公共供给）。
- 供需结构与既有证据同源：动机基线（动机统计口径）设定线 ≈14% 供货、故事线 ≈64% 消费；09-20 调研三反转之一"服务设定党 = 给故事党供货"。文化基因库正是该洞察的机制化延伸；冷启动依赖设定型用户早期密度。

### 张力 B："不建新会话"（会话级）vs 成长阶梯（用户级）

- D21 拍板 9 砍的是**会话级跨会话继承**（对齐循环 = 同会话内 W/M/S 编译 → 对齐 → 继续）。
- 成长阶梯是**用户级纵向旅程**（跨月），需要用户体系先行（依赖差距 3 的解）。
- 分层表述：会话内成长已立（两阶段生命周期 + tier 逐级细化）；用户级成长 = 未立项的远期层，不与 D21 冲突。

## §6 逆风提醒（设计约束级）

"自我发现"式追问对一部分用户是**压力**而非解放。疗愈型（基线 5%）用户恰恰最需要"不用急"，但"你为什么觉得这件事重要"处理不当就是逼问。**"镜子"处理不当会变成"审讯"。** 第 0 拍（C3）若做，必须：可跳过 / 不评分 / 不门禁——与 D21 说人话纪律同向，且不得进入门禁契约计数。
