- Echo UGC 用户操作流程
  - 0️⃣ 身份初始化 🏠（/）
    - 首次访问
    - 检查 LocalStorage
      - 无 user_id
        - POST /api/identity/register
        - 保存 user_id 到 LocalStorage
        - 赋予临时user_id
        - 引导注册
          - 注册入用户系统系统
      - 有 user_id
        - 跳过注册
    - 显示用户 ID + FREE徽章
    - 说明：MVP阶段 VIP/SVIP 无差异，仅预留接口
  - 1️⃣ A1 世界观设计 🌍（/a1）
    - 使用生成器① IP设计生成器
    - Step1 进入A1工作台
    - Step2 选择方式
      - 路径A 选种子
        - 8种预设：克苏鲁/赛博朋克/仙侠等
        - 系统预填种子默认值
      - 路径B 自定义想法
        - 输入创新点子
        - 获取空模板+创新区
    - Step3 态②访谈（核心循环）
      - AI按10板块引导提问
      - 用户回答问题
      - 语义编译 三级匹配
        - 创新语句
          - AI分类提案 二选一确认卡
            - 归入现有字段
            - 归入其他区
        - 常规语句
          - 直接写入结构化文件
      - 右栏实时显示 diff + 10板块完成度
      - 判断 10板块必答完成？
        - 否 → 继续访谈（循环）
        - 是 → 定稿按钮点亮
    - Step4 定稿
      - 前置校验 10板块齐？
        - 否 → 409错误+缺失清单 → 回访谈补齐
        - 是 → 文件转图谱（一次性转换）
      - 产出 IP图谱 IP0001-W1-v1
        - 存入 GraphStore
        - 返回 graph_id + graph_code
      - 原地切换为 IP展板
        - 氛围图
        - 设定浮层
    - 🔁 修改分支（可选）
      - IP展板弹出图谱条目浮层
      - 选中条目去修改
      - 回态②定位板块
      - 重新定稿 → 新版本 W1-v2（旧版保留）
  - 2️⃣ A2 产品策划 🎲（/a2）
    - 使用生成器②③④⑤
    - Step1 进入A2工作台
    - Step2 GraphSelector 选择A1图谱
      - 默认最新已定稿
      - stale图谱带徽章
    - Step3 选择路径 ⭐核心分支
      - 路径A 完整策划线（策划增强线）
        - 策划分析 /api/a2/analyze
          - 游戏内容建议
          - 类似IP推荐
          - 风险提示
        - 多轮对话决策
          - 用户回答 → AI反馈
        - 决策落定 /api/a2/decide
          - 生成A2'文件
        - 查看策划报告 /api/a2/report
          - 免费完整实现
      - 路径B 跳过策划线（TRPG默认线）⚡
        - 骰子投影 生成器④
          - 生成骰子模板图谱
          - v+1 版本化
        - 角色投影 生成器⑤
          - ⚠️依赖 需图谱+骰子模板
          - 生成角色模板图谱
        - 直接进入主模组生成
        - TRPG默认标注+下位拓展
    - 汇合 主模组生成 生成器③
      - POST /api/a2/file/{id}/finalize
      - 产出 主模组图谱 IPxxxx-M1-v1
        - 主模组展板
        - 提示词组
        - A2''文件
    - Step4 展板组 /a2/boards
      - tab切换查看
        - 骰子展板
        - 角色展板
        - 主模组展板
  - 3️⃣ A3 内容生产 🎨（/a3）
    - 使用生成器⑥⑦
    - Step1 进入A3工作台
    - Step2 GraphSelector 选择主模组图谱
      - 默认最新
      - stale标记
    - Step3 场景+资产扩写 生成器⑥
      - POST /api/a3/expand
      - 输入 主模组图谱+scope+counts
      - 产出 次级模组图谱 IPxxxx-M1-S1-v1
        - 场景清单
        - 资产清单
    - Step4 查看提示词组
      - GET /api/a3/file/{id}/prompts
    - Step5 图片生成 生成器⑦
      - POST /api/a3/assets/generate
      - 异步任务+Wave分组轮询进度
      - 图片版本化
      - 审批后才可用
  - 4️⃣ GM大厅 🎮（/lobby）
    - Step1 进入GM大厅
    - Step2 装配数据包 GET /api/lobby
    - Step3 SceneView 载入A3场景图
    - Step4 CharacterCardPanel 角色卡
    - Step5 DicePanel 骰子面板
    - Step6 Terminal 交互终端
    - Step7 GM进行TRPG游玩 🏁

  - 🔀 stale图谱处理（横切机制）
    - 触发：上游变更（如A1重新定稿）
    - 自动标记下游图谱stale
      - 只标记不删除
    - 用户选择
      - 继续使用stale → 留痕使用
      - 重新生成 → 新版本v+1
  - 📜 核心规则
    - 修改不污染铁律
      - 一切修改=追加新版本
      - 永不就地覆盖
    - 图谱=事实源
      - 定稿后图谱为唯一真相
      - 文件=图谱序列化导出（单向）
    - stale不阻断
      - 提示变更集
      - 不阻断不删除
    - 四层编码
      - IP序号-阶段-实例-版本
      - 例 IP0001-W1-v1
