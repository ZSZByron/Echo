## 5.2 路由映射表 v1.3（配方化重述）

> **重述原则**：v1.2 表的"模块优先序"是**前移序列**（对固定 10 模块队列做置换重排）。甲架构下模块池开放（16 模块：原 10 + 6 新），路由 = **选择配方**——每个冲动类型映射到一张模块配方（池内子集 + 池内序）。`test_module_ids_match_spec` 锁序契约由注册表配方契约重锚（DN2，tier 池语义）。语气锚点 / 种子推荐 / ai_fill 粒度三列继续按 v1.2 有效，不重复誊录，下表只列变更列。

### 5.2.1 配方总则

- **默认配方（m1_default）**= 原 10 模块全集原序——设定型体验逐字节兼容（D14 红线）。
- **四故事型配方**（M2 落地，**D19 终审修订**）：**纯故事模块**——剧情（M12）+ 角色（M11）即全部（plot/unsure 剧情主线打头；romance/character_driven 角色速写打头）；romance 边界声明由 §9 合规边界锚点承载（M10 设定边界不再常驻故事线）；**世界建构模块仅设定线使用（D19）**。
- **通用线（unsure）** = 故事侧默认配方（承接 v1.2 通用线行语义；冲动坐标可随行为向设定侧迁移，§10.1 机制不变）。
- **门禁语义（DN1 结果）**：配方内模块全达标方可 finalize；missing_sections 只列配方内未达标模块；配方外 = 不适用。
- **prompt 骨架恒 1（R2 不变式）**：配方差异是数据不是代码。

### 5.2.2 类型 → 配方矩阵（M2 已实施，已对照代码真源核验）

> 真源 = `RECIPES`（`backend/app/domains/creation/shared/module_registry.py`）：每型一个 Recipe，含 module_ids 有序子集 / entry_subfield 入口前置 / anchor 语气锚点 / ai_fill 粒度。未知冲动类型确定性降级 default（G3）。配方矩阵（**D19 终审版**，故事四型 = 纯故事模块 剧情+角色，零世界建构；原 DN6 初稿的 §5.2 前移序子集方案就此废除）：

| 配方 | module_ids（有序） | entry_subfield | anchor | ai_fill |
|------|-------------------|----------------|--------|---------|
| **default** | 原 10 模块全集原序（设定型逐字节不变） | 无 | 无 | default（无过滤） |
| **plot**（剧情） | 剧情 → 角色 | 剧情.core_dilemma | E1-Lite 锚点逐字 | default |
| **unsure**（说不清，通用线） | 剧情 → 角色 | 剧情.opening_event | 同上 | default |
| **romance**（爱情） | 角色 → 剧情 | 角色.key_relations | 合规边界措辞逐字保留（§9） | exclude 文明与社会.faction_type（M4b 字段级收口；D19 后配方内无该模块，保留为无害防御） |
| **character_driven**（角色驱动） | 角色 → 剧情 | 角色.identity | 同上 | default |
| 其余六型（设定-重度/哲理/探索/怀旧/疗愈等） | E1-Lite 前移置换全集（nostalgia/healing 不在优先级表 → 原序全集） | E1-Lite 入口子字段逐字 | E1-Lite 锚点逐字 | default |

**故事配方的设计约束（D19 终审版）**：故事配方 = 世界建构族的**空子集**——每故事型 module_ids 与世界建构族交集为空（灵魂契约，测试 `test_story_recipes_contain_zero_worldview_modules` 锁定）；入口前置、语气锚点（情感张力/合规边界）逐字保留不受配方裁剪影响；finalize 门禁故事线只需 剧情+角色 过半（DN1 子集语义自动收窄）；graphify 合法锚点 = 配方并集（自动缩小）；产出模块世界信号缺失走 optional 降级+披露（§5.2.3，既定设计）。**v1.2 §5.2 表八行 + 通用线行保留为历史设计依据与语气/种子/兑现物列的权威来源；模块序一列以本节配方表为准。**

### 5.2.3 主模组产出闭环（M3 并入，A2 资产收编）

配方执行完毕后可进入**产出模块族**：主模组文字版（module_compile，LLM 生产方契约评审已留痕）/ 骰子投影 / 角色投影 / 文档导出（端点资源名 = `doc`，界面「文档输出」，D15）。`signal_requirements` 声明输入依赖，缺料 → 409（A2 契约族照搬）。此节为 §5.2 的产出侧延伸，取代 v1.2 表"A2 联动意向"列——A2 阶段坐标退役，产出模块直接入池。
