### 2.2 功能按端拆分原则

| 原则 | 说明 | 例子 |
|---|---|---|
| **重创作在 Web** | 创作工具需要大屏幕 + 键盘 + 复杂交互 | 世界编辑器、图谱编辑器 |
| **轻浏览在小程序** | 即开即用，无需安装 | 灵感速记、内容浏览 |
| **深互动在 App** | 需要推送通知 + 持久连接 | 游戏大厅、即时消息 |
| **全景管理在桌面** | 数据密集 + 批量操作 | 用户管理、数据分析 |

## 八、数据模型（MVP 核心）

### 8.1 用户模型

```
User
├── id: UUID
├── username: str (unique)
├── email: str (unique)
├── password_hash: str
├── display_name: str
├── avatar_url: str | None
├── bio: str | None
├── skill_tags: list[str]        # 编剧/原画师/概念设计/AI/GM/玩家
├── role: UserRole               # creator / player / admin
├── created_at: datetime
└── updated_at: datetime
```

### 8.2 作品模型

```
Work
├── id: UUID
├── author_id: UUID (FK → User)
├── title: str
├── description: str
├── content: str                  # Markdown 正文
├── tags: list[str]              # TRPG系统标签（D&D/克苏鲁/自定义...）
├── work_type: WorkType          # world / module / scenario / asset_pack
├── module_data: dict | None     # 关联的 CampaignPackage JSON
├── cover_image: str | None
├── status: WorkStatus           # draft / published / archived
├── view_count: int
├── like_count: int
├── favorite_count: int
├── created_at: datetime
└── updated_at: datetime
```

### 8.3 互动模型

```
Comment
├── id: UUID
├── work_id: UUID (FK → Work)
├── user_id: UUID (FK → User)
├── parent_id: UUID | None       # 支持嵌套回复
├── content: str
├── created_at: datetime

Like
├── user_id: UUID (FK → User)
├── work_id: UUID (FK → Work)
└── created_at: datetime

Favorite
├── user_id: UUID (FK → User)
├── work_id: UUID (FK → Work)
└── created_at: datetime
```

### 8.4 创作工具模型（扩展现有）

```
Module（新增）
├── id: UUID
├── level: ConstraintLevel       # CORE / MODULE / SCENARIO
├── parent_id: UUID | None       # SCENARIO → MODULE 继承
├── world_config: dict           # 世界设定
├── constraints: list[Constraint]
├── graph_snapshot: dict         # 知识图谱快照
└── created_at: datetime

CampaignPackage（新增）
├── id: UUID
├── main_module_id: UUID (FK → Module)
├── scenario_module_id: UUID (FK → Module)
├── merged_config: dict          # 继承覆写后的完整配置
├── work_id: UUID | None (FK → Work)  # 可关联到作品
└── created_at: datetime

GMSession（新增）
├── id: UUID
├── campaign_package_id: UUID (FK → CampaignPackage)
├── gm_user_id: UUID (FK → User)
├── mode: GMMode                 # assistant / auto / tutorial
├── state: dict                  # 当前游戏状态
├── case_cache: list[dict]       # 判例缓存
└── created_at: datetime

Inspiration（新增，小程序用）
├── id: UUID
├── user_id: UUID (FK → User)
├── content: str                 # 灵感速记内容
├── tags: list[str]              # 标签
├── is_synced: bool              # 是否已同步到 Web 端
├── created_at: datetime
└── updated_at: datetime

SyncLog（新增，多端同步）
├── id: UUID
├── user_id: UUID (FK → User)
├── device_type: DeviceType      # web / miniprogram / app / desktop
├── action: SyncAction           # pull / push
├── entity_type: str             # work / comment / like / inspiration
├── entity_id: UUID
├── timestamp: datetime
└── created_at: datetime
```

## 九、关键设计决策

| # | 决策 | 选择 | 理由 | 日期 |
|---|---|---|---|---|
| 1 | MVP 范围 | **创作工具 + 最简社区** | 没有内容就没有社区，没有社区就没有交易 | 2026-08-04 |
| 2 | MVP 多端策略 | **Web 核心功能，小程序可选后置** | 重创作需要大屏幕，轻浏览可小程序 | 2026-08-04 |
| 3 | App 端/桌面端启动 | **第7-12月（MVP 后）** | 需要用户量支撑，避免早期分散资源 | 2026-08-04 |
| 4 | 社区是否独立服务 | **不独立，集成到现有 FastAPI** | MVP 阶段单体足够，微服务后置 | 2026-08-04 |
| 5 | 数据库是否迁移 | **MVP 用 SQLite，后置 PostgreSQL** | 减少基础设施复杂度 | 2026-08-04 |
| 6 | 认证方案 | **JWT（多端统一）** | FastAPI 生态标准，无状态 | 2026-08-04 |
| 7 | 多端同步策略 | **REST API + 本地缓存** | MVP 阶段无需实时同步，简单拉取推送即可 | 2026-08-04 |
| 8 | 社区功能最小集 | **注册+主页+作品+评论+点赞** | 能闭环：注册→发布→互动 | 2026-08-04 |
| 9 | AI GM 是否纳入 MVP | **Sprint 4（第13-16周）** | 是核心蓝海但需要创作工具先就绪 | 2026-08-04 |
| 10 | 小程序创作端启动 | **Sprint 5（第17-20周，可选）** | 轻量创作场景，Web 端核心就绪后扩展 | 2026-08-04 |
| 11 | 交易/分账何时启动 | **第7-12月（MVP 后）** | 没有用户量和内容量，交易无意义 | 2026-08-04 |
| 12 | 企业服务/治理何时启动 | **第13-24月** | 需要足够的众筹组和企业客户 | 2026-08-04 |
