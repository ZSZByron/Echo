## 1. 提案内容

**B1 验收对象改为"甲的模块化产物"**，具体为两个验收物：

1. **故事型全流程**：plot/romance/unsure/character_driven 任一故事型冲动入口进入，走配方化访谈（M12 剧情 + M11 角色 + 有限世界建构子集），配方子集门禁定稿，图谱与产出链正常工作。验收锚点 = 2026-09-22 翻车记录（`.sisyphus/evidence/jia-requirement-evidence-interview-failure.md`）四场景重放全绿——首问故事、偏转被尊重、细节入素材槽、建议贴故事。实现依据：M1 模块注册表 + 配方门禁（b6a56f4）、M2 故事模块族 + 四型配方（45caf2a）。

2. **主模组文字版 finalize→Markdown 闭环**：定稿后经产出模块（M3，d5ae8f6）生成主模组文档，一路到 Markdown 导出，零加工可读。这接管了原 A2 P0"主模组文字版闭环"的实质验收意图，但其坐标不再是"A2 阶段产出"，而是甲架构内的产出模块（family="output"）。

## 2. 不变的部分

- B1 的性质不变：仍是**基线验收**（一名外部用户在无协助下走通全链并真实使用导出物，D 系原始意图）。
- 验收纪律不变：真实用户、无协助、导出物被真实使用。
- 设定型（default 配方）逐字节回归仍是前置条件：故事型绿灯不得以设定型体验受损为代价。

## 3. 时点

原 B1 时点绑定 A2 P0（~10 月初顺延案）随分期一起失效。建议时点 = F1-F4 四审通过后、产品方终审前，作为终审（B1 重定义验收，D17 波次序既有表述）的直接输入。具体日期由产品方终审时定。
