## §2 施工范围（动什么）
1. **触发时机**：`guide_engine._apply_stall_guard`（L883-1028，话术 L942-945）对 `suggest_examples`（interviewer.py L589-651）的调用，从 stall==2 失败路径 → interview 主路径每问默认附带（合并单次调用）。
2. **话术**：删除"我没能准确理解你的回答"等道歉/指责式文案 → 邀请式（"这里有几个方向，也可以直接说你的"）。
3. **通道全通确认**：序号直选（guide_engine L1251-1280 pending_suggestions）/ 换一批 / 揉合（"把 1 和 3 揉一起"）三条用户动作端到端可用。
4. **跳过路径**（L1223-1247）：跳过后仍出选项，不做死路。
5. **埋点落日志**（天级工作量）：三个信号源——选项选票（哪个被选）/ stall 计数 / 跳过——结构化日志 + 周报聚合；不扩信号闭集（治理未拍）。
6. **【顺带项·阻塞则砍】九型弹种**：生成 prompt 注入九型 anchor-block（module_registry.py L73-77 类型已在，impulse_coords 可取），纯 prompt 增补、零调用增量。

1. 每问带 3 个选项，且选项从已答内容长出（答完"让渡利益"，后续选项须与让渡利益相关，严禁全局通用示例——护栏 L621-630 生效）；
