## §1 动态结构问句模板（26 个变化定义）

### 1.1 两个模板族（通用骨架）

**▶ 起终点式（20 项）**——三问式按已知程度选用：

| 情形 | 问句模板 |
|---|---|
| 全问（from/to 都空） | 「他（它）原来是什么样的？后来变成了什么样？中间是哪件事促成的？」 |
| 补 from（只知 to） | 「记下了他变成了【终点】——他原来是什么样的？我猜是从【选项A】／【选项B】开始的，对吗？」 |
| 补 to（只知 from） | 「从【起点】出发的这个人，你想让他最后变成什么样？」 |
| 补 trigger（两态都有） | 「是什么事，把他从【起点】推成了【终点】？」 |

**⇄ 属性维度式（5 项）**——两问式：

| 情形 | 问句模板 |
|---|---|
| 全问 | 「在【维度】上，是变多了还是变少了／变强了还是变弱了？变化有多猛？」 |
| 补方向（只知维度） | 「【维度】这件事——是往涨的方向走，还是往跌的方向走？」 |

### 1.2 二十六项逐项实例化（问句 · 例答）

| 项（形态） | 实例化问句 | 例答 |
|---|---|---|
| 力量.获取方式 ▶ | 「得到力量之前是什么人？得到之后成了什么？走的是哪条路？」 | 凡人少年 →(顿悟) 悟道剑修 |
| 力量.力量代价 ⇄ | 「用力量要付代价——伤的是哪一样？越用越狠吗？」 | 寿元（长→短·缓） |
| 历史.关键节点 ▶ | 「这件大事之前世界什么样？之后变成了什么样？」 | 神治之世 →(天道崩碎) 碎裂乱世 |
| 历史.当代主剧情 ▶ | 「这个时代从什么局面开始，正被推向什么局面？」 | 枯竭之世 → 补天／虚无 |
| 剧情.破局大事 ▶ | 「他原来的日子什么样？哪件事把它砸碎了？」 | 婚宴 → 密令到 |
| 剧情.选项一/二与代价 ▶×2 | 「选这边：得到什么、失去什么？」（两遍） | 立功+线人活 ↔ 众叛亲离 |
| 剧情.僵局的代价 ▶ | 「如果他一直拖着不选，每天会塌掉什么？」 | 线人风险 +1／日 |
| 剧情.交换之秤 ⇄ | 「他要的东西在涨，那跌下去的是什么？」 | 威能↑ ↔ 恩义↓ |
| 剧情.中途转折 ▶ | 「哪次变化让他发现——自己一直追错了方向？」 | 误认凶手 →(血书) 知她护道 |
| 剧情.明暗交汇点 ▶ | 「瞒着的那条线，哪一刻浮出水面、和明线撞上？」 | 档案曝光·当众 |
| 剧情.成功线/失败线 ▶×2 | 「赢到那头，世界和他各是什么样？／输到那头，他跌到哪一步？」 | 端网·家散／亡命 |
| 剧情.摇摆第三者 ⇄ | 「那个人立场往哪边偏？什么事会让他倒戈？」 | 我方 ↔ 对方（抚恤金真相） |
| 剧情.大方向 ⇄ | 「整个故事的情绪，是往上走、往下沉、还是来回打转？」 | 先扬后抑 |
| 剧情.衔接点 ▶ | 「支线在哪个节骨眼上碰到主线？碰之前之后各什么样？」 | 高潮前夜·软肋救场 |
| 剧情.支线结局 ▶ | 「这条支线走到头，落在哪里？」 | 默默守望 → 放手祝福 |
| 角色.代价史 ▶ | 「这个缺陷每次发作——发作前他什么样、发作后什么样？」 | 不求助 → 线人暴露 |
| 角色.关系卡变化 ⇄ | 「这段关系里，信任／亲近／敌意现在是多是少？往后会怎么走？」 | 信任：满→裂（可修复？） |
| 角色.弧光 起点/转折/终点/拒绝线 ▶×4 | 「开头的他是什么人？哪件事逼他开始变？结尾变成什么人？（或者：全世界都变了，他偏不变？）」 | 谁都不信 →(被迫托付) 敢交后背 |
| 玩法.玩家身份 ▶ | 「玩家（主角）从什么身份起步，最后站到什么位置？」 | 外门弟子 → 执剑长老 |
| 玩法.成长方式 ⇉ | 「变强是一点点攒（量变），还是关口上突变（质变）？」 | 每次突破解锁新剑意 |
| 玩法.成长尽头 ▶ | 「一路变强，变到头是什么样？」 | 以剑合道·自成天道 |

> 模板与④稿兼容性实测：弧光/玩家身份现行问法即模板原生形态，其余动态项在 2.1 落地时按上表改写。

## §3 投递话术族（⑦的三示范扩成句式表，随 1.3 落地）

| 族 | 句式 | 例 |
|---|---|---|
| 落位确认 | 「好画面／好想法——我记进【槽位名】了（一句话复述）。回到刚才：【当前问题】」 | 「记进【支线卡·结局】了（他放下这段过往）。回到力量——」 |
| 灵感入架 | 「记进你的灵感架了。它让我想到【槽位A】或【槽位B】——现在安家，还是先留着？」 | 「满天断剑——像【视觉·意象】，也可能是【世界起源】」 |
| 回题桥接 | 「这正好和【当前模块】是一对——」 | 「师姐的剑和力量代价是一对：恩义就是他的代价」 |
| 半填补问（▶） | 「记下【终点/起点】了。我猜另一头是【选项】，对吗？」 | 「记下'变得特别狠'——是从'最守规矩'开始的吗？」 |
| 半填补问（⇄） | 「【维度】——是涨还是跌？」 | 「信任——全崩了，还是裂了缝？」 |
| 撤销护栏 | 「刚才那笔记错了地方？说一声，我挪走。」（D23 披露沿用） | |
| **追加循环（清单停驻）** | 「记下这一条了。还有吗——再说说下一个，或者我们聊别的？」＋AI 长卡提议「要不要来一张【XX】的卡？」（⑤§9 清单型 L3 配套） | 收完师姐卡：「还有吗——要不要来一张她义父的卡？」 |
