## §0 三形态定义与判定规则

| 形态 | 标记 | 答案的形状 | 例 |
|---|---|---|---|
| **点定义** | ● | 快照：一个状态/事实/规则——"是什么" | 边城义庄的守夜人 |
| **变化定义·起终点式** | ▶ | 轨迹：**起点态 →(触发) 终点态**——"从什么样变成什么样" | 从用谎言保护所有人 → 学会让真相先落地 |
| **变化定义·属性维度式** | ⇄ | 轴变：**维度 + 消长方向（±幅度/速率）**——"哪个维度、变强还是变弱" | 信任(满→裂)；禁术威能(弱→强) ↔ 恩义(全→负) |
| 双形特例 | ⇉ | 同一字段两种变化模式并存 | 成长：量变=维度渐进 / 质变=态跃迁 |

**判定规则**：① 有明确**两态迁移**的（人变了、真相曝光了、地位升格了）→ ▶ 起终点式；② 只有**强弱/多少/方向消长**、没有可命名的两个态的（信任加深、资源枯竭、立场摇摆）→ ⇄ 属性维度式；③ 记录的是**状态本身**而非状态迁移 → ● 点定义。

**全量统计**：92 个 L3 = **● 点 66 ＋ 变化 26**（▶ 起终点 20 ＋ ⇄ 属性维度 5 ＋ ⇉ 双形 1）。

## §2 变化定义转换设计（19 组，覆盖 26 个变化 L3）

> 每组：转换后形态（结构）＋ 示例。示例沿用官方宇宙（林澈/仙侠/守夜人）。

**§2-1 力量体系.获取方式 ▶**
结构：`获得前之态 →(路径：学/觉醒/仪式/科技) 获得后之态 ＋ 门槛（封闭精英/开放众生）`
例：凡人少年 →(顿悟觉醒) 悟道剑修；门槛：万中无一。

**§2-2 力量体系.力量代价 ⇄**
结构：`代价维度表：维度 + 消长方向 + 速率（缓/跳变）`
例：寿元(长→短·缓) ｜ 人形(存→失·随用量累积) ｜ 心性(稳→蚀·大失败时跳变)。

**§2-3 历史时间线.关键节点 ▶**
结构：`节点前世界态 →(触发事件) 节点后世界态`
例：神治有序之世 →(300年前天道崩碎) 碎裂乱世（古神陨落/修士代天）。
> 施工注：此转换改变上传解析与图谱"事件节点"的数据形状（从"事件条目"变"态迁移边"）——影响最大的一处，入拍板。

**§2-4 历史时间线.当代主剧情 ▶**
结构：`当代开场世界态 → 收场世界态（收法可两备：成/败）`
例：灵气枯竭之世 → 补天续灵之世 / 虚无吞没之世。

**§2-5 剧情.破局大事 ▶**
结构：`日常态 →(破局事件) 失衡态`
例：婚礼进行时 →(卧底密令到) 当夜出走。

**§2-6 剧情.核心抉择 ▶ 三态机**
结构：`当前态 → 选A态(得X·失Y) ／ 选B态(得X'·失Y')；停留原地 = 当前态衰减(僵局代价)`
例：林澈：忠家（妹夫账目保全·线人当夜死）↔ 忠职（线人活·婚礼当夜众叛亲离）；拖延 = 线人风险每时辰 +1。

**§2-7 剧情.交换之秤 ⇄**
结构：`得之维 ↔ 失之维（双向天平）`
例：禁术威能(弱→强) ↔ 授业恩义(全→负)。

**§2-8 剧情.中途转折 ▶（认知迁移）**
结构：`误判态 →(新线索) 明判态`
例：以为师姐是灭门凶手 →(血书现) 知她十年护道。

**§2-9 剧情.主线暗线（明暗交汇点承载）▶**
结构：`隐瞒态(谁不知什么) →(交汇事件) 曝光态(各方知情位重排)`
例：义父=保护伞（林澈不知）→(档案曝光) 人尽皆知·信任崩塌。

**§2-10 剧情.分支预案 ▶ 双终点**
结构：`抉择时刻态 → 成功态 ／ 失败态`
例：端网成功·家散人离 / 端网失败·亡命江湖。（与 P2 拆槽天然同构——成功/失败本就是两条迁移边。）

**§2-11 剧情.摇摆的第三者 ⇄**
结构：`立场维度：我方 ↔ 对方（摆幅 + 触发）`
例：搭档遗孀：我方(护他) ↔ 对方(被义父收买)——触发：抚恤金真相。

**§2-12 剧情.大方向 ⇄**
结构：`基调维度三向：扬 ↗ ／ 沉 ↘ ／ 环 ↻`
例：先扬后抑=复合轨迹(扬→沉)；结局留微光=终点态属性（● 点，见 §3）。

**§2-13 剧情.支线卡 ▶（整卡轨迹）**
结构：`支线开启态 →(衔接点×N，各带衔接方式=对主线的修改器) 支线结局态`
例：咖啡店支线：默默守望 →(得知她有男友) 放手祝福——反哺：主线上他学会了告别。

**§2-14 角色.代价史 ▶ 清单**
结构：`发作前 →(软肋被戳) 发作后` × N 条
例：①证据烂在手里 →(不求助) 线人暴露；②独闯仓库 →(不信队友) 搭档殉职。

**§2-15 角色.关系卡 ⇄ 附件**
结构：`关系现状(● 点) ＋ 变化维度附件：信任/亲密/敌意 各维度 + 方向 + 幅度`
例：师姐卡：现状=互为唯一软肋；附件=信任(满→裂，可修复?——留给弧光终点)。

**§2-16 角色.弧光 ▶ 标准形（全系统范本）**
结构：`起点态 →(转折事件) 终点态；拒绝线 = 幅度 0 特例（"从X到X"——不变也是合法答案）`
例：谁都不信 →(被迫托付义父案真相) 敢把后背交给别人。
> 现行 hint"从 X 到 Y"与本文书稿 ④ 的优化问法已与此形态对齐——弧光即 ▶ 的原生样板。

**§2-17 玩法.玩家身份 ▶**
结构：`入世态 → 成就态`
例：外门弟子 → 执剑长老（现行示例原生就是起终点，零转换成本）。

**§2-18 玩法.成长方式 ⇉ 双形**
结构：`量变 = 属性维度渐进（境界: 低→高）；质变 = 起终点跃迁（凡 → 圣，一次跳变）`
例：每次突破境界解锁新剑意=质变链（▶▶▶ 串成阶跃轨迹）。

**§2-19 玩法.成长尽头 ▶ 终点半边**
结构：`……→ 尽头态（三型：地位/法则/心境——即终点态的分类）`
与 §2-17 拼接即完整轨迹：入世态 →(成长方式) 尽头态。例：外门弟子 →(质变链) 以剑合道·自成天道。

## §4 工程落点（与既有管线的接缝）

1. **fills 值 schema**：三形态三结构——● = 文本快照；▶ = `{from态, to态, trigger?, cost?}`；⇄ = `{dimension, direction, pace/幅度?}`。LLM 按字段的值形态声明产出（interviewer fills 解析按形态分支）。
2. **graphify 图谱语义**：● → 节点；▶ → **迁移边**（from 节点 → to 节点，边携带 trigger——事件节点从"点"升格为"边"）；⇄ → 节点属性的阶段序列（或属性变更边）。概念边家族 +1 枚「迁移边」（与⑤稿「衔接边」同期设计）。
3. **访谈问法**：▶ 题天然问"他从什么样变成什么样"（弧光/玩家身份现行文案已对齐）；⇄ 题问"哪个维度、变强还是变弱"。与文稿④的问句优化兼容，无需返工。
4. **渲染红利**：所有变化定义可同框渲染为**状态轨迹条**（展板/图谱 UI：● 站点 + ▶ 弧线 + ⇄ 仪表盘）——三类值形态三种可视化原子。
5. **与 D23-B 合流**：AnswerNode 树（大类→小类→更小类）承载分类骨架，值形态承载**叶子节点的数据类型**——两轴正交，同批施工不冲突。
