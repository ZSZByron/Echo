> **用途**：①甲计划 F3 真实 QA 的验收脚本蓝本 ②产品方审阅"每类用户最终拿到什么"的样例集。

## 案例 1：设定-重度型

**用户输入**：选"设定-重度"卡 → 种子详情页选「群星彼岸」→ 公理三问回答："这个宇宙的铁律：一切力量皆需等价代价（公理）；群星是活的神祇（核心概念）；冷峻浩瀚的太空歌剧（类型）"。

**流程**：S0 种子+公理 → S1 力量推演演示（M3【锚】：AI 从公理推出 3 条后果供验证——" stellar 共鸣要折寿/神祇馈赠需献祭记忆/舰队跃迁耗一颗行星的寿命"）→ S2 世界骨架预览+视觉板（M7【输】："哥特废墟+星舰残骸+冷蓝金属"）→ S3 M5/M6/M4 逐项【代+确认】（AI 代填文明/历史/地理，用户逐项确认或改写）→ S4 M1 完整收口（命名「星骸纪元」+核心体验一句话）。

**断言**：首问=公理三问；M8/M9 仅一句意向探测（答"否"→收缩）；代填项全部带【代】来源徽章。

**最终结果示例——世界骨架预览（S2 文字版节选）**：
```
【星骸纪元】骨架预览 v1
◆ 公理：一切力量皆需等价代价
◆ 力量体系（由公理推演·已验证）
  · 星共鸣术：沟通群星之神→每次折寿一年
  · 神恩：实现愿望→献祭一段记忆
  · 跃迁引擎：折跃舰队→行星寿命 -100 年
◆ 视觉板：哥特废墟 / 星舰残骸 / 冷蓝金属 / 深空黑
[导出资产包] [进入定稿]
```

## 案例 2：角色驱动型

**用户输入**：选"角色驱动"卡 → M11 属性卡："沈孤鸿，前朝剑圣；欲望：为师门复仇；缺陷：重诺到自毁；关键关系：师父(被杀)/仇人·当朝国师；弧光方向：复仇→放下；命运命题：'他能否在复仇前活成师父希望的人？'"

**流程**：S0 属性卡 → S1 文本速写卡+命运轨道（M12【输】：命运轨道事件"国师篡位日，他在城头拔剑又收剑"）→ S2 完整速写卡（含角色视觉：M7"褪色青衫+断剑"）+ 弧光轨道图 → S3 世界按需展开（M2【代】舞台"王朝末年灵气枯竭"、M3 轻【输】"他的剑气以寿元为代价"）→ S4 M6 关键节点与弧光对齐校验。

**断言**：首问=角色.身份；M11 在 prompt 目录首位；世界模块全部【代】+确认。

**最终结果示例——速写卡（S2）**：
```
┌─ 角色速写卡 · 沈孤鸿 ──────────────┐
│ 身份：前朝剑圣·褪色青衫·断剑        │
│ 欲望：为师门复仇        缺陷：重诺自毁  │
│ 弧光：复仇 ──城头收剑──→ 放下        │
│ 命运轨道：国师篡位日，城头拔剑又收剑    │
│ 📎 世界舞台（AI 代拟·已确认）：王朝末年，│
│    灵气枯竭，剑气以寿元为代价          │
└──────────────────────┘
```

## 案例 3：剧情型（翻车记录的正面重放）

**用户输入**：选"剧情"卡（次冲动：爱情）→ M12 单问"你的故事从哪一幕开始？"→ **"雪原上，妹妹失踪了，只留下一只绣鞋。他必须立刻决定：追进暴雪，还是回去报信。"**（开场事件+核心抉择一次给出）

**流程**：S0 M12 单问启动 → S1 开场叙事段（DN5 端点）+ 时间线骨架（M6【输】关键节点"北境百年战争第 7 年"——**历史退居背景**）→ S2 时间线可视化+冲突地图（M5【输】"守军残部 vs 寒潮教团"）→ S3 M2【代】解释层、M3/M4【代】try-fail 阻力（"极寒反噬：越深入雪原，记忆越冻结"）→ S4 M12 分支树【锚】收口 + M1【代+确认】命名。

**断言**：**全程不出现"势力类型/历史纪元"类世界建构轰炸**（翻车场景 3 反转）；偏转可用（"能先聊聊妹妹吗"→指针跳 M12.线索链）；剧情细节进 M12 不触发误判提案（翻车场景 2 反转）。

**最终结果示例——开场叙事段 + 分支树（S1/S4）**：
```
【开场 · 雪原绣鞋】（200 字，opening_narrative 产物）
暴雪第七日，哨塔的钟哑了。沈见山在雪里看见那只绣鞋时，
妻子的话还在耳边——"看好小雪"。追进去，是教团的猎场；
回去报信，雪停前妹妹就是一具冰雕。他把剑塞进腰带，
数了三次呼吸，迈向雪深处。……（触发 M12.核心抉择）

【M12.分支预案 · 已勾选】
 ✓ 追进暴雪 → 成功树：找到妹妹·失去两指（冻伤）
 ✗ 回去报信 → 失败树：妹妹被教团"收养"→ 二幕反转
```

## 案例 4：哲理型

**用户输入**：选"哲理"卡 → "我的世界里不可违反的规则：**死者不得复生**——所有复活尝试都制造'赝品'。"

**流程**：S0 公理命题采集 → S1 公理卡（命题+违反后果推演【锚】："复活者每存在一天，一个活人失去名字"）+ 文明绑定（M5【输·绑定共现】：信奉者"无名教会"/违反者"盗名者公会"——强制成对出现）→ S2 思想实验切片（M12.剧情切片【锚】："一个母亲复活了儿子，第二天她忘了自己叫什么"）→ S3 M6【代】违规史 → S4 M1 主题一句话收口。

**最终结果示例——公理卡（S1）**：
```
┌─ 世界公理卡 ─────────────────┐
│ 公理：死者不得复生              │
│ 违反后果：复活者每存在一天，       │
│           一个活人失去名字        │
│ 信奉者：无名教会（以遗忘为圣礼）    │
│ 违反者：盗名者公会（贩卖名字）     │
│ 思想实验：母亲复活儿子→翌日忘己名  │
└─────────────────────┘
```

## 案例 5：爱情型（content_guard 同批强制）

**用户输入**：选"爱情"卡 → 合规预检通过（成年角色声明）→ M11 双人关系卡："宿敌恋人——帝国女将军 × 叛军军师；关系引力：互相欣赏的敌人；边界声明：克制留白，无露骨内容。"

**流程**：S0 关系卡+M1 套路库选择（"命中宿敌"）+ 合规前置 → S1 文本双人速写卡 → S2 初见场景（M12【输】opening="战场谈判，她递毒酒他饮尽"）+ 完整速写 → S3 情感节拍线（M12.tension=情感阻力："效忠帝国 vs 心仪叛军"）+ M3/M4/M5【代】阻力素材库 → S4 M10 强化 preset 全程生效。

## 案例 7：疗愈型

**用户输入**：选"疗愈"卡（零提问）→ 种子直达「破晓之剑」→ M1 仅命名权："就叫'晨风谷'吧。"

**流程**：S0 一键直达 → S1 现成世界+陪伴开场 → S2 第一段共写（用户接一句"旅人推开了客栈的门"，AI 顺势两句）→ S3 按需"揭示"（用户点"这个世界还有什么？"→ 逐层展开 AI 代填内容——反向探索）→ S4 深度支持走 LLM 原生，不建专属机制。

**断言**：全程提问数 ≤1；M2-M9 全【代·不可见】；M10 全代填；无门禁压力提示。

**最终结果示例——共写片段（S2）**：
```
【晨风谷 · 与你共写】
AI：晨风谷的客栈里，炉火正暖。掌柜擦着一只
    不属于任何客人的杯子，等你开口。
你：旅人推开了客栈的门。
AI：风铃响了一声。掌柜没抬头，只把杯子推到
    逆光的位置——"这杯，等你很久了。"
    （想继续吗？不想写也可以，我替你走两步。）
```

## 案例 8：说不清型（迁移链路）

**用户输入**：选"说不清"卡 → M12 单问"先聊聊你世界里发生的事"→"呃……就是一个挺酷的机械城市？有很多齿轮和蒸汽……别的没想过。"

**流程**：S0 中性引导 → S1 推断包交付（M5/M2/M3/M4【代·推断】全部带纠正入口）→ S2 三值判定 → S3 迁移（按判定结果进入目标型流程，**已采集/已纠正字段全量继承**）→ S4 本型撤销。

**最终结果示例——推断包 + 迁移报告（S1/S3）**：
```
 【推断包 · 3 条】（对/不对/接近）
 ① "齿轮城市=维多利亚蒸汽朋克文明"      [对✓]
 ② "蒸汽核心是神权机构，垄断动力"        [接近△→改为"商会垄断"]
 ③ "你更想写小人物在大机器里的故事"       [对✓]
→ 三值判定：剧情倾向 0.78 → 坐标轴≈72
【迁移报告】
 目标流程：剧情型（M12 首字段已预填"机械城，
 齿轮与蒸汽"）· 已继承 2 条纠正记录（=坐标证据）
 本型撤销，字段无损带入 → [进入剧情流程]
```
