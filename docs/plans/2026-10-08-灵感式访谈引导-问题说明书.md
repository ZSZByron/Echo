**三个超出 D23 范围的新取证点**：
1. **"不知道"是合法创作状态**——用户不是没想法，是被问法卡住（"失去美好"三句后系统才听到情感核心）；
2. **术语黑话暴露**——"什么叫执行者？"（D21 说人话整改了进度栏/fills 措辞，未覆盖**问题文案本身**的编剧术语：执行者/张力源/秘密维度）；
3. **结构化表达 vs 线性问卷冲突**——"一个故事里有主线和支线！你问的是什么？""用支线结局说明主线成功"——高结构感用户的回答是网状的，问卷是队列的。

### 2.3 关键代码事实（本文论证依据）

- **F1 问题文案全是静态模板**：M11/M12 十五字段 question/hint/example 写死（story_modules.py L58/65/72/79/86/93/100/107/114/130/137/144/151/160/167），`example` 为全局统一示例（"如：边城义庄的守夜人……"），与用户种子/已答内容零关联。
- **F2 单问句铁律**：interviewer.py L580 "严禁追加任何其他疑问句——单问句铁律"——LLM 被禁止即兴追问，只能问当前模板题。
- **F3 灵感生成的触发条件是失败**：suggest_examples 仅在 stall_count==2（连续两轮填不上当前字段）由 `_apply_stall_guard` 调用（guide_engine.py L930-949），且话术为道歉/指责式："我没能准确理解你的回答"。
- **F4 选项生成质量已具备约束**：prompt 内置种子基调块 + 已答内容 digest + 故事型护栏（L621-630：示例必须从用户已答的剧情/角色/情感线索延伸，严禁世界建构模板示例）。
- **F5 跳过 = 空串推进**：L1223-1247，"跳过"存空串、计跳过信号、进下一题；归档机制存在但无感知披露。

## §3 病理诊断（六病灶）

| # | 病灶 | 机制根源 | 与 D23 关系 |
|---|---|---|---|
| 1 | **灵感是道歉，不是服务** | F3：3 选项生成质量够、触发太晚、话术反着说（指责用户"没被理解"） | D23 外新增 |
| 2 | **好素材不被生长** | LLM 职责清单只有"提取+复述"，无"接续创作"职责——"在能大获全胜时让渡利益的人！"是人物弧光的种子，AI 只会记账不会问"那他第一次让利时失去了什么？" | D23 外新增（北极星差距 1 的体验层实证） |
| 3 | **问所有人同一个问题** | F1：静态问卷 + 全局 example，个性化零注入 | D23 外新增 |
| 4 | **跳过 = 素材丢失感** | F5：归档无感知，用户视角"我的不知道被扔了" | D23 外新增 |
| 5 | **术语黑话 + 循环解释** | 问题文案含编剧术语（执行者/张力源/走向基调），说人话整改未覆盖问题本体；"?下一项是什么？"暴露进度不透明 | D23 外新增（D21 接缝） |
| 6 | **结构化表达 vs 线性问卷** | 网状回答（主线支线互证）进单字符串队列 | 与 D23-B（层级条目）部分重叠，但根因是**问法**不是**存储**——D23 解决存得下，本文解决问得对 |

**一句话病理**：灵感机制（3 选项 + 序号直选 + 贴合上下文生成 + 故事型护栏）**已经全部存在于代码库**，但它被设计成"用户失败后的补偿路径"，而不是"用户一进来就享受的默认服务"。**方向对了，位置装反了。**

## §4 外部证据综述（2026-10-08 两轮检索）

| # | 来源 | 发现 | 对本问题的启示 |
|---|---|---|---|
| E1 | **Sudowrite Story Bible**（sudowrite.notion.site 官方指南） | Braindump 自由倾倒（"anything you want，几百字更好"）→ 每字段带 **Generate 按钮**（AI 先写一版）+ **Rewrite 按钮**（按指令改写）→ 字段依赖链（Synopsis 影响 Characters/Worldbuilding/Outline） | "问卷结构 + 生成式填充"是成熟商业范式；用户永远可以说"你先写一版我再改"——选项前置有先例 |
| E2 | **Patchwork：Intent Elicitation in Mixed-Initiative Co-Creativity**（HAI-GEN 2024） | 三设计模式：Ask Don't Guess / Refine via Examples（brainstorming 模式生成变体，用户**保留/删除即表态**）/ Gauge Creative Momentum；**question reversal——用户可把问题抛回给 AI 答**；leading questions 借自 TRPG 且允许拒绝预设 | 我们缺的不是提问技巧，是"抛回"通道与"变体即表态"的低成本交互；leading question 可直接移植 |
| E3 | **Varied Scaffolding Levels in Co-writing with LLMs**（CHI 2024，N=131 拉丁方实验） | U 型曲线：低脚手架（句子级提示）**无显著帮助**；高脚手架（段落级完整提案）**显著提升非惯常写作者**的质量与产量，代价是 ownership 温和下降 | 目标用户（爱幻想不会写的普通人）需要的是**具体完整的提案**而非 hint 提示语——hint 字段形同虚设的实证解释 |
| E4 | **Choice over Control**（CHI 2023，N=129） | 用户**显著偏好从 3 个建议中选择，胜过自己写指令**（写指令费力且中断心流）；非叙事指令主要用来"要灵感/要主题/要事实" | 3 选项是降低表达门槛的实证最优形态——我们已有此机制（F3/F4），只是藏在失败路径里 |
| E5 | **Partnering with Generative AI**（RCT，N=486 + 复验 N=640，arXiv 2510.23324） | human-led question-mode：想法质量升**且**保住多样性与归属感，用户还会主动深化（60% 大幅展开）；model-led（AI 重写）质量升但多样性/归属感双降 | "用户决定灵魂，AI 扩展可能性"有实证支撑；问法必须是激发式（reflective questions）而非审讯式 |
| E6 | **Diving into Co-Creativity**（CHI 2026） | 好奇心式措辞的建议在会话**后期更持久**（中性建议后期采纳率骤降，好奇心式稳定）；最佳时机 = 用户慢下来/到达决策点时 | 追问/扩展的切入时机 = 用户卡住时——恰好是现有 stall 位置，时机判断基础设施已在 |
| E7 | **TRPG playbook 传统**（Dungeon World SRD / Apocalypse World 2e playbooks + NPC Setup Guide / Fate Core SRD） | 角色构建 = **选择列表 + 填空混合**（DW bonds："____欠我一顿饭，还没还"填人名即成关系；AW NPC prompts：勾 1-3 条陈述填空格即成故事钩子；Fate 协作三阶段共创）；GM 提问纪律 = provocative questions（"那你觉得 Grundloch 之前见过他吗？"） | **格式即灵感**——不会创作的人会选择；选项 + 空格是最低门槛表达；带预设的追问（leading）是 TRPG 百年验证的引导技术 |

**证据合力**：E3+E4 证明"给具体选项 > 给提示语 > 让用户自己想"；E5 证明"AI 扩展 + 用户裁决 > AI 代写 > AI 审问"；E6 证明切入时机在卡壳点；E1+E2 证明商业与研究两端都有成熟交互形态；E7 提供低门槛表达格式与追问技术的直接素材库。

## §5 预设方案（三方向，互不排斥，推荐 A→B 序贯）

### 方向 A：选项前置（保守 · 快赢）

**内容**：把 suggest_examples 从"卡壳救援"提升为**默认交互**——每个问题自动附带 3 个 AI 生成的具体选项（复用现有生成逻辑：种子基调 + 已答 digest + 故事型护栏），用户可：自由输入（一等地位不变）/ 序号直选（通道已有 L1251-1280）/ "换一批" / "把 1 和 3 揉一起"。

- **改动面**：触发时机（stall≥2 → 默认每问）+ 话术基调（道歉式 → 邀请式"这里有几个方向，也可以直接说你的"）+ 生成调用编排。
- **成本控制**（关键工程点）：十五字段 × 每问 +1 次调用不可接受 → 与 `interviewer.interview` **合并为单次调用**（InterviewResult 增加 examples 字段，fills 与 examples 同 prompt 同返回）——每会话调用数不变或仅微增。
- **兼容性**：LLM 提议+用户确认 ✅（选项=提议，选择=确认，且首填自动写入先例已立）；单生产单消费 ✅；门禁计数 ✅（选项选择走 pending_suggestions 路径，与跳过/自答同权）；冲动坐标——**选项选择是否计为新信号源**为治理扩点（闭集枚举扩展，随立项登记）。
- **风险**：选项锚死想象力（E6 认知流畅性偏差）——自由输入框必须视觉平等；生成质量依赖真机调优（E0 观察项）。

### 方向 B：镜子-扩音器循环（目标形态 · 北极星同构）

**内容**：访谈哲学从"提取信息"改为三拍循环——
1. **镜子**：AI 先复述用户话里的亮点（现有"已记下"升级为有温度的反映式倾听）；
2. **扩音器**：接住素材给 3 个"如果往这边走会怎样"的具体化扩展（含 TRPG 式 leading question："那这位前辈，当年也是从让渡利益走过来的吗？"——带预设、可拒绝）；
3. **裁决**：用户挑选 / 混合 / 否决 / 自己写 / **抛回**（"你来答"——E2 question reversal，AI 给版本用户改）。

- **改动面**：interviewer prompt 职责重写（新增"反映+扩展"职责）；**单问句铁律需放宽为"单问句 + 多选项并列"**（与 D21 prompt 纪律的接缝，须随立项定盘）；guide_engine 主流程结构不变。
- **实证对齐**：E5 question-mode 保归属感且激发深化（60% 大幅展开）；北极星差距 1 落位；三拍天然规避 §6 审讯逆风（可跳过/可换/可抛回，不评分不门禁）。
- **风险**：反映式话术质量依赖真机调优；与北极星 C3（第 0 拍情感核心）合流设计待拍板（清单第 4 项）。

### 方向 C：Playbook 化（激进 · 远期观察）

**内容**：十五字段问卷改为"角色卡/剧情卡"勾选界面（AW playbook 式：勾选陈述 + 填空），AI 用已答内容滚动生成下一批陈述；对话访谈退为自由输入通道。

- **收益**：创作门槛降为选择门槛，"格式即灵感"（E7）；视觉化=进度透明（顺带治病灶 5）。
- **风险**：前端新交互范式 + 与 D23 AnswerNode 层级树、两阶段生命周期（预设→自由流程）架构耦合——**不宜近期动**；记入北极星候选池观察即可。

### 推荐路径

**A 先行（地基，快赢，本周量级）→ B 为目标形态（A 的选项就是 B 的第三拍，A→B 不返工）→ C 远期观察。** 三方向均不动 v0.5 三铁律与配方边界（D19）。
