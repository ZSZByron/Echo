## §1 设计定盘（施工级，锁死）

### 1.1 触发键
JSON schema 行（interviewer.py L593）追加 `"knowledge_request": false,`。独立于 `user_confused`（语义诚实：求知识 ≠ 听不懂）。旧解析器忽略未知键向前兼容（D20 worldview_invites 先例）。

### 1.2 规则 6.5 文案（插入规则 6 之后、规则 7 之前）
```
"6.5 知识求助判定（优先于规则 6 的提问分支）：如果用户向你提出"
"领域事实性/知识性问题——期待你提供资料来帮他写故事，而不是在"
"回答当前问题（如「精神病院里腕带代表什么」「当前最受欢迎的"
"现代小说女性主角职业是什么」）：置 knowledge_request=true，"
"并给出一个用于联网检索的中文 search_query（概括用户想知道的"
"知识点）。此时 fills 必须留空、user_confused=false——严禁把"
"用户的提问内容当作任何字段的答案记录。",
```

### 1.3 知识对话态状态机（引擎层，guide_engine）
字段（A1Session，L316 区域 dataclass additive）：
```python
knowledge_thread_active: bool = False
knowledge_thread_turns: int = 0
```
- **置位**：本轮 interview 后 `knowledge_request=true` 且搜索 reference 非空 → `active=True, turns=1`。reference 为空（降级/断网）→ **不置位**（没搜到就不装知识态，行为回落现状）。
- **冻结**：`active=True` 时本轮 interview 返回的 fills **一律丢弃**，`log_event(session_id, "knowledge_freeze", dropped=len(fills), turns=...)` 留痕。
- **退出（任一，确定性）**：①直选通道命中（guide_engine L1298+ 分支）→ 复位后正常直选；②「跳过」→ 复位后常规跳过；③`turns > 3` 强制复位（防卡死）；④本轮 `knowledge_request=false` 且 fills 空 → 复位（话题自然离开）。
- **保持**：本轮 `knowledge_request=true` → `turns += 1`。`user_confused` 轮不影响知识态（独立通道互不干扰）。

### 1.4 二段式知识分支（interviewer，L332 块旁同构新增）
`raw.get("knowledge_request")` → `search_sync(query)` → 注入头 `【联网检索参考资料】（用于回答用户的知识提问）` → 重写指令：`基于上述资料重写 guidance_reply：先用一两句有据的话直接回答用户的知识问题，再给2-3个贴合种子基调的创作选项，最后自然引回当前问题。保持其余字段语义不变。` → 二次 chat_json → 覆盖 raw（同 L361-362 模式）。

### 1.5 披露尾注（引擎层）
knowledge_request 二次生成成功且 reference 非空 → api_response 组装处 `reply = reply + "\n（已联网查证）"`。**user_confused 通道不加**（存量行为零扰动；两通道统一尾注留二期）。

```python
"""D24 T1: web_search 契约测试——降级契约 + 新端点形状（锁定 2026-10-09 修复）。"""
import httpx
import pytest

from app.ai import web_search


class _StubResp:
    def __init__(self, payload, status=200):
        self._payload = payload
        self.status_code = status

    def raise_for_status(self):
        if self.status_code >= 400:
            raise httpx.HTTPStatusError("err", request=None, response=None)

    def json(self):
        return self._payload


class _StubClient:
    """捕获 payload 并回放 stub 响应。"""
    resp = None
    captured = None

    async def __aenter__(self):
        return self

    async def __aexit__(self, *a):
        return False

    async def post(self, url, headers=None, json=None):
        type(self).captured = {"url": url, "headers": headers, "json": json}
        if isinstance(self.resp, Exception):
            raise self.resp
        return self.resp


def _run(monkeypatch, key="k" * 49, resp=None, exc=None):
    monkeypatch.setenv("ZHIPU_API_KEY", key)
    if exc is not None:
        _StubClient.resp = exc
    else:
        _StubClient.resp = resp
    monkeypatch.setattr(httpx, "AsyncClient", lambda **kw: _StubClient())
    return web_search.search_sync("精神病院 腕带 作用")


def test_missing_key_returns_empty(monkeypatch):
    monkeypatch.delenv("ZHIPU_API_KEY", raising=False)
    assert web_search.search_sync("任何") == ""


def test_http_error_degrades_to_empty(monkeypatch):
    assert _run(monkeypatch, exc=httpx.ConnectError("boom")) == ""


def test_empty_results_return_empty(monkeypatch):
    assert _run(monkeypatch, resp=_StubResp({"search_result": []})) == ""


def test_uses_new_endpoint_and_payload(monkeypatch):
    digest = _run(monkeypatch, resp=_StubResp(
        {"search_result": [{"title": "腕带", "content": "身份识别"}]}))
    cap = _StubClient.captured
    assert cap["url"] == "https://open.bigmodel.cn/api/paas/v4/web_search"
    assert cap["json"]["search_query"] == "精神病院 腕带 作用"
    assert cap["json"]["search_engine"] == "search_std"
    assert cap["headers"]["Authorization"].startswith("Bearer ")
    assert digest == "- 腕带：身份识别"


def test_digest_caps_at_five(monkeypatch):
    items = [{"title": f"t{i}", "content": f"c{i}"} for i in range(7)]
    digest = _run(monkeypatch, resp=_StubResp({"search_result": items}))
    assert len(digest.splitlines()) == 5
```
