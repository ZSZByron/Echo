## 0. 概念澄清（本次设计的地基）

| 概念 | 归属 | 语义 |
|---|---|---|
| **主剧情（M6.主剧情）** | M6 历史时间线 | **不变**——世界观历史发展脉络，大背景层（"当前时代的主剧情线"=历史正在发生什么） |
| **细节剧情（M12，本次新建）** | 故事侧采集模块 | **具体的故事内容**：开场事件、当下抉择、情节张力、线索走向——用户"想看故事开场/想写感情故事"冲动的直接落点 |
| **场景（M13，A3 提取）** | 产出模块 | 故事/世界的内容切片容器（Scene 实体），下游扩写 |
| **资产管线（M14，A3 提取）** | 产出模块 | 场景/视觉资产的生产流水线（状态机+审核） |

> 一句话：**M6 是"世界曾经/正在发生什么"（背景板），M12 是"主角的这段故事怎么走"（前景戏）**。E1-Lite 翻车的根因正是只有背景板没有前景戏——故事用户被按在历史纪元问卷上。

## 6. 种子调用模块（seed_invoker）与种子品类扩容（2026-09-22 补）

### 6.1 必需模块 vs 可选模块——性质区分（产品方裁决原义）

> **其他模块是必需的，种子模块不是必须——它只为节省时间，让用户快速找到一个原型、快速进入创作状态。**

| 维度 | M1-M12 采集模块 | seed_invoker 种子服务 |
|---|---|---|
| 性质 | **必需**：配方组成，门禁计数对象 | **可选**：纯提效服务，全程可不出现 |
| 采集字段 | 有（问卷字段） | 零——不采集任何字段 |
| 门禁 | 参与（配方内全达标） | 不参与 |
| 不用会怎样 | 世界缺这块内容，图谱空洞 | 无任何损失——用户自己从零讲，一样走完全程 |
| 用了会怎样 | （本来就要答） | 省时：基底预填静默生效（【基】/【抽】），用户只讲增量 |
| 注册类型 | `ModuleDef(level=L1)` | `service`（module_registry 新类目，非问卷模块） |

### 6.2 种子品类扩容：现实类三形态

| 形态 | 分歧度 | 例 |
|---|---|---|
| 纯现实（一模一样） | 零——基底=现实常识全预填，用户只讲故事 | 90 年代上海恋爱 / 现代刑侦 |
| 魔改现实 | 一个分歧点 | 1946 停战破裂 |
| 平行世界 | 一套隐藏规则 | 现代都市+隐秘超自然 |

机制：现实基底包（预制常识数据，**确定性非 LLM**）+ M10 preset"基底锁定"第三态 + field_sources 增 `baseline_prefill` 来源。

### 6.3 seed_invoker 交互设计（对话中氛围提案）

- **触发**：显式=配方走到氛围字段（M1 类型/M7 视觉）；隐式=用户输入薄（说不清单问后/skip 首问）时提前
- **提案**：确定性语境匹配器（冲动类型+custom_idea+已答字段 × 种子目录含现实类）→ 2-3 个近邻例子 + 纯现实选项；**匹配是查表代码不是 LLM，零等待**
- **剧本**："要不要给你几个现成的起点？①群星彼岸（冷峻太空歌剧）②碳末纪 2050（气候重建）③纯现实基底（就在现代都市讲你的故事）——选一个，或者继续说你的"
- **纪律**：选中→预填静默生效对话不断；拒绝→永不复问（记 open_question）；疗愈/怀旧不触发；原种子页退役为"我想直接挑"高级入口
