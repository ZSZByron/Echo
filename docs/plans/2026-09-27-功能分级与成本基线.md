# 功能分级与成本基线（必须 / 提升 / 定制 三级）

> **日期**: 2026-09-27 ｜ **性质**: 产品/成本分析基线（预注册式写定）
> **触发**: 产品方指令「对当前提供给用户的一切功能进行成本推断，分必须/提升/定制三级」+「落成一个文档」。
> **分级定义（产品方原话，2026-09-27）**：
> - **必须级** —— 流程上必须有，要不然体验不完全；
> - **提升级** —— 有了体验才完整，没了也不会惹恼免费人群；
> - **定制级** —— 有了体验提升极大（瀑布与水龙头的区别），但完全是增量定制，不影响主题体验。
>
> **成本口径（重要声明）**：数字为**推断估算**，基于 ①deepseek-v4-flash 文本档价格假设 ②每会话 ≈80 轮访谈 + 1 次定稿基准 ③图像 = 万相档 ④D21 在建功能按设计成本模型推算。**非实测**——E0 telemetry 真实数据回收后校准（本表为预期基线，偏离 = 复核信号，同动机占比基线纪律）。AI 生成数值须人工验证后方可用于定价决策。

## 一、必须级（流程缺了它，体验断裂）

| 功能 | 成本机制 | 每会话成本（估） | 状态 |
|---|---|---|---|
| 冲动卡选择 + 配方路由 | 纯查表（session/start 落定配方） | **¥0** | ✅ 已有（主次切换=在建 D21⑦） |
| 引导式访谈对话 | 每轮 1 次 LLM 调用（interviewer chat_json）——**产品本体的边际成本就是它** | **¥0.3~0.6** | ✅ 已有 |
| fills 填空建议 | 合并在同一轮调用内，零边际调用 | ≈¥0 | ✅ 已有 |
| 定稿门禁 + graphify 图谱编译 + 图谱页 | 每会话 1 次 graphify + 确定性装配 | **¥0.05~0.1** | ✅ 已有 |
| 真值闸 / 诚实降级 / 警告账本 | 纯代码 | ¥0 | ✅ 已有 |
| 重定稿 + stale 血缘传播 | 纯代码 | ¥0 | ✅ 已有 |
| 收尾触发双条件检测（配方问完+fills 清零） | 纯代码盘点 | ¥0 | 🟡 D21⑧ 在建 |

**小计 ≈ ¥0.4~0.7/会话。** 特征：成本全部集中于「对话」一件事，其余近乎免费。

## 四、汇总账

```
免费完整体验（必须级 + 提升级基础部分）   ≈ ¥0.5~1 /会话
                                       ↓ 全开
对齐循环全套（摘要+推测卡+循环编译）      ≈ ¥1~2 /会话
                                       ↓ 按需定制（用量计费候选区）
视觉生成 + 深度循环 + 大规模代填 + 语义匹配  ¥1~3+ /会话
```

## 五、战略结论（三条）

1. **成本结构天生适合免费模式**：核心体验（对话+图谱+文档）压在 ¥1 以内，确定性件占功能数量大头——「LLM 只做判断题 + 确定性打底」哲学的自然结果；
2. **付费墙的位置自己长出来了**：图像生成（物理上贵）+ 用量型功能（循环深度/代填量/语义匹配）——全部符合定制级定义「增量定制、不影响主题体验」；
3. **现成的收费杠杆**：**LLM 导语层 vs 确定性骨架**——同一产物双版本（免费=干净骨架，付费=文笔版），零开发成本的价格分层，主模组与 D22 三件全部适用。
