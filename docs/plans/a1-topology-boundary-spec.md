# A1 世界观IP设计 — 拓扑边界规格书

> **版本**: v0.1
> **日期**: 2026-08-14
> **定位**: 将厂家世界观设计树转化为 A1 结构拓扑定义
> **关联**: `2-A1-v0.2-6维约束体系×6层生成维度.md` §6.4, `3_knowledge-assets.md` §5 边类型词典 v0.1

---

## 0. 核心原则

**A1 定义的是拓扑，不是描述。**

| 错误做法（普通描述） | 正确做法（拓扑定义） |
|---|---|
| "这个世界有魔法" | `Concept(POWER_SYSTEM)` –`POWER_SATURATES_GEO`→ `Geography(高魔区)` |
| "大陆在地表" | `Geography(SKY_LAYER)` –`GEO_ABOVE`→ `Geography(SURFACE)` |
| "神创造了世界" | `Concept(PHILOSOPHY)` –`RULE_SHAPES_GEO`→ `Geography(主世界)` |
| "势力A和势力B打仗" | `Faction(A)` –`FACTION_OPPOSES`→ `Faction(B)` |

**转化规则**：每一条世界观设定，必须能回答以下三个问题之一（否则不构成拓扑定义）：

1. **节点关系**：谁→（什么边）→谁？映射到边类型词典 v0.1 的哪一种？
2. **边界约束**：什么被锁定为不可覆写常量？A2/A3 不能改什么？
3. **拓扑维度**：这个设定对应力量体系拓扑/地理拓扑/时间线拓扑的哪个维度？

## 1. A1 产出物清单

### 1.1 骨架节点（5 种实体，创建后不可变）

| 实体类型 | 来源模块 | detail_level | 粒度 |
|---------|---------|-------------|------|
| **Geography** | 模块4(地理空间) + 模块2/3 推导 | CONCEPT | 结构级：宇宙学下位→主世界→地区→区域（不细化到地点以下） |
| **Faction** | 模块5(文明与社会) | CONCEPT | 结构级：势力+意识形态+领地关联 |
| **Event** | 模块6(历史时间线) | CONCEPT | 结构级：关键节点+因果链（不包含支线/平行剧情） |
| **Concept** | 模块2(世界本体) + 模块3(力量体系) | CONCEPT | 结构级：力量体系/宇宙学/哲学/其他 |
| **Constraint** | 模块9(AI生成边界) + 6维约束编译 | CONCEPT | 结构级：LAW/RED/SOC等不可违反常量 |

### 1.2 结构拓扑边（15 种，不可覆写常量）

> 详见 `3_knowledge-assets.md` §5.2 边类型清单 v0.1

| 类别 | 边类型数 | A1 独有 | A1+ 可建 |
|------|---------|---------|---------|
| 第1类：地理层内部关系 | 4 | `GEO_ABOVE`, `GEO_BELOW` | `GEO_CONTAINS`, `GEO_BORDERS` |
| 第2类：规则/力量→地理（因果链） | 3 | `RULE_SHAPES_GEO`, `POWER_SATURATES_GEO`, `POWER_SOURCES_FROM_GEO` | — |
| 第3类：地理→势力/事件（跨层投影） | 3 | — | `GEO_SEPARATES`, `GEO_NOURISHES`, `GEO_HOSTS_EVENT` |
| 第4类：势力/事件/概念层内部关系 | 5 | `CONCEPT_MANIFESTS_AS` | `FACTION_ALLIED`, `FACTION_OPPOSES`, `EVENT_CAUSED_BY`, `CONSTRAINT_LIMITS` |
| **合计** | **15** | **6 种仅 A1** | **9 种 A1+** |

### 1.3 A1 不产出（边界外）

| 内容 | 归属 | 理由 |
|------|------|------|
| 地点分区（功能/空间/边界/管理4维度） | A2 | 区域内功能填充，非结构拓扑 |
| 场景细节（景观/物质/生境/人文4维度） | A3 | PC 实际经过的空间样貌，具体实体填充 |
| 地点设计（几何区位/层级地位/流动网络/功能分工） | A2/A3 | 具体区划指标，非宏观拓扑 |
| 平行剧情 / 主剧情的支线 | A2/A3 | 运行时扩展，A1 只锁主线骨架 |
| 文明经济结构变化（新型/维持政治体系） | A2 | 区域文化层面动态 |

## 2. 模块逐一拓扑化

---

### 模块①：IP定位

#### 2.1.1 节点定义

| 设定项 | 节点类型 | 属性 | 拓扑语义 |
|--------|---------|------|---------|
| 名称 | — | `EntityNode.name` | 世界唯一标识，不可重命名 |
| 概念(哲学+剧情+冲突) | — | `WorldSchema.concept` | 编译为所有下游节点的生成约束根 |
| 类型(力量+物质+哲学) | — | `WorldSchema.world_type` | 决定 6×6 权重矩阵的初始偏移 |
| 核心体验(主要行为+目标) | — | `GameplayAnchor.core_loop` | 约束 Campaign 层叙事走向 |

#### 2.1.2 边界声明（不可改变范围）

```
IP定位 → 所有字段标记 source_stage="A1"
  ├─ 不可重命名、不可修改概念、不可修改类型
  ├─ 核心体验锁定为 GameplayAnchor 的常量种子
  └─ A2/A3 可引用但不可覆写
```

#### 2.1.3 拓扑约束

- 概念中的"哲学"部分 → 映射到模块②的 `Concept(PHILOSOPHY)` 节点
- 概念中的"剧情"部分 → 映射到模块⑥的 Event 因果链起点
- 概念中的"冲突"部分 → 映射到模块⑤的 `FACTION_OPPOSES` 边

### 模块②：世界本体

#### 2.2.1 节点定义

| 设定项 | 节点类型 | concept_type | 拓扑语义 |
|--------|---------|-------------|---------|
| 来源：起源力量 | `Concept(OTHER)` | — | 起源力量是所有因果链的根节点（无 caused_by 上游） |
| 来源：起源时间线 | — | — | 编译为模块⑥ Event 图的时间轴原点 |
| 存在物：力量体系 | `Concept(POWER_SYSTEM)` | — | 通过 `POWER_SATURATES_GEO` / `POWER_SOURCES_FROM_GEO` 连接 Geography |
| 存在物：宇宙学 | `Concept(COSMOLOGY)` | — | 通过 `CONCEPT_MANIFESTS_AS` 连接 Geography |
| 存在物：哲学思想 | `Concept(PHILOSOPHY)` | — | 预示世界走向，编译为 Constraint(CORE) 约束所有下游 |
| 存在物：其他 | `Concept(OTHER)` | — | 有影响但非3类的生灵/规则/物质/存在 |
| 现实规则：意志主导 | `Constraint(LAW)` | — | 约束：现实规则=意志扭曲物质，拓扑形态动态可变 |
| 现实规则：物质主导 | `Constraint(LAW)` | — | 约束：现实规则=物质法则刚性，拓扑形态稳定不可变 |

#### 2.2.2 结构拓扑边（A1 独有）

| 边类型 | 源→目标 | 拓扑语义 |
|--------|--------|---------|
| `RULE_SHAPES_GEO` | `Constraint(LAW)` → `Geography` | 物理法则塑造地形（如：高重力→扁平大陆） |
| `POWER_SATURATES_GEO` | `Concept(POWER_SYSTEM)` → `Geography` | 力量体系渗透地理（如：元素魔法→元素浓度带） |
| `CONCEPT_MANIFESTS_AS` | `Concept(COSMOLOGY)` → `Geography` | 宇宙学具现为地理（如：位面结构→传送门节点） |

#### 2.2.3 边界声明

```
世界本体 → source_stage="A1"，创建后不可变
  ├─ 起源故事 → 锁定为 Event 因果链的根，A2/A3 不可新建"更早的起源"
  ├─ 现实规则(意志/物质主导) → 锁定 Constraint(LAW, CORE)，约束所有力量体系交互
  ├─ 哲学思想 → 锁定为世界走向的终极约束，结局必须验证或挑战它
  └─ A2/A3 不可新建 RULE_SHAPES_GEO / CONCEPT_MANIFESTS_AS 边
```

#### 2.2.4 拓扑维度检查

- [ ] 起源力量是否有明确的因果链下游？（起源→力量体系→地理）
- [ ] 现实规则（意志/物质）是否编译为 Constraint 并影响所有 LAW 层权重？
- [ ] 哲学思想是否映射到模块⑥的结局约束？

### 模块③：力量体系

#### 2.3.1 节点定义

力量体系本身是一个 `Concept(POWER_SYSTEM)` 节点，但其内部结构通过拓扑维度定义：

| 力量子系统 | 编译为 | 拓扑语义 |
|-----------|--------|---------|
| 力量本体定义（意识体/物理背景/特殊环境/科技） | `Concept(POWER_SYSTEM).attributes.source_type` | 决定力量是"有限资源"还是"无限资源" |
| 力量来源底层（意志/物质） | `Constraint(LAW)` | 约束：力量必须遵循物质或意志逻辑 |
| 力量影响比例（本体资质 vs 外界刺激） | — | 编译为权重矩阵中 LAW vs ACT 的初始偏移 |

#### 2.3.2 四维拓扑映射（核心转化）

用户设计树中的4个拓扑维度，每个必须编译为具体的边或约束：

**维度1：溯源维度（能量来源）**

| 设定 | 编译为 | 边/约束 |
|------|--------|--------|
| 力量体系（能量本源）↔ 世界本体（起源/宇宙学） | 能量流动拓扑 | `POWER_SOURCES_FROM_GEO`（力量源于地理）或 `Concept → Concept` 依赖 |
| 起源=神创 → 力量=神性馈赠 | 自上而下单向流 | `Concept(ORIGIN)` → `Concept(POWER_SYSTEM)` → `Geography`（单向链） |
| 起源=虚空诞生 → 力量=环境汲取 | 环境到个体内聚流 | `Geography` → `Concept(POWER_SYSTEM)`（反向依赖） |
| 宇宙学节点是否是力量高产点 | 节点控制拓扑 | `POWER_SATURATES_GEO`：`Concept(POWER_SYSTEM)` → 关键 Geography 节点 |

**维度2：载体维度（阶层分化）**

| 设定 | 编译为 | 边/约束 |
|------|--------|--------|
| 力量获取（学习/觉醒/仪式/科研） | 获取拓扑 | `Constraint(ACT)`：定义技能检定方式和门槛 |
| 封闭拓扑（精英统治，稀有难掌握） | 权限映射 | `Constraint(SOC, CORE)`：力量获取门槛=高，A2/A3 不可降低门槛 |
| 开放拓扑（众生平等，普及低门槛） | 权限映射 | `Constraint(SOC, CORE)`：力量获取门槛=低，A2/A3 不可提高门槛 |
| 存在物差异决定力量分布 | 层级拓扑 | `Concept(POWER_SYSTEM)` 通过 `CONCEPT_MANIFESTS_AS` 映射到不同物种分布 |

**维度3：机制维度（交互法则）**

| 设定 | 编译为 | 边/约束 |
|------|--------|--------|
| 物质主导→等价交换（消耗物质产生效果） | 交互拓扑（守恒） | `Constraint(LAW)`：力量交互遵循守恒律 |
| 意志主导→唯心投射（消耗精神扭曲现实） | 交互拓扑（非守恒） | `Constraint(LAW)`：力量交互不遵循守恒律 |
| 科技规则 vs 魔法规则互斥 | 排他性拓扑 | `Constraint(LAW)`：互斥规则对，A2/A3 必须遵守互斥约束 |

**维度4：代价维度（平衡约束）**

| 设定 | 编译为 | 边/约束 |
|------|--------|--------|
| 承载能力 vs 操作能力的关系 | 平衡拓扑 | `Constraint(ACT)`：代价=承载差值的函数 |
| 力量使用过度→变异/非人化 | 反馈回路 | `Constraint(WST)`：力量滥用触发状态变更（buff/debuff） |
| 残酷物理→代价=肉体损耗 | 代价映射 | `Constraint(LAW)`：代价类型=物理/生命 |
| 善恶二元→代价=精神腐蚀 | 代价映射 | `Constraint(SOC)`：代价类型=道德/精神 |

#### 2.3.3 边界声明

```
力量体系 → source_stage="A1"
  ├─ 4个拓扑维度的选择 → 编译为 Constraint(LAW/ACT/SOC/WST) 不可覆写常量
  ├─ 力量来源类型 → 锁定，A2/A3 不可引入新力量来源
  ├─ 获取拓扑（开放/封闭）→ 锁定门槛方向，A2/A3 不可逆转
  ├─ 交互拓扑（守恒/非守恒）→ 锁定，A2/A3 不可违反
  └─ 代价机制 → 锁定代价类型，A2/A3 可增加具体代价项但不可移除代价
```

### 模块④：地理空间

> **切割声明**：A1 只产出地理结构拓扑（骨架节点 + 结构边）。地点分区/场景细节/地点设计归 A2/A3。

#### 2.4.1 A1 产出的地理层级（骨架节点）

```
A1 地理拓扑层级（严格到此为止）
  └─ 主世界 (Geography, CONCEPT)
      └─ 地区 (Geography, CONCEPT)      ← A1 到此为止
          └─ 区域 (Geography, CONCEPT)   ← A1 到此为止
              └─ [地点以下 → A2 分区 → A3 场景]
```

| 层级 | A1 产出 | A2 产出 | A3 产出 |
|------|---------|---------|---------|
| 主世界 | ✅ 结构拓扑 + 法则绑定 + 垂直层级 + 位面连接 | ❌ | ❌ |
| 地区 | ✅ 结构拓扑 + 文明位阶 + 叙事权重 + 法则同调 | ❌ | ❌ |
| 区域 | ✅ 结构拓扑（核心-边缘/网络连接） | ✅ 功能分工填充 | ❌ |
| 地点 | ❌ | ✅ 分区设计（4维度） | ✅ 场景细节（4维度） |

#### 2.4.2 结构拓扑边

| 设定 | 边类型 | 拓扑语义 |
|------|--------|---------|
| 大陆包含区域 | `GEO_CONTAINS` | `Geo(CONTINENT)` → `Geo(REGION)` |
| 区域邻接 | `GEO_BORDERS` | `Geo(A)` ↔ `Geo(B)` |
| 天空层在地表之上 | `GEO_ABOVE` | `Geo(SKY_LAYER)` → `Geo(SURFACE)` — **仅 A1** |
| 地下世界在地表之下 | `GEO_BELOW` | `Geo(UNDERGROUND)` → `Geo(SURFACE)` — **仅 A1** |
| 物理法则塑造地形 | `RULE_SHAPES_GEO` | `Constraint(LAW)` → `Geography` — **仅 A1** |
| 力量渗透地理 | `POWER_SATURATES_GEO` | `Concept(POWER_SYSTEM)` → `Geography` — **仅 A1** |
| 力量源于地理 | `POWER_SOURCES_FROM_GEO` | `Concept(POWER_SYSTEM)` ← `Geography` — **仅 A1** |

#### 2.4.3 主世界设计的4维度（全部 A1 结构常量）

| 维度 | 设定项 | 编译为 | 拓扑语义 |
|------|--------|--------|---------|
| **架构维度** | 结构形态（浮岛/同心球/世界树...） | `Concept(COSMOLOGY).attributes.structure` | 定义 Geography 节点的 vertical_layer 枚举范围 |
| **架构维度** | 边界（有限/无限，内/外） | `Constraint(LAW, CORE)` | 世界边界的不可逾越性约束 |
| **法则维度** | 能量来源位置 | `POWER_SOURCES_FROM_GEO` 边 | 力量从哪里来→地理哪里是高势能区 |
| **法则维度** | 神权架构（神是否真实存在/干预程度） | `Constraint(LAW)` + `Concept(PHILOSOPHY)` | 约束模块⑤的势力类型和模块⑥的事件因果 |
| **法则维度** | 生死规则（灵魂去向） | `Constraint(LAW)` | 约束所有涉及死亡的 Event 和 ACT 判定 |
| **位面维度** | 位面拓扑（主世界与哪些位面接壤） | `GEO_BORDERS`（跨位面）或 `GEO_CONTAINS` | 定义跨界旅行路径的拓扑结构 |
| **位面维度** | 传送门机制 | `GEO_CONTAINS` 跨层边 | 定义"宇宙级港口"超级节点 |
| **位面维度** | 位面共振（区域与位面锚定） | `POWER_SATURATES_GEO` | 共振区=高魔/高科技区 |
| **纪元维度** | 创世阶段（初生/暮年） | `Concept(PHILOSOPHY).attributes.era_stage` | 约束模块⑥时间线走向 |
| **纪元维度** | 循环机制（线性/循环/大灾变） | `Concept(PHILOSOPHY).attributes.time_mode` | 约束 Event 因果链的拓扑形态（链/环/断裂） |

#### 2.4.4 宇宙级拓扑检查（A1 必须完成）

- [ ] 能量流动检查：力量源头 ↔ 地理核心区是否对应？
- [ ] 位面渗透检查：邪恶位面入口 ↔ 附近区域政治格局是否反映危机？
- [ ] 文明神权一致性检查：地面宗教建筑 ↔ 宇宙观中神明属性是否一致？

#### 2.4.5 地区设计的4维度（全部 A1 结构拓扑）

| 维度 | 设定项 | 编译为 | 拓扑语义 |
|------|--------|--------|---------|
| **行星地理格局** | 纬度地带性（热/温/寒） | `Geography.attributes.climate_zone` | 约束区域生态和资源类型 |
| **行星地理格局** | 海陆分布（世界岛/孤悬大陆/大洋孤岛） | `GEO_BORDERS` 拓扑密度 | 世界岛=高连通性，孤岛=低连通性 |
| **文明演化位阶** | 原生/次生/边缘文明 | `Faction.attributes.origin_type` | 约束势力间的文化等级关系 |
| **文明演化位阶** | 支配/挑战者/被遗忘 | `FACTION_OPPOSES` / `FACTION_ALLIED` 边密度 | 支配者vs挑战者=对立边密度高 |
| **叙事承载权重** | 主线舞台/后勤区/探索区/禁区 | `Geography.attributes.narrative_role` | 约束 Campaign 层的剧情分配权重 |
| **法则同调程度** | 高魔/低魔/法则破碎区 | `POWER_SATURATES_GEO` 边的强度值 | 高魔区=力量势能高节点，破碎区=约束冲突区 |

#### 2.4.6 区域设计的4维度（A1 锁定拓扑关系，A2 填充分工）

| 维度 | A1 锁定（结构拓扑） | A2 填充（区域内部） |
|------|---------------------|-------------------|
| **核心-边缘** | 区域间的 `GEO_BORDERS` + 核心区/边缘区/过渡区标注 | ❌ 不修改区域间关系 |
| **系统分工** | 区域的 `narrative_role`（增长极/资源腹地/生态屏障/战略储备） | ✅ 区域内具体产业分工 |
| **网络连接** | 区域间的连通性拓扑（枢纽/桥头堡/终端） | ✅ 区域内交通网细节 |
| **发展梯度** | 区域的发展阶段标注（高/中/低/衰退） | ✅ 区域内具体发展阶段细节 |

#### 2.4.7 特殊地理

| 设定 | 编译为 | 边界 |
|------|--------|------|
| 塑造规则 ID 列表 (shaping_rules) | `RULE_SHAPES_GEO` 边的源 Constraint ID | 仅 A1，A2/A3 不可新建 |

### 模块⑤：文明与社会

#### 2.5.1 节点定义

| 设定项 | 节点类型 | 属性 | 拓扑语义 |
|--------|---------|------|---------|
| 核心价值（意识形态） | `Faction.ideology` | — | 锁定势力行为逻辑根 |
| 力量资源 | `Faction` ↔ `Concept(POWER_SYSTEM)` | `CONSTRAINT_LIMITS` 边 | 谁能使用什么力量 |
| 自然资源 | `Faction.territory_geo_ids` | `GEO_NOURISHES` 边 | 势力←地理滋养 |
| 经济（力量物质化部分） | `Constraint(SOC)` | — | 约束：经济结构=力量体系映射 |
| 政治 | `Constraint(SOC, CORE)` | — | 锁定政治类型，与力量获取拓扑一致 |
| 冲突（势力间关系） | 边 | `FACTION_OPPOSES` / `FACTION_ALLIED` | 势力拓扑的核心结构 |

#### 2.5.2 冲突类型→边映射

| 冲突类型 | 编译为边 | 拓扑语义 |
|---------|---------|---------|
| 资源争端 | `FACTION_OPPOSES` + `GEO_NOURISHES`（争夺同一地理） | 两个势力竞争同一资源源 |
| 信仰争端 | `FACTION_OPPOSES` + `CONSTRAINT_LIMITS`（宗教约束冲突） | 信仰体系互斥 |
| 种族争端 | `FACTION_OPPOSES` + `CONCEPT_MANIFESTS_AS`（物种差异） | 存在物差异导致对立 |
| 文化争端 | → A2 `CULTURE_INFLUENCES` | A1 只锁定阵营对立，文化细节由 A2 填充 |
| 权利争端 | `FACTION_OPPOSES` | 直接权力对立 |
| 特殊争端 | `FACTION_OPPOSES` + `CONSTRAINT_LIMITS` | 世界观特殊规则导致 |

#### 2.5.3 边界声明

```
文明与社会 → source_stage="A1"
  ├─ 势力(Faction)骨架节点 → 不可变
  ├─ 势力间关系边(FACTION_OPPOSES/ALLIED) → 不可覆写结构常量
  ├─ 政治类型 → 锁定 Constraint(SOC, CORE)，与力量获取拓扑一致
  ├─ 经济结构=力量体系映射 → 锁定，A2 不可引入与力量体系矛盾的经济
  └─ 文化争端细节 → A2 填充
```

### 模块⑥：历史时间线

#### 2.6.1 节点定义

| 设定项 | 节点类型 | 属性 | 拓扑语义 |
|--------|---------|------|---------|
| 长度（时间跨度） | — | 编译为 Event 图的时间轴范围 | 约束所有 Event 的 era 分布 |
| 关键节点 | `Event` | `severity`: COSMIC/MAJOR/REGIONAL/MINOR | 骨架事件节点 |

| 关键节点.涉及势力 | `Event.involved_faction_ids` | 关联 Faction 节点 | 事件锚定到势力拓扑 |
| 关键节点.因果上游 | `EVENT_CAUSED_BY` 边 | `Event` ← `Event` | 事件因果链 |
| 事件图（因果链） | 边 | `EVENT_CAUSED_BY` 拓扑 | 有向无环图（线性时间）或环（循环时间） |

#### 2.6.2 主剧情的4维拓扑映射

| 维度 | 设定 | 编译为 | 拓扑语义 |
|------|------|--------|---------|
| **驱动维度（起源回响）** | 剧情开端是对起源的"触发" | Event 因果链起点 → `Concept(ORIGIN)` | 起源→事件链根→因果传播 |
| **驱动维度** | 意志主导→转折靠信念/牺牲 | `Constraint(NAR)` | 叙事约束：转折点机制=精神类 |
| **驱动维度** | 物质主导→转折靠资源/科技 | `Constraint(NAR)` | 叙事约束：转折点机制=物质类 |
| **代理维度（意志载体）** | 主角/反派=存在物的极端样本 | `Concept → Faction` 的具现 | 角色模板锚定到存在物类型 |
| **代理维度** | 势力强弱=力量体系分布 | `FACTION_OPPOSES` 边权重 | 力量高势能节点=剧情主导者 |
| **舞台维度（空间映射）** | 决战发生在拓扑敏感点 | `GEO_HOSTS_EVENT` → 关键 Geography | 事件锚定到位面通道/天险等 |
| **舞台维度** | 地图现状=剧情投影 | `RULE_SHAPES_GEO`（古代大战→地形改变） | 历史事件解释地理异常 |
| **归宿维度（哲学闭环）** | 结局验证/挑战哲学 | `Concept(PHILOSOPHY)` ↔ 最终 Event | 哲学=结局约束 |
| **归宿维度** | 循环论→新轮回开始 | Event 图拓扑=环形 | 因果链形成闭环 |
| **归宿维度** | 虚无主义→不可避免衰败 | Event 图拓扑=熵增链 | 因果链单向衰败 |

#### 2.6.3 边界声明

```
历史时间线 → source_stage="A1"
  ├─ 主剧情 Event 骨架 → 不可变
  ├─ 事件因果链(EVENT_CAUSED_BY) → 不可覆写结构常量
  ├─ 主剧情4维映射 → 编译为 Constraint(NAR/ACT)，锁定叙事走向
  ├─ 平行剧情 → A2/A3 运行时扩展（不可修改主线因果链）
  └─ 主剧情的支线 → A2/A3 运行时扩展
```

### 模块⑩：骰子设定

#### 2.10.1 定位

骰子设定是**力量体系→游戏机制的映射框架**，属于 A1 的规则定义层（不是运行时执行层）。

#### 2.10.2 五维拓扑映射（每个维度编译为不可覆写约束）

| 映射维度 | 设定（世界本体侧） | 编译为（机制侧） | 约束类型 |
|---------|------------------|----------------|---------|
| **现实规则→概率分布** | 意志主导→高不确定性 | 线性分布（d20/d100） | `Constraint(LAW)`：骰子分布=线性 |
| **现实规则→概率分布** | 物质主导→稳定性 | 钟形曲线（3d6/4dF） | `Constraint(LAW)`：骰子分布=钟形 |
| **力量来源→骰子数量** | 本体（天赋/血脉）→固定能力值 | 固定骰子（d20+修正） | `Constraint(ACT)`：骰子模式=固定骰 |
| **力量来源→骰子数量** | 客体（环境汲取）→可变能量储备 | 骰池机制 | `Constraint(ACT)`：骰子模式=骰池 |
| **获取方式→判定方式** | 封闭拓扑（精英学习/觉醒） | Roll-under | `Constraint(ACT)`：判定方向=below |
| **获取方式→判定方式** | 开放拓扑（科研/工具） | Roll-over | `Constraint(ACT)`：判定方向=over |
| **玩法行为→成功判定** | 战斗/冒险→快节奏 | 二元判定 | `Constraint(NAR)`：判定层次=二元 |
| **玩法行为→成功判定** | 研究/调查→细节叙事 | 多层次判定 | `Constraint(NAR)`：判定层次=多层 |
| **哲学平衡→代价机制** | 残酷物理/等价交换 | 临界结果+修正陷阱 | `Constraint(WST)`：代价机制=风险回报 |

#### 2.10.3 边界声明

```
骰子设定（规则定义） → source_stage="A1"
  ├─ 5维映射的每个选择 → 编译为 Constraint 不可覆写常量
  ├─ 具体骰子参数 → 锁定为 Constraint 值
  ├─ 运行时骰子判定执行 → 不属于 A1（属于游戏引擎运行时 C/D 阶段）
  └─ A2 骰子模板生成器 → 引用 A1 约束，不可违反映射规则
```

| 意志主导 | LAW 约束值=意志 | `Constraint(LAW).value = WILL_BASED` |
| 物质主导 | LAW 约束值=物质 | `Constraint(LAW).value = MATTER_BASED` |
| 力量来源 | 能量流动拓扑 | `POWER_SOURCES_FROM_GEO` 边 |
| 获取方式 | 行为约束 | `Constraint(ACT)` |
| 代价机制 | 世界状态约束 | `Constraint(WST)` |
| 主要地形 | 地理骨架节点 | `Geography` CONCEPT 级 |
| 垂直层级 | 垂直拓扑边 | `GEO_ABOVE` / `GEO_BELOW` |
| 特殊地理 | 因果链边 | `RULE_SHAPES_GEO` / `POWER_SATURATES_GEO` |
| 核心价值 | 势力意识形态 | `Faction.ideology` |
| 冲突 | 势力关系边 | `FACTION_OPPOSES` / `FACTION_ALLIED` |
| 关键节点 | 事件骨架节点 | `Event` CONCEPT 级 |
| 因果上游 | 事件因果边 | `EVENT_CAUSED_BY` |
| 主剧情4维度 | 编译为约束集 | `Constraint(NAR/ACT, CORE)` |
| 玩家身份 | 玩法锚点 | `GameplayAnchor.player_role` |
| 成长方式 | 玩法锚点 | `GameplayAnchor.growth_path` |
| 骰子5维映射 | 编译为约束集 | `Constraint(LAW/ACT/NAR/WST)` |
