# Part 1 · 前沿设计理论地图（按讨论顺序排列）
| # | 理论 | 核心主张 | 对你的价值 |
|---|---|---|---|
| 1 | **Garrett 五层要素模型**（《The Elements of User Experience》，被引 5600+ 次）：战略层→范围层→结构层→框架层→表现层 | 每一层的决策必须由上一层约束；表现层的争议不能在表现层解决 | 这是本次对话的**总框架**。"界面丑"是表现层症状，病根大概率在战略层——你的产品方在骂第五层，问题可能在第一层 |
| 2 | **JTBD（Jobs to be Done）**：用户不是"使用产品的人"，而是"雇佣产品完成某项任务的人"。问法是"什么情境下，谁需要完成什么，为什么现有方案不够" | 把"目标群体"从人口学标签翻译成**任务陈述**，两群用户可能雇同一产品干完全不同的活 | TRPG 厂商和小说作者就是典型：同一个"世界观工坊"，被雇佣干的事可能南辕北辙 |
| 3 | **Norman 情感化设计三层次**：本能层（visceral，第一眼的颜值）/ 行为层（behavioral，用起来的顺畅）/ 反思层（reflective，用完后的自我叙事）+ **美学-易用性效应**（好看的界面会让用户更容忍缺陷、更愿意学习） | "丑"不是审美问题，是信任与耐心的杠杆问题 | 产品方说"要给人用这个软件就能实现梦想的感觉"——这句话其实是在本能层和反思层各要一样东西，你得拆开 |
| 4 | **Nielsen 10 可用性启发式**：系统状态可见性、防错、识别而非回忆、灵活与效率…… | 体验有**客观基线**，不全是主观审美 | 你的审计结论（error 强 / empty 无 / loading 裸 / 键盘 0 处 / 窄屏破版）可以直接映射到启发式条目上，用来跟产品方"丑不丑"的主观争论**解耦** |
| 5 | **AI 产品 UX 模式**（2025-2026 前沿）：渐进式能力披露、不确定性状态、human-in-the-loop 覆盖、一致的结构化输出 | AI 产品的核心体验不是"好看"，是**信任校准**：让用户知道 AI 什么时候可信、什么时候要复核 | 你的产品是 AI 访谈 + AI 提案 + AI 推断边——这是你们的品类主战场，而审计显示这些点几乎没被设计过 |
| 6 | **Design Tokens 三层架构**：primitive（原料）→ semantic（语义，如 `color-surface-raised`）→ component（组件级） | 令牌的价值在语义层，primitive 直接上样式表 = 设计决策失去单一事实来源 | 你们已有 primitive（space/stardust/nebula），但没有 semantic 层——所以 GuidedChat 才会逸出去用 slate/indigo，因为**没有语义令牌可依** |

## 第一层 · 战略层拷问（最痛，先来）
**Q1. 你的产品到底雇佣来干什么活？**
小说作者雇它，可能是"把脑子里散乱的世界观逼成结构"；TRPG 厂商雇它，可能是"把设定集变成可交付的 IP 资产"。这是**两个不同的 JTBD**。
→ 拷问依据：§8 产品方裁决"个人创作者优先"，但北极星又说含平台化（多用户/大厅）。**你能否用一个 JTBD 句式同时覆盖两者？如果不能，谁被牺牲？**
**Q2. "有真实外部用户"——第一个外部用户从哪个具体渠道来？**
审计 §2.2：没有 landing page，外访用户第一屏是 CRT 绿字旧 Demo，title 还是 "frontend"。
→ 你说北极星是外部用户。那么回答：**那个人此刻打开网址，30 秒内看到什么、理解什么、做什么？** 答不出来，"外部用户"就是愿望不是目标。
**Q3. "用这个软件就能实现梦想"——这是营销口号还是产品承诺？**
→ 拆开答：本能层它指什么画面？反思层它指什么用户叙事（"我因为我做了X，所以达成了Y"）？**如果只能保留一个，留哪个？**（Norman 三层次在此处就是解剖刀。）
**Q4. 产品方说痛点是"界面丑 + 功能难找"，排序已裁决。你接受这个排序吗？**
→ 拷问依据：审计 §6 显示"功能难找"可能根本不是"难找"，而是**不存在**（零全局导航、3 幽灵路由只能手敲 URL）；"界面丑"下面埋着**中文字体未定义**（§4.4，等宽栈对中文不生效，全部回退宋体/雅黑）这种一小时的修复。
→ **你是打算照单全收"丑+难找"，还是先用证据改写问题清单？** 如果你照单全收，告诉我为什么。
