# 预设 1：lovecraftian_horror / 深渊低语

## ① IP定位

- **名称**：深渊低语
- **概念**：*哲学*——宇宙对人类漠不关心，知识即疯狂；*剧情*——理智时代的黄昏，旧日支配者的封印松动，知情者挣扎求生；*冲突*——求真本能与自保本能的对抗，真相揭示即惩罚
- **类型**：*力量*——超自然/神秘学（低魔，代价极重）；*物质*——1920 年代现实世界 + 隐藏的神话层；*哲学*——宇宙恐怖主义（人类渺小论）
- **核心体验**：*主要行为*——调查、解谜、逃避、理智管理；*目标*——暂时阻止更糟的事情发生（而非"胜利"）

## ② 世界本体

- **来源**：
  - 起源力量：旧日支配者与外神——先于人类文明的存在，非创世神而是"更早的住客"
  - 起源时间线：远古沉睡 → 前文明崇拜 → 理性时代掩盖 → 当前封印松动
- **存在物**：
  - 力量体系（POWER_SYSTEM）：神秘学仪式与禁忌典籍（死灵之书、深渊咒典）——无职业魔法，只有付代价的凡人
  - 宇宙学（COSMOLOGY）：现实表层 + 梦境地（幻梦境）+ 深海/星际的非欧几何空间（拉莱耶、犹格斯星）
  - 哲学思想（PHILOSOPHY）：人类渺小论——文明是宇宙意外的涟漪；预示世界走向"不可避免的知晓与崩溃"
  - 其它（OTHER，含地理概念）：深潜者、米·戈、修格斯、食尸鬼等眷族与实体
- **现实规则**：**物质占主导**——物理法则刚性，超自然是"更深层的宇宙真相"而非可操控的魔法；人类意志无法扭曲现实，只能目睹并承受

## ③ 力量体系

- **来源**：
  - 力量本体定义：特殊环境（神话实体栖息地渗透）+ 意识体（外神意志的边缘辐射）
  - 力量来源底层：物质——完全是自然巧合（宇宙本就如此，与人类意志无关）
  - 力量影响生灵比例：本体（个体理智韧性）为主，客体（禁忌典籍接触）为辅
  - 溯源维度：环境汲取流——力量从神话节点（遗迹、深海、古籍）向接触者内聚流动；有限资源，接触越多损耗越大
- **获取方式**：
  - 获得：间接学习（阅读典籍——总结定性）+ 觉醒（环境——目睹触发"不可逆的知晓"）+ 仪式（来自高位存在传授，代价极重）
  - 载体维度：封闭拓扑——知识被教团垄断，精英式习得；普通人的门槛是"敢不敢付出理智"
  - 使用：间接——操作人造物（咒文、旧印、星辰银钥）驱散或封印；直接使用必付代价
  - 机制维度：物质主导 → 等价交换拓扑守恒——每次施法/阅读按 SAN 损失公式计价
- **代价**：承载短板——效果+反噬。理智（SAN）按 "成功损失/失败损失" 公式（如 0/1d6、2/1d10）损耗；克苏鲁神话技能每 +1%，SAN 上限永久等量下降；单次损失 5+ 点触发临时疯狂（1d10 小时）；诅咒物品不可丢弃，只能以特定仪式解除

## ④ 地理空间

- **主要地形**：宇宙学下位 → 主世界（1920 年代新英格兰）→ 地区：
  - 现实地貌：海岸地貌（印斯茅斯的沙坝、海蚀崖）、流水地貌（密斯卡托尼克河谷）、喀斯特地貌（无名之城的地下河）
  - 超自然地貌：非欧几何建筑（拉莱耶，"角度错误"的内力塑造）、南极古城（远古者文明遗迹）——分布稀疏、强弱与神话节点重合
- **垂直层级**：地面（人类文明层）→ 地下（食尸鬼隧道、无名之城）→ 深海（拉莱耶）→ 深空（犹格斯星）——越深越古老越危险
- **特殊地理**：shaping_rules = [外神梦境渗透、非欧几何法则]；power_sources = [拉莱耶（沉睡之神）、幻梦境入口、冷之高原]

## ⑤ 文明与社会

- **核心价值**：
  - 地理：沿海衰败村镇与学院城市的双元结构
  - 资源：力量资源=禁忌典籍与文物；自然资源=衰退期农业与渔业
  - 经济：力量的物质化=诅咒文物黑市；第一产业为主
  - 文化：按知识掌握程度分层（无知者/知情者/疯者）；求知越深越孤立
  - 政治：表层民主机构（报社、警方、大学）实际无力；暗层教团渗透
- **冲突**：信仰争端（教团复辟 vs 理性守序）+ 特殊争端（"该不该让别人知道真相"）
- **势力类型**：秘密教团（神权制）、学院理性派（学术制）、幸存者网络（松散互助制）——取材 1920 年代美国社会结构

## ⑥ 历史时间线

- **长度**：跨度数亿年（神话时间）→ 当前纪元："理智时代的黄昏"（1920s）；主要发展力量=人类理性 vs 神话复苏
- **关键节点**：
  1. 远古支配者沉睡（COSMIC，拉莱耶，无势力，无上游——因果链根）
  2. 前文明崇拜鼎盛与崩溃（MAJOR，冷之高原/无名之城，古教团，上游=①）
  3. 理性时代建立，神话被典籍封存（MAJOR，阿卡姆/密斯卡托尼克大学，学院派，上游=②）
  4. 当前：封印松动，各地异象频发（REGIONAL，印斯茅斯/敦威治，新教团，上游=③）
- **事件图**：沉睡 → 崇拜崩溃 → 理性掩盖 → 松动异象（线性熵增链，无循环）
- **主剧情**：
  - 起源回响：开端=对"远古沉睡"的意外触发（考古/典籍重现）
  - 意志载体：调查者=PHILOSOPHY（人类渺小论）的极端样本——理性者被迫见证非理性
  - 空间映射：决战发生在拓扑敏感点=封印节点（印斯茅斯近海、敦威治山丘）
  - 哲学闭环：结局验证"人类渺小"——世界没有变好，只是暂时没变更糟；历史呈熵增拓扑

## ⑦ 视觉设计

- **关键词**：昏暗油灯、深海绿与尸斑青、湿滑黏稠、腐败畸形、旧书与灰尘、雾气
- **建筑风格**：1920 年代新英格兰殖民式木屋与砖石学院建筑 + 教团的扭曲非欧几何祭坛（资源=本地木材石料；文化=清教徒克制 vs 亵渎崇拜；身份标识=大学徽章/教团刺青）
- **材质偏好**：腐朽木头、潮湿石砖、黄铜器具、羊皮纸、福尔马林玻璃罐；避免光洁金属与明亮色

## ⑧ 玩法设计DNA

- **玩家身份**：
  - 社会身份（初期）：记者、教授、医生、侦探——适应规则的理性职业
  - 维度身份（中后期）：架构定位=世界边界的"守门人"（封锁知识）or"窥探者"（不可逆求知）；法则定位=力量体系的使用者（有限防御性使用）
  - 超越身份（终极）：不可达——本预设哲学上禁止神格化，终极是"清醒的疯者"
  - 参与动机：探究动机为主（寻找真相）+ 生存动机（保住 SAN）
- **主要行为**：探索（对物=知识/信息；位移=水平地理拓扑）、研究（破解迷题=剧情维度；禁忌知识=法则维度）、有限的战斗（逃跑优于战斗）
- **成长方式**：机制维度成长=技能熟练（侦查/图书馆/心理学）；因果维度成长=揭露历史真相获"洞察者"优势——但每次成长以 SAN 上限为代价；成长尽头=社会性终点（剧情完成，幸存即结局）

## ⑨ 骰子设定（参照 Call of Cthulhu 7e）

| 拓扑维度 | 本预设选择 | 映射结果 |
|---|---|---|
| 现实规则→概率分布 | 物质主导（宇宙冷漠，专家更稳） | **d100 百分比骰**（以技能值为基准判定） |
| 力量来源→骰数 | 本体（个体理智韧性固定） | 固定骰 + 技能修正 |
| 获取方式→判定 | 封闭拓扑（知识精英习得） | **Roll-under**（掷骰低于技能值；人物卡"技能80%"=80% 成功） |
| 玩法行为→成功判定 | 研究/调查 | **多层次判定**（大成功/成功/困难成功/失败/大失败，Bonus/Penalty 骰细化） |
| 哲学→代价机制 | 知识即代价 | SAN 损失公式 "X/YdZ"（成功损失/失败损失）+ 临时/永久疯狂表 |

## ⑩ AI生成边界

- **可生成**：NPC（教团成员/知情者/疯者）、调查事件（线索链+技能检定 DC）、诅咒物品资产（附带理智代价）、场景（废弃地点+氛围）、平行剧情/支线
- **不可改变**：IP定位、世界本体（外神设定/SAN 规则）、力量体系（理智代价公式）、主剧情（封印松动因果链）、视觉设计基调、主世界地理（新英格兰+拉莱耶）、特殊地理（神话节点）；severity 枚举（COSMIC/MAJOR/REGIONAL/MINOR）封闭不可修改

## ⑪ 其它：Call of Cthulhu 7e 特殊设计亮点

- **玩法亮点**：
  - **三层线索结构**——核心线索（推进剧情必须，自动获得，永不卡关）+ 奖励线索（技能检定解锁）+ 危险线索（付出代价才知道）。调查永不死锁。
  - **追逐战规则（Chase）**——专用追逐系统：速度/障碍/CON 检查表，恐怖片式"跌倒即死"节奏。
  - **剧本结构性"死于知识"**——模块设计遵循"玩家知道得越多，越接近疯狂"，信息即倒计时。
- **角色设计亮点**：
  - **调查员羁绊系统（Ties）**——创角必填：一个信念、一个重要之人、一个意义之物、一个归属之地。角色死于疯狂/死亡时，羁绊成为遗嘱与下一代调查员的引子（传承式团）。
  - **职业即凡人**——记者/教授/侦探等纯现实职业表，无"英雄职业"，凡人性是设计核心。
- **判定机制亮点**：
  - **推演（Pushing the roll）**——失败可要求重掷，但 Keeper 可宣布"赌一把"的后果加倍（再失败更糟）。玩家自我施压的机制。
  - **奖励/惩罚骰（Bonus/Penalty Dice）**——掷 2 个十位骰取高/取低，环境优劣势不加减数值而是双骰竞争。
  - **幸运值（Luck）**——可花费永久幸运点强行改判，但花光后命运不再眷顾。
- **独有亮点**：**守秘人（Keeper）叙事权**——任何 SAN 损失允许 Keeper 直接指定调查员的下一个动作（尖叫/昏厥/扣扳机），把角色失控写进规则。

# 预设 2：cyberpunk_heist / 霓虹窃案

## ① IP定位

- **名称**：霓虹窃案
- **概念**：*哲学*——人性是可量化的消耗品，一切有价；*剧情*——公司冷战时代的边缘人靠高危委托求生；*冲突*——个体灵魂对抗系统吞噬
- **类型**：*力量*——科技（义体/网络）；*物质*——近未来反乌托邦都市；*哲学*——愤世嫉俗的物质主义
- **核心体验**：*主要行为*——潜入、黑客、战斗、谈判；*目标*——在人性值归零前捞够退休金

## ② 世界本体

- **来源**：
  - 起源力量：科技资本——公司不是被创造的，是演化出的人类寄生结构
  - 起源时间线：旧互联网时代 → 数据崩塌（DataKrash）→ 公司战争 → 停战条约当前纪元
- **存在物**：
  - 力量体系（POWER_SYSTEM）：义体化 + 网络入侵（Netrunning）
  - 宇宙学（COSMOLOGY）：物理空间（城市分层）+ 网络空间（数据要塞、ICE 防线）双宇宙
  - 哲学思想（PHILOSOPHY）：市场功利主义——存在即可交易；预示走向"人性彻底商品化或边缘人反抗"
  - 其它（OTHER，含地理概念）：AI（残存/恶意）、黑冰（恶性程序）、清道夫
- **现实规则**：**物质占主导**——物理与数字法则刚性，无超自然；意志只能通过技术手段（神经接口）间接干预现实

## ③ 力量体系

- **来源**：
  - 力量本体定义：科技（义体、网络接口）
  - 力量来源底层：物质——完全是自然巧合（技术积累的客观产物）
  - 力量影响生灵比例：客体（外界刺激/改装投入）远大于本体——钱决定义体等级
  - 溯源维度：内聚流——力量从公司研发端向黑市/个人端扩散；有限资源（财力决定上限）
- **获取方式**：
  - 获得：学习（间接——系统化训练）+ 科研（建立模型/借助工具/实验/验证/重复）+ 觉醒（灌注——非法军事实验）
  - 载体维度：开放拓扑表层（人人可装义体）+ 封闭内核（顶级军用科技被公司垄断）——阶层分化按钱包划分
  - 使用：直接（调用物质能量/人造物）+ 间接（操作人造物——黑客操控网络、控制第三者——智能武器）
  - 机制维度：物质主导 → 等价交换守恒——每件义体扣人性值，每次入侵冒黑冰风险
- **代价**：承载能力 vs 操作能力——义体率超过承受阈值即触发赛博精神病检定；人性值归零 = 角色失控（成为"赛博精神病"NPC）；承载特性继承——军用义体的攻击本能是上位缺点

## ④ 地理空间

- **主要地形**：主世界（夜之城式都市）→ 地区：
  - 现实地貌：流水地貌（改造河道）+ 风成地貌（恶土沙尘暴区、雅丹式荒地）
  - 超自然地貌（科技地貌）：公司塔群（垂直内力——资本塑造）、数据要塞（网络空间"地形"）、黑市地下城
- **垂直层级**：深空（轨道公司资产）→ 天空（飞行器航线/企业顶层）→ 地面（街道层——主战场）→ 地下（黑市、下水道、旧地铁）——垂直即阶级
- **特殊地理**：shaping_rules = [公司战争重建、资本分区法则]；power_sources = [网络节点（数据要塞）、企业研发中心、黑市义体诊所]

## ⑤ 文明与社会

- **核心价值**：
  - 地理：都市垂直分层——越高越贵
  - 资源：力量资源=数据与科技；自然资源=恶土的稀缺水与耕地
  - 经济：力量的物质化=义体/芯片/ICE 破解器；第二产业（军工义体）+ 第三产业（中间人经济）主导
  - 文化：按义体化程度分层（原体纯血/轻度改装/深度义体）；街头文化崇拜传奇雇佣兵
  - 政治：公司科层制取代政府；街头由帮派与中间人秩序维系
- **冲突**：资源争端（公司抢数据/抢人才）+ 权利争端（个体权利 vs 公司所有权——"你的义体是租的"）

- **独有亮点**：**Nat20 文化**——自然 20/自然 1 的固定 5% 神话时刻，桌面上的集体仪式感被写进规则心脏。

# 预设 8：court_intrigue / 鸩酒与玫瑰

## ① IP定位

- **名称**：鸩酒与玫瑰

- **核心体验**：*主要行为*——对话博弈、情报经营、结盟背刺、危机应对；*目标*——把自己支持的继承人送上王座（或自己坐上去）

## ② 世界本体

- **来源**：
  - 起源力量：开国征战——王朝以血与誓约奠基（"打天下"的合法性源头）
  - 起源时间线：开国之乱 → 中兴盛世 → 当前"主少国疑、权臣环伺"
- **存在物**：
  - 力量体系（POWER_SYSTEM）：阴谋系统（Intrigue）——立场/技巧/风度的社交战斗
  - 宇宙学（COSMOLOGY）：单层现实世界（无位面无魔法——唯一"宇宙"就是权力结构本身）
  - 哲学思想（PHILOSOPHY）：现实主义权谋论——没有好人坏人，只有动机与立场；预示走向"新秩序或新乱世"
  - 其它（OTHER，含地理概念）：密探网络、边关军阀、教门势力
- **现实规则**：**物质占主导**——物理与生理法则刚性（毒药有药理、刀剑会致命）；"改变现实"靠制度与信息，不靠超自然

## ③ 力量体系

- **来源**：
  - 力量本体定义：意识体（权力=他人意志的集合）——力量是"能调动多少人的意志"
  - 力量来源底层：意志——与"能思考的东西"互动（说服、胁迫、联姻）
  - 力量影响生灵比例：客体（地位/情报/关系网）远大于本体（个人魅力）——结构高于个体
  - 溯源维度：宫廷内聚流——权力向王座汇聚又自王座扩散（集聚流/扩散流）；信息即能量，节点=情报房与密道
- **获取方式**：
  - 获得：学习（间接——宫廷教育/观察总结）+ 觉醒（环境——危机时刻的立场选择）+ 仪式（联姻/结拜/效忠礼）
  - 载体维度：封闭拓扑——贵族血统即门槛，寒门天花板低（精英统治的极端）
  - 使用：直接影响它灵意志（说服/威吓）+ 间接控制第三者（密探/说客/替罪羊）
  - 机制维度：物质主导 → 等价交换守恒——每条情报、每次结盟都有对价；信任是最贵的货币
- **代价**：信任值隐藏（−10~+10），只能通过行为线索推断——误判即背叛；社交战斗以风度（Composure）为"生命值"——失态即败北；投毒/暗杀暴露则身份泄露给目标派系；联姻须逐一说服每个发言权者（各需胜利点数+资源交换）

- **玩法亮点**：
  - **家族即角色（House as Meta-character）**——开局先共创家族（领地/历史/七属性/宿敌），再各自扮演家族成员——"角色团"之上还有"家族团"，集体叙事被机制化。
  - **家族运势（House Fortunes）**——每月依总管属性掷"运势骰"决定家族事件（丰收/丑闻/战争）——政治压力自动生成，无需 GM 手动喂剧情。
  - **领地经营与冒险双循环**——政务（资源分配/联姻/筑城）与冒险（个人荣耀/刺探/征战）两条腿走路，一方玩家开宴会时另一方在打仗。
- **角色设计亮点**：
  - **背景事件表（Life Events）**——创角即掷人生：战争经历/失恋/背叛/获得名师——命运感先于自由意志。
  - **命运点（Destiny Points）**——稀有货币：改判、保命、"命运注定我不会死在此"——权谋世界里主角光环是限量供应的奢侈品。
- **判定机制亮点**：
  - **Intrigue 社交战斗**——与武力战斗完全对称的系统：立场值（Disposition）=血条、技巧（Charm/Bargain/Intimidate…）=武器、风度（Composure）=护甲——"话说错一句，等同挨一刀"。
  - **联姻的多方胜利点结算**——每名有发言权的亲属各自需要说服到不同分数——一场婚事就是一场多人副本。
- **独有亮点**：**把"嘴仗"规则化为正式战斗系统**——纯对话场景拥有与战争同等的规则深度，暴力不再是唯一被认真对待的解决方式。
