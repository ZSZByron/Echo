## 1. 模块化工程纪律（本版新增）

### 1.1 路由真相源唯一（module_registry）

`backend/app/domains/creation/shared/module_registry.py` 是模块遍历/门禁/校验/预填/展板的**唯一入口**。

**六处全集直访禁令清单**（任何消费方禁止直接遍历 `MODULES` 或 `MODULE_POOL` 全集，必须 `get_recipe(session)` 后按 `recipe["module_ids"]` 遍历）：

| # | 位置 | 改造 |
|---|---|---|
| 1 | finalize 门禁（a1_routes.py:1137） | 全集遍历 → 配方集遍历 |
| 2 | graphify 锚点校验（graphify.py:239/:474） | 合法键全集 → 配方并集 |
| 3 | `first_module()` 默认（guide_engine.py:101-102） | 全集首模块 → 配方首模块 |
| 4 | `_build_sections`（a1_routes.py:958） | 配方感知 |
| 5 | ip_poster.py:8/:39-40（展板 panels） | 配方感知 |
| 6 | worldview_upload.py:24-29/:193-200（上传 prompt schema） | default 配方渲染不变；故事型 × 上传链归 DN6 |

补充纪律：`get_recipe` 对未知冲动类型回落 default，**永不抛异常**；问卷树门面函数加配方参数（默认 = 全集），MODULES 数据零改动。改造依据与行为定义 = [[SYSTEM_DESIGN_SPEC_v6]] §2.1，此处为纪律清单，不复制契约正文。

### 1.2 LLM 生产方封闭清单（四点 + 立项流程）

全系统 LLM 生产方封闭为四点：**interviewer / inference_pack / module_compile / opening_narrative**（生产方-归属-产出详表 = v6 §2.5，不复制）。

配套纪律：

1. 清单外任何模块**不得新增 LLM 调用**——"LLM 只产内容与建议，永不产结构/数值/路由"
2. 新生产方逐一走三铁律"单生产单消费"契约评审立项留痕（**DN5**），**先立项后写码**
3. 推断包复用 pending_proposals + confirm 交互，不直写 answers（J1 真值闸拦截占位）
4. module_compile 免费线（零 LLM 确定性装配）先行；LLM 失败降级为骨架 + ledger 披露，绝不阻塞主流程

### 1.3 prompt 骨架恒 1（R2）

interviewer 保持**单一 prompt 骨架**；配方差异（目录/进度摘要/锚点）一律以参数注入渲染，禁止按配方分叉骨架文件。`_progress_summary` / `_field_catalog` 按配方渲染——**禁止向 LLM 泄露配方外字段目录**（G5 泄露修复，规范化为禁令）。

### 1.4 图谱防乱五防线

五防线（锚点校验=配方并集 / 家族-tier 固定映射 / 产物图谱独立命名空间 / 确定性装配不变式 / 跨配方不比较）的机制详表 = [[SYSTEM_DESIGN_SPEC_v6]] §2.7 + [[2026-09-22-jia-modular-architecture-design]] §5.1，此处只立纪律：**触及装配链的改动必须能回答"五防线各是否仍然成立"**；M/TD/TC 图谱节点永不出现于 W 图谱。

### 1.5 契约测试重梳清单（C1-C9）

| 契约 | v5 语义 | v6 处置 |
|---|---|---|
| C1-C2 | 既有基线契约 | 不受影响，照旧 |

| C5 | tier 闭集 | **重锚**：断言改"池内模块必有 tier"（TIER_MAP 加键 10→16 翻案记录入 D14/DN2） |
| C6 | R6 可达性 | **重述**：配方内纯置换可达性进契约测试 |
| C7 | loop E2E | M1a 清债后重锚（importmode 修复） |
