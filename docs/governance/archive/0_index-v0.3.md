                     |

     表2  产品架构总览          ← 系统"做什么"？（空间维度）

## 使用规则

1. **每次开发会话第一步**: 读 `PROJECT_STATE.md`（唯一进度真相源），再按需查本索引定位治理文档
2. **新增功能前**: 查表2（架构）确认系统边界，查表4（UX）确认用户路径
3. **新增数据模型时**: 更新表3（知识资产）
4. **代码结构变更时**: 更新表5（工程治理）
5. **版本化更新（治理铁律）**: 更新任何治理表时**新建文件顺延版号**（如 `4_ux-flow-v0.3.md`），frontmatter 标注 `supersedes` 指向旧版，不修改原版；被取代的旧版移入 `archive/`
