## 模块①：IP定位

厂家第一眼看到的世界概要。

### 名称
世界的命名，用于标识和推广这个世界观的名称。

### 概念
世界的核心理念或一句话定位，概括世界的本质特征。由三要素构成：**哲学 + 剧情 + 冲突**。

### 类型
世界观的分类类型，定义世界的性质和范畴。由三要素构成：**力量 + 物质 + 哲学**。

### 核心体验
玩家在这个世界中的核心体验和感受，定义玩家的主要活动和情感体验。由两要素构成：**主要行为 + 目标**。

## 模块②：世界本体

### 来源
世界存在的起源，包括创世神话、科学起源、虚空诞生等根本性起源故事。
- **起源力量**
- **起源时间线**

### 存在物
世界上存在的根本性存在，包括抽象概念和实体类型，定义世界的构成要素。**包含地理概念**。
- **力量体系（POWER_SYSTEM）**
- **宇宙学（COSMOLOGY）**
- **哲学思想（PHILOSOPHY）** — 世界背景哲学预示着世界的走向
- **其它（OTHER）** — 不包含在上面三类，但是有影响的生灵、规则、物质、存在

### 现实规则
支配世界运行的基本规则，包括物理法则、魔法体系、科技水平、宇宙规则等。
- **意志占主导** — 现实规则 = 意志扭曲物质，拓扑形态动态可变
- **物质占主导** — 现实规则 = 物质法则刚性，拓扑形态稳定不可变

## 模块③：力量体系

### 3.1 来源

力量的根本来源，定义力量从何而来，如元素、神力、科技、虚空等。

**力量本体定义**（枚举，可发挥想象力）：
- 意识体 / 物理背景 / 特殊环境 / 科技 / 发挥想象力

**力量来源底层**：
- 意志：与"能思考的东西"互动
- 物质：完全是自然巧合

**力量影响生灵比例**：
- 本体：个体资质
- 客体：外界刺激

#### 溯源维度：能量来源

- **连接对象**：力量体系（能量本源）↔ 世界本体（起源/宇宙学）
- **设计逻辑**：力量必须有其物理或哲学来源。这决定了力量是"有限资源"还是"无限资源"。
- **维度体现**：
  - **流动拓扑** — 能量从哪里流向哪里？
    - 起源是"神创" → 力量来源是"神性馈赠"（自上而下的单向流动）
    - 起源是"虚空诞生" → 力量来源是"环境汲取"（从环境到个体的内聚流动）
  - **节点控制** — 宇宙学中的关键节点（如位面通道）是否是力量的高产点？
    - 例：所有的魔法塔都必须建在"地脉节点"上（力量体系依赖宇宙学拓扑）

### 3.2 获取方式

如何获得或使用力量，包括学习、觉醒、科技研发、仪式等方法。

#### 力量如何影响生灵 — 获得

**学习**：
- 直接学习：预感 / 激发 / 训练
- 间接学习：总结（定性 / 定量）/ 系统 / 殖装·g改造

**觉醒**：环境 / 血脉 / 灌注 / 学习

**仪式**：来自自然环境 / 来自知识总结 / 来自高位存在传授

**科研**：建立模型 → 借助工具 → 实验 → 验证 → 重复

#### 载体维度：阶层分化

- **连接对象**：力量体系（使用者/权限）↔ 世界本体（存在物/哲学思想）
- **设计逻辑**：谁能使用力量？直接对应"存在物"的生物学差异和社会阶层的哲学划分。
- **维度体现**：
  - **层级拓扑** — 力量在不同物种间的分布
    - 存在物是"龙/神" → 具有先天力量（天赋拓扑，高势能）
    - 存在物是"人类" → 需后天学习（习得拓扑，低势能）
  - **权限映射** — 哲学思想决定力量获取门槛
    - 哲学是"精英统治" → 力量体系稀有且难以掌握（封闭拓扑）
    - 哲学是"众生平等" → 力量体系普及且低门槛（开放拓扑）

#### 使用

- **直接**：调用物质/能量 / 调用人造物 / 直接影响其它生灵意志
- **间接**：
  - 操作人造物：低级是直接使用自然物，高级是人造物
  - 控制第三者：低级是驱使自然生灵，高级是力量改造的生灵

#### 机制维度：交互法则

- **连接对象**：力量体系（运作方式）↔ 世界本体（现实规则/意志 vs 物质）
- **设计逻辑**：力量体系必须遵循现实规则的底层逻辑。这是区分"硬奇幻"与"软奇幻"的关键。
- **维度体现**：
  - **交互拓扑** — 力量如何改变现实？
    - 物质主导规则 → 力量体系遵循"等价交换"（消耗物质产生效果，拓扑守恒）
    - 意志主导规则 → 力量体系遵循"唯心投射"（消耗精神扭曲现实，拓扑非守恒）
  - **排他性** — 力量体系是否排斥其他规则？
    - 科技规则 vs 魔法规则 → 设定是否存在"互斥拓扑"（如磁场干扰魔法，魔法腐蚀机械）

### 3.3 代价

使用力量需要付出的代价，包括生命消耗、精神损耗、资源枯竭、道德堕落等。

#### 根据来源底层和个体影响的冲突

- **承载能力 vs 操作能力**：
  - 承载 > 操作 → 效果大于预期/正常效果
  - 承载 = 操作 → 正常效果无代价
  - 承载 < 操作 → 有代价
- **承载短板**：效果 + 反噬
- **承载特性本能**：上位缺点继承
- **特殊约定**：满足条件支付代价

#### 代价维度：平衡约束

- **链接对象**：力量体系（副作用/限制）↔ 世界本体（现实规则/哲学思想）
- **设计逻辑**：没有代价的力量体系是失真的。代价是维护世界"哲学平衡"的手段。
- **维度体现**：
  - **平衡拓扑** — 获得力量必须支付什么？
    - 现实规则是"残酷物理" → 代价是"肉体损耗"（生命值/寿命）
    - 哲学思想是"善恶二元" → 代价是"精神腐蚀"（滥用力量堕落为恶）
  - **反馈回路** — 力量的使用如何反作用于使用者？
    - 力量使用过度 → 导致存在物变异或非人化（拓扑形态改变）

## 模块④：地理空间

### 4.1 地理单元的类型 — 主要地形

层级：**大陆 → 区域 → 地标**

宇宙学下位 → 主世界 → 地区：

**地理地貌**：
- **引用现实地形地貌**（按内力/外力分类）：
  - 星体地貌（地球内部构造运动，内力作用）：大陆、大洋
  - 海岸地貌（外力：波浪、潮汐、洋流）：沙滩、海蚀崖、沙坝、潟湖
  - 流水地貌（外力：流水/河流）：峡谷、冲积扇、三角洲、河漫滩
  - 冰川地貌（外力：冰川）：冰斗、角峰、U形谷、冰碛垄
  - 风成地貌（外力：风力）：沙丘、雅丹地貌、风蚀蘑菇
  - 喀斯特地貌（地下水溶解）：溶洞、峰林、天坑、地下河
  - 丹霞/雅丹地貌（特殊岩性与风化/侵蚀）：赤壁丹崖、风蚀垄槽
- **超自然地形地貌**（力量来源、现实规则驱动）：内力还是外力？分布？强弱？

**水平位置** / **主区域**

## 模块⑤：文明与社会

### 5.1 核心价值

势力的核心意识形态：
- **地理**
- **资源**：力量资源 / 自然资源（现实地貌 + 力量影响）
- **经济**：

### 5.3 势力类型

## 模块⑥：历史时间线

### 6.1 长度

世界历史的时间跨度与所属历史时期（era）：
- 时间 / 时段名称 / 主要发展力量

### 6.2 关键节点

历史事件，每个事件含：
- **影响范围**（severity，封闭枚举 4 值，**不允许添加或修改**）：
  - 宇宙级 `COSMIC` / 重大 `MAJOR` / 区域级 `REGIONAL` / 次要 `MINOR`
- **发生地**（`location_geo_id`，关联地理）
- **涉及势力**（`involved_faction_ids`）
- **因果上游**（`caused_by_event_id`，对应 `EVENT_CAUSED_BY` 边）

### 6.3 事件图

事件之间的因果链图：时期 / 关键节点 / 前后关系

### 6.4 主剧情（四大设计维度）

#### 驱动维度：起源回响

- **链接对象**：主剧情（开端/核心冲突）↔ 世界本体（起源/现实规则）
- **设计逻辑**：所有主剧情本质上都是对"世界起源"的回应。起源故事定义历史的初始动力。
- **维度体现**：
  - **因果拓扑** — 剧情开端是否是对起源设定的"触发"？
    - 起源是"神创" → 剧情开端往往涉及"神谕"或"弑神"
    - 起源是"虚空诞生" → 剧情开端往往涉及"异变"或"虚空入侵"
  - **规则制约** — 现实规则决定剧情冲突的解决方式
    - 意志主导 → 转折点依靠"信念/牺牲/精神觉醒"
    - 物质主导 → 转折点依靠"资源/科技/物理力量对比"

#### 代理维度：意志载体

- **链接对象**：主剧情（主角/阵营）↔ 世界本体（存在物/力量体系）
- **设计逻辑**：关键角色和势力必须是"存在物"的典型代表，是力量体系的具象化符号。
- **维度体现**：
  - **映射关系** — 主角/反派是某种"存在物"的极端样本
    - 存在物包含"龙" → 剧情中必须有"屠龙者"或"龙骑士"
  - **力量节点** — 势力强弱直接对应力量体系的分布
    - 力量体系是"高魔" → 掌握历史的必须是法师/神权阶级（力量拓扑的高势能点）

#### 舞台维度：空间映射

- **链接对象**：主剧情（关键事件发生地）↔ 世界本体（宇宙学/地理/其他）
- **设计逻辑**：历史大事件必须发生在宇宙学结构的关键节点上。剧情是地理空间的"活化"。
- **维度体现**：
  - **位置拓扑** — 决战/重大事件必须发生在"拓扑敏感点"
    - 宇宙学有"位面通道" → 剧情高潮发生在通道入口（争夺连通性）
    - 地理上有"天险" → 剧情中必有"关口攻防战"（利用阻隔性）
  - **地理演化** — 剧情结果解释地图现状
    - 地图上有个大坑 → 剧情中必有一场"古代大战"导致地形改变（时间维度的地理投影）

#### 归宿维度：哲学闭环

- **链接对象**：主剧情（结局/主题）↔ 世界本体（哲学思想）
- **设计逻辑**：剧情结局必须验证或挑战世界的哲学思想。历史时间线是世界观的"论证过程"。
- **维度体现**：
  - **一致性验证** — 结局是否契合哲学基调？
    - 哲学是"循环论" → 结局是"新的轮回开始"，历史呈圆环拓扑
    - 哲学是"虚无主义" → 结局是"不可避免的衰败"，历史呈熵增拓扑
  - **思想斗争** — 剧情冲突的本质是哲学观念的冲突
    - 哲学有"善恶二元" → 时间线就是善与恶的拉锯战

## 模块⑧：玩法设计DNA

### 8.1 玩家身份

玩家在世界中的角色定位，需与模块①的核心体验逻辑一致。

**定位三阶段**：
- **社会身份（初期）**：对应地理层级。如：流浪者、行商、雇佣兵。*（此阶段玩家适应规则）*
- **维度身份（中后期）**：对应宇宙层级。
  - 架构定位：你是维护世界边界的"守门人"？还是打破边界的"入侵者"？
  - 法则定位：你是力量体系的"使用者"？还是"篡改者"？
- **超越身份（终极）**：对应哲学层级。如：神格化、概念体、观测者。*（此阶段玩家定义规则）*

**合理的参与动机**：
- 生存动机 — 解决物质/空间维度的匮乏（缺钱、缺地）
- 探究动机 — 解决时间/演化维度的谜题（寻找历史真相、阻止末日）
- 主宰动机 — 解决哲学/意志维度的冲突（确立新的价值观、成为新神）

**主导玩家组织**

### 8.2 主要行为

玩家反复执行的核心动作。示例：`["探索","战斗","选择","成长"]`

**探索**：
- 位移：水平位移（地理拓扑）/ 垂直位移（架构拓扑）/ 工具·能力（媒介交互）
- 对物：自然（物质）/ 力量（能量）/ 知识（信息）
- 对人：
  - 盟友（关系拓扑）：宠物 / 亲人 / 同道 / 利益一致
  - 任务（交互行为）："信息交换"（获取情报）和"概念同化"（传教）
  - 敌人（关系拓扑）：目标冲突

**战斗**：
- 攻击：近战（物理/力量体系-机制维度）/ 远程（物理/力量体系）/ 特殊（法则篡改）
- 防御：闪避（空间博弈）/ 抗击（空间博弈）/ 中断（法则对抗）
- 力量体系（势能操作）：复合属性的能力 / 利用物理世界增强自己削弱对方

**研究**：
- 破解迷题：法则维度 / 剧情维度
- 力量成长：本体重塑

**提升**：符合力量体系——消耗资源（代价维度）换取能力的质变

### 8.3 成长方式

玩家的重复玩法循环和成长路径。**符合 IP 概念与类型的完成目标的行为导致成长**：

- **符合力量体系的互动导致成长**（上位是 IP 类型）— 机制维度
  - 量变：熟练度提升（动作更流畅）
  - 质变：获得新的拓扑能力（如攻击附带穿透、范围扩大）
- **符合导向 IP 目标的良性冲突互动导致成长** — 哲学维度
  - 通过抉择（选择阵营、选择命运）获得"哲学点数"，解锁特定路线的终极技能
- **符合 IP 概念、扩充世界观的行为导致成长** — 因果维度
  - 探索未知区域（解开地图迷雾）→ 获得"先驱者"加成
  - 揭露历史真相（解开时间迷题）→ 获得"洞察者"加成
- **其它**

**成长尽头**（目标完成，成长的尽头是目标的确定性）：
- 社会性终点：剧情完成了
- 法则性终点：成为新的力量体系，成长的尽头是成为世界的规则
- 哲学性终点：创造了新的概念，成长的尽头是成为模因
- 其它

## 模块⑨：骰子设定

### 一、核心映射模型：设定驱动机制选择

RPG 规则设计的本质，是将世界本体（设定层）转化为数值机制（规则层）的过程。不存在"万能"的骰子或等级系统，只有"最契合"的拓扑选择。

**拓扑映射流程**：世界设定（现实规则/力量来源）→ 核心体验目标（策略性/叙事性）→ 机制维度选型（骰子/等级）

### 二、骰子系统的拓扑设计框架

骰子不仅是随机数生成器，更是世界物理法则与力量体系的具象化。

**1. 概率分布维度：现实规则的映射**

决定因素：世界本体中的"现实规则"是物质主导还是意志主导。

- **意志主导的现实 → 高不确定性/戏剧性 → 线性分布**
  - 逻辑链条：当现实规则由"意志""信仰"或"叙事逻辑"主导时，强调精神力量对现实的扭曲与奇迹。要求骰子机制提供高方差、高戏剧性的结果（凡人凭意志创造奇迹，英雄因疏忽陨落）。
  - 选材概率提升：大幅提高选择**单一骰子（d20、d100）**的概率——线性分布让极端结果拥有固定且不可忽视的概率（如 5%），契合"唯心"世界观的不可预测性与英雄主义叙事。
- **物质主导的现实 → 稳定性/真实性 → 钟形曲线分布**
  - 逻辑链条：当世界遵循严格的物理法则或残酷的自然规律时，强调能力积累与客观限制。要求骰子机制提供低方差、高可预期性——专家比新手拥有压倒性的稳定优势。
  - 选材概率提升：大幅提高选择**多骰子总和（3d6、4dF）**的概率——钟形曲线让中间值最常见、极端情况极罕见，模拟"训练有素者极少失手"的物理真实性。

**2. 骰子数量维度：力量来源的映射**

- **力量来源为"本体"（天赋/血脉）→ 固定能力值 → 固定骰子机制**
  - 逻辑链条：力量来源于"血脉""觉醒"或"灵魂强度"，角色能力是相对固定的属性值（如"我的魔力是15"）。随机性是对固定能力的一次"抽样"。
  - 选材概率提升：提高选择固定骰子机制（掷一个 d20 并加修正值）的概率。骰子仅作为检验天赋是否发挥作用的判官，而非力量的来源。
- **力量来源为"客体"（环境汲取/可调动能量）→ 可变能量储备 → 骰池机制**
  - 逻辑链条：力量来源于外部环境（地脉节点）或可消耗的"精神池/能量池"，角色能力表现为"可调动的资源量"。
  - 选材概率提升：大幅提高选择**骰池机制**的概率。骰子数量直接映射"力量储备/环境能量"，掷骰过程模拟"调动资源"，成功数代表"调动效率"——契合需要管理有限资源的玩法设计。

**3. 判定方式维度：获取阶层的映射**

- **获取方式为"学习/觉醒"（封闭拓扑/精英统治）→ 能力值固定且重要 → Roll-under（掷骰低于数值）**
  - 逻辑链条：力量获取依赖严格训练、血脉觉醒或高门槛学习（哲学思想为精英统治），技能数值本身就代表绝对成功率。
  - 选材概率提升：极大提高 Roll-under 概率。玩家直接在人物卡上看到"技能80%"= 80% 概率成功。强化培养成就感，符合封闭、高门槛设定。
- **获取方式为"科研/工具操作"（开放拓扑/众生平等）→ 动态难度/环境交互 → Roll-over（掷骰高于目标）**
  - 逻辑链条：力量获取更多依赖工具、环境适配或临场发挥（哲学思想为众生平等），能力修正值需与外部世界定义的"难度等级（DC）"对抗。
  - 选材概率提升：极大提高 Roll-over 概率。GM 通过设定 DC 灵活反映"环境复杂度""工具质量"等客体因素，契合"物质主导"或"科技主导"的世界观。

**4. 成功判定维度：玩法行为的映射**

- **核心行为为"战斗/高速冒险"→ 快节奏/明确结果 → 二元判定**
  - 逻辑链条：强调快速激烈的战斗或生死冒险时，掷骰结果须迅速裁决"成功或失败"，维持节奏和紧张感。
  - 选材概率提升：提高二元判定及固定临界规则（nat20 必中 / nat1 失误）的概率。简化裁决，叙事焦点迅速推进到下一个动作。
- **核心行为为"研究/调查/社交博弈"→ 细节叙事/灰色地带 → 多层次判定**
  - 逻辑链条：侧重解谜、调查或复杂社交时，单纯成败不足以编织细致剧情，需要知道"成功得多完美"或"失败得多惨痛"。
  - 选材概率提升：提高多层次判定（大成功、成功、困难成功、失败、大失败）及 Blackjack 机制的概率。骰子结果直接转化为叙事丰富程度，服务于调查类游戏对细节的苛求。

**5. 世界观哲学（平衡约束）与代价机制的拓扑**

- **哲学思想为"残酷物理/等价交换"→ 代价维度：肉体损耗 → 临界结果与修正值陷阱**
  - 逻辑链条：底层哲学强调平衡与残酷时，力量使用必须伴随风险——骰子机制中嵌入"风险与回报"。
  - 选材概率提升：提高引入**条件性临界机制或爆炸骰（Open-ended Roll）**的概率。追求极致成功可能导致不可控的灾难性失败（大失败风险随修正值增加而增加），在数值层面映射"力量滥用必遭反噬"的世界公理。

### 三、总结拓扑图谱

| 设定维度 | 设定选择 | 映射驱动的设计哲学 | 提高选材概率的骰子维度 |
|---|---|---|---|
| **现实规则** | 意志主导（英雄主义/神话叙事） | 戏剧张力优先，追求高方差与意外惊喜 | 概率分布：线性分布，单一骰子（d20/d100），高方差 |
| | 物质主导（真实模拟/硬科幻） | 稳定性与公平性优先，追求能力主导与可预测 | 概率分布：钟形曲线，多骰子总和（3d6），低方差 |
| **力量来源** | 本体/天赋（血脉/觉醒） | 固定属性抽样——能力恒定，骰子检验发挥 | 骰子数量：固定骰子机制，掷固定数量骰子+修正值 |
| | 客体/环境（地脉/电池） | 资源管理模拟——能力是可调动的资源池 | 骰子数量：骰池机制，骰子数量直接映射力量规模 |
| **获取方式** | 封闭拓扑（精英学习/觉醒） | 直观成功率——技能值即代表实力 | 判定方式：Roll-under，掷骰低于技能值 |
| | 开放拓扑（科技研发/工具使用） | 动态难度对抗——能力与环境的交互决定结果 | 判定方式：Roll-over，掷骰加修正值超过 GM 设定的 DC |
| **玩法行为** | 战斗/冒险 | 节奏流畅优先，快速裁决明确结果 | 成功判定：二元判定，或简单的固定临界（nat20/nat1） |
| | 研究/调查 | 叙事细节优先，结果层次丰富剧情 | 成功判定：多层次判定，划分大成功至大失败的多个阈值 |

> 游戏设计者可依据自己构建的世界观（世界本体）和玩法蓝图，精准定位到最适合的骰子机制组合，在底层逻辑上保证规则与叙事的完美融合。

## 模块⑩：AI生成边界

### 10.1 可生成范围

AI 被授权生成的内容类型。示例：`["NPC","任务","物品","场景","资产"]`

#### 地理空间

**地点分区**（已确定地点在大陆中的具体位置，只生成地点下属的分区——**A2 生成内容**）：

- 地貌点/区域怎么组合：
  - 行政区域的首府的区划
  - 行政区域、地貌间的荒野或林地、湖泊等
- **功能定位维度：主导功能**
  - 设计指标：
    - 主导用途：生态保育区（以林地、湿地为主）/ 农业生产区（以耕地、村庄为主）/ 城镇建设区（以建筑、道路为主）
    - 人类活动强度：密集活动区（市中心）/ 适度活动区（郊区）/ 限制活动区（荒野/核心保护区）
  - 与场景的关系：场景是功能的载体（"生态保育区"分区内包含多个"林地"和"湖泊"场景）
  - 隐含拓扑：互补拓扑（供需关系）+ 依附拓扑（单一功能）—（有向流）
- **空间构成维度：空间排列组合**
  - 设计指标：
    - 组合模式：单一主导型（如"国有林场"，内部 90% 是林地，边界清晰）/ 镶嵌混合型（如"乡村旅游区"，林地农田村庄交错，边界模糊）
    - 连通性：分区内场景连成一片 / 廊道（河流、道路）串联的多个斑块
  - 隐含拓扑：嵌套拓扑（核心区）+ 散点拓扑（边缘区）—（层级深度）
- **边界属性维度：分区之间的界限**
  - 设计指标：
    - 边界类型：行政边界（行政区划划定，便于管理）/ 自然边界（地形地貌如分水岭、流域划定，利于生态完整性）/ 功能边界（规划红线划定）
    - 边缘效应：刚性的（围墙、公路）/ 柔性的（过渡带、缓冲区）/ 混合
  - 隐含拓扑：门控拓扑（关卡）+ 过滤拓扑（缓冲带）—（开关与阻抗）
- **管理归属维度：归谁管、谁来管**
  - 设计指标：
    - 行政级别：省级自然保护区 / 市级工业园区 / 村级自治区域
    - 权属状态：国有 / 集体 / 私有——决定分区内场景的处置权
    - 政策适用：该分区适用的特殊法律法规或规划导则
  - 隐含拓扑：层级拓扑（行政包含）+ 重叠拓扑（一地两管）—（树状与交集）

**分区中的场景**（PC 实际可以经过的空间的样貌——**A2、A3 生成内容**）：

- 地貌点/区域里的细节：荒野或林地、湖泊的细节；区划里的细节
- **景观要素**（场景在空间上呈现的几何特征）：
  - 斑块（面状要素）：大片林地、湖泊、城镇建成区
  - 廊道（线状要素）：河流、道路、防护林带——连接不同斑块
  - 基质（背景底色）：大面积荒野或农田，其他要素镶嵌其中
  - 作用：决定场景的边界和连通性。隐含包含关系和穿越关系
- **物质构成维度：土地覆盖类型**（决定场景的视觉色调和基本纹理）：
  - 植被覆盖：林地（森林、灌木林）/ 草地（天然、人工）/ 耕地（水田、旱地）
  - 水体覆盖：水域（河流、湖泊、水库）/ 水库
  - 裸露地表：未利用地（荒野、沙地、裸岩）
  - 人工建筑：建设用地（城镇、农村居民点）
  - 隐含拓扑：硬边界相邻与介质阻隔关系
- **生境**（场景为生物提供的生存条件和生态服务，决定场景的动态变化）：
  - 栖息功能：林地是动物的窝，湖泊是鱼类的家
  - 调节功能：湿地净化水质，森林调节气候
  - 生产功能：耕地提供粮食，牧场提供肉类
  - 承载功能：建设用地承载人类活动
  - 隐含拓扑：功能联通关系与流向拓扑关系
- **人文社会维度**（人类社会赋予场景的法律地位、文化意义和管理归属）：
  - 行政等级：省、市、县、乡、村
  - 权属关系：国有林地、集体农田、私有领地
  - 文化意象：名胜古迹、风水林、圣湖、纪念碑等
  - 隐含拓扑：人文归属与边界分割关系

#### 文明与社会

- **能改变经济结构**：新型政治体系 → 文化变化 → 社会关系变化 → 代理人变化/不变
- **不能改变**：维持原政治体系 → 文化不变 → 社会关系不变 → 代理人变化

#### 历史时间线

- 平行剧情
- 主剧情的支线剧情

#### 视觉设计

- 只能新增不能修改原设计

#### 细分主题 5

### 10.2 不可改变范围

AI 不可修改的受保护元素。示例：`["主线剧情","魔法源","核心冲突","关键词"]`

以下均**只能随主线剧情更新版本修改，GM/PC 不可修改**：

- **IP定位**
- **世界本体**
- **力量体系**
- **历史时间线**（主剧情）
- **视觉设计**
- **玩法设计DNA**
- **地理空间**：
  - 主要地形：宇宙学下位 → 主世界 → 地区 → 区域 → 地点（各级均锁定）
  - **地点设计**（几何区位 / 层级地位 / 流动网络 / 功能分工四维度）：
    - **几何区位维度：空间位置和相对关系**：相对位置（核心节点/边缘节点/门户节点）、空间距离、拓扑关系
    - **层级地位维度：等级秩序**：等级序列（一级节点-区域中心 / 二级节点-次中心 / 三级节点-一般地点）、首位度、支配力
    - **流动网络维度：物质、能量和信息的流动**：流的方向（集聚流/扩散流）、流的内容（物流/人流/资金流/信息流）、网络角色（枢纽/桥头堡/终端）
    - **功能分工维度：干什么、互补性**：专业化职能、互补性（互补合作 vs 同质化竞争需错位设计）
  - **区域设计**（空间战略位势 / 系统分工角色 / 网络连接密度 / 发展梯度位势四维度）：
    - 空间战略位势：核心-边缘拓扑（核心区/边缘区/过渡区）、屏障拓扑（向海门户/向陆门户、战略屏障）
    - 系统分工角色：增长极 / 资源腹地 / 生态屏障 / 战略储备（源-汇拓扑、链式拓扑）
    - 网络连接密度：网络枢纽度、网络通达性、网络封闭性（星座拓扑、孤岛拓扑）
    - 发展梯度位势：高梯度区 / 中梯度区 / 低梯度区 / 回流区·衰退区（扩散拓扑、崩塌拓扑）
  - **地区设计**（行星地理格局 / 文明演化位阶 / 叙事承载权重 / 法则同调程度四维度）：
    - 行星地理格局：纬度地带性（热带/温带/寒带·极地，力量可能影响气候维度）、海陆分布格局（世界岛/孤悬大陆/大洋孤岛）（环绕拓扑、桥接拓扑）
    - 文明演化位阶：文明起源属性（原生文明核心区/次生·边缘文明区）、世界中心-边缘结构（支配性地区/挑战者地区/被遗忘地区）（层级树拓扑、依附拓扑）
    - 叙事承载权重：主线舞台（承载 80% 主线剧情）/ 资源后勤区 / 神秘探索区 / 禁区废土（可达性拓扑、迷雾拓扑）
    - 法则同调程度：高魔·高科技区 / 低魔·低科技区 / 法则破碎区（相变拓扑、异界拓扑）
  - **主世界设计**（架构 / 法则 / 位面 / 纪元四维度）：
    - 架构维度——定义"世界的形状"：
      - 结构形态：飘浮虚空岛屿（《艾尔登法环》/《黑暗之魂》）/ 层层包裹同心球体（D&D）/ 连接位面的巨树（北欧神话、《魔兽世界》）
      - 物理法则：重力如何运作？天空的尽头是什么？太阳是星体还是神的战车？
      - 设计建议：画"宇宙剖面图"（纵向剖面而非平面地图）；设定边界（无限虚空还是不可逾越的屏障如"迷锁""世界之墙"）
      - 拓扑体现：边界拓扑——闭合性（有限/无限、内/外）+ 包含关系（确定地理层级）
    - 法则维度——定义"世界的底层逻辑"：
      - 能量来源：魔法或灵气从哪里来？（地底源泉 vs 星辰辐射）决定高魔区/禁魔区分布
      - 神权架构：神明是否真实存在？远处观望的造物主还是直接干预的统治者？神系混乱度对应地面战乱频率
      - 生与死的规则：灵魂死后去往何处？（冥界/世界树/直接消散）决定丧葬文化差异
      - 设计建议：编写"创世代码"——列出三条不可违背的铁律（如：魔力需支付代价；死者不可复生；光是有限的）——这是地理设计中所有矛盾的终极解释权
      - 拓扑体现：场论拓扑——势能与梯度（势能差：高魔区 vs 低魔区 = 高势能节点 vs 低势能节点；能量流动方向构成世界的矢量场）+ 主导性映射（意志主导→拓扑随意志动态变形；物质主导→拓扑刚性稳定）
    - 位面维度——定义"关系的网络"：
      - 位面拓扑：主世界与哪些位面接壤？（决定入侵、贸易和跨界旅行的路径）
      - 传送门机制：复杂仪式还是天然裂缝？"宇宙级港口"是地理设计中的超级节点（连接地狱裂缝的城市必然是军事重镇）
      - 设计建议：设计"位面共振"——火山岛可能是火元素位面的锚点，充满高强度火元素生物和资源
      - 拓扑体现：网络拓扑——连通性（节点：传送门、世界树、虚空裂缝，连接点数量决定开放程度；路径；隔离）+ 渗透性（不同存在物的生存空间界限）+ 分层拓扑（存在物按能量层级或哲学属性分布在天上界/地下界）
    - 纪元维度——定义"时间的刻度"：
      - 创世阶段：混沌初开（神明还在创造）还是暮年（神明离场，世界衰退/崩坏）？
      - 循环机制：线性还是循环？是否有"大灾变"周期？"第五纪元"的前四个纪元留下了什么遗迹？
      - 设计建议：绘制时间轴，标记宇宙级大事件（众神战争、大分裂、魔法枯竭）——事件痕迹就是地理中的"奇迹景观"或"禁区"（神战陨落的坑洞形成内陆海）
      - 拓扑体现：变形拓扑——变形（进步哲学→拓扑向外扩张；衰退哲学→向内收缩；循环哲学→衔尾蛇结构自洽循环）+ 断裂（古代战争导致连通的大陆拓扑断裂形成孤岛）
  - **宇宙学设计**
  - 垂直层级（主世界）
  - 特殊地理（`shaping_rules` + `power_sources`）

### 宇宙级"拓扑检查"（验证设计）

1. **检查"能量流动"**：宇宙的能量源头是否与地理上的核心区域相对应？（宇宙观是"群星指引魔力"→ 高魔区必须在视野开阔的高原或山顶，而非地下）
2. **检查"位面渗透"**：宇宙观中的"邪恶位面"是否在地理上有入口？如果有，附近政治格局是否反映这种危机？（通往地狱的裂痕附近应是高度军事化的要塞或变异生物的废土，而非安逸田园）
3. **检查"文明与神权的一致性"**：地面宗教建筑是否符合神明属性？（太阳神已死亡 → 太阳神庙应荒废凄凉甚至被改建，而非金碧辉煌——除非为了缅怀）
