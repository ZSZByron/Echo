# 2-A1 世界观底层拓扑概念树 v0.4

> **定位**：A1 世界观生成中**从世界底层向上**的拓扑关系概念树——每个设定槽位挂载：填空类型 / 词典概念嵌入 / 拓扑产出 / 上游依据 / 下游派生 / LLM 填空策略。本文是**知识图谱生成与 LLM 自动填空/关系树生长的推理依据**。
>
> **分类权威声明**：骨架分类 = **问卷树（v0.3 十大模块）**。`3_knowledge-assets` 的实体五分类（Geography/Faction/Event/Concept/Constraint）与边词典**作为概念嵌入到问卷树槽位上使用，不作为顶层分类**（它无层次、不够详细，仅是槽位的"编译目标类型"字典）。
>
> **配套**：[[2-A1-v0.3-问卷维度全景图]]（问卷字段结构权威）、[[2-A1-v0.1-定稿图谱拓扑与回退流]]（当前实现状态）。

## 0. 使用原理（LLM 如何用这棵树）

### 0.1 双序原理

| 序 | 顺序 | 用途 |
|----|------|------|
| **访谈序**（问卷序） | ①IP定位 → ②本体 → ③力量 → ④地理 → ⑤文明 → ⑥历史 → ⑦视觉 → ⑧玩法 → ⑨骰子 → ⑩边界 | 人类问卷流程：先锚定创意再展开世界 |
| **拓扑序**（本文序） | L0 存在基座 → L1 动力学 → L2 显现 → L3 时间 → L4 表达 → L5 命题 → L6 治理 | **LLM 填空/推导序**：上游先填，下游才有依据 |

两序不矛盾：问卷序是拓扑序的**合法拓扑排序之一**（问卷设计已保证每题的上游先问）。

### 0.2 填空类型体系（封闭，不允许扩充）

| 类型 | 形态 | 例 |
|------|------|-----|
| `ENUM` | 封闭枚举，值逐字 | severity: `COSMIC/MAJOR/REGIONAL/MINOR` |
| `AXIS` | 二元光谱轴（端点封闭） | 意志主导 ↔ 物质主导 |
| `TREE` | 结构化树值 | terrain: 大陆→区域→地标 |
| `DAG` | 结构化因果值 | key_nodes: 四元组列表 |
| `TEXT` | 自由文本 | 概念描述 |

### 0.3 LLM 填空策略标注（封闭，不允许扩充）

| 标注 | 含义 |
|------|------|
| `[必问]` | 仅用户可填，LLM 只提问 |
| `[规则派生]` | 确定性函数推导，LLM 无需创作（如骰子五链） |
| `[上下文派生]` | LLM 依据上游已填槽位+种子生成，需用户确认 |
| `[校验]` | 不可填，仅做一致性验证 |

### 0.4 填空→图谱物化协议（关系树如何生长）

```
每次槽位填充后立即物化（增量式）：
1. 产出节点：按槽位的「词典概念」字段建/更新节点
2. 产出边：  按槽位的「拓扑产出」+ §3 派生边总表建边
3. 传播失效：上游已填值变更 → 沿 DERIVES 边标记下游 stale → 重新派生
4. 运行校验：§4 拓扑检查器（宇宙级3检查 + 转化清单8条）
```

## 1. 底层→顶层总图

```
L6 治理层   ⑩AI生成边界（锚定不可变集 + 开放A2/A3填充域）
L5 命题层   ①IP定位（全树的压缩投影根：概念/类型/体验）
L4 表达层   ⑦视觉 ⑧玩法DNA ⑨骰子   ← 纯派生汇（零上游输入不可填）
L3 时间层   ⑥历史时间线            ← 全树汇聚点（接收L0-L2全部输入）
L2 显现层   ④地理空间（空间显现） ⑤文明与社会（社会显现）
L1 动力学层 ③力量体系（4维光谱：溯源/载体/机制/代价）
L0 存在基座 ②世界本体（起源/存在物/现实规则——全宇宙分叉点）
```

依赖方向：**L0 向上滋养，L4-L5 向下投影，L6 横向治理一切**。

> 格式：`槽位路径 ｜填空类型｜词典概念（嵌入 3_knowledge-assets）｜拓扑产出｜上游依据→下游派生｜LLM策略`

### L0 存在基座（②世界本体）

```
◆ 世界本体.起源.起源力量
  ｜AXIS（意志型 ↔ 物质型）｜Concept(ORIGIN)｜全图因果链根节点（无 caused_by 上游）
  ｜上游：无（根）→ 下游：力量.流动拓扑、历史.主剧情.驱动维度（起源回响）
  ｜[必问]（种子可预填）

◆ 世界本体.起源.起源时间线
  ｜TEXT｜Event 时间轴原点｜约束 ⑥长度 的 era 起点
  ｜上游：无 → 下游：历史.time_span
  ｜[必问]

◆ 世界本体.存在物
  ｜ENUM*（容器多选：POWER_SYSTEM / COSMOLOGY / PHILOSOPHY / OTHER，封闭不允许新增大类）｜Concept 分类容器
  ｜拓扑产出：每个勾选类建一个 Concept 子节点；PHILOSOPHY 预示世界走向→编译为 Constraint(NAR,CORE) 终局约束
  ｜上游：无 → 下游：力量.层级拓扑（存在物差异→力量分布）、历史.主剧情.代理维度（主角=极端样本）
  ｜[必问]

◆ 世界本体.现实规则 ★全树最高杠杆节点
  ｜AXIS（意志主导·拓扑动态可变 ↔ 物质主导·拓扑刚性稳定）｜Constraint(LAW, CORE)
  ｜拓扑产出：全宇宙分叉点，4条下游派生的源头
  ｜上游：起源力量（弱对齐校验）→ 下游：力量.交互拓扑 / 骰子.概率分布 / IP.类型（三要素之一）/ 历史.主剧情.规则制约
  ｜[必问]；[校验] 与力量.来源底层 对齐
```

## 4. 拓扑检查器（finalize/增量时运行）

**宇宙级三检查**（来自问卷全景树）：
1. 能量流动：力量源头 ↔ 地理高势能核心区是否对应
2. 位面渗透：邪恶位面入口 ↔ 附近政治格局是否反映危机
3. 文明神权：宗教建筑 ↔ 神明属性是否一致

**转化清单**（boundary-spec §6，8 条）：每条设定≥1个节点或边 / 覆写级别标注 / 力量4维各≥1条编译 / 因果边指向具体 Geography / 主剧情4维编译 / 骰子5链编译 / 边界表与拓扑一一对应 / 无未转化的描述性文本。

**交叉对齐校验**（本文新增）：
- 现实规则 ↔ 力量.来源底层（同侧）
- IP.类型 ↔ 力量+现实规则+概念（三要素还原一致）
