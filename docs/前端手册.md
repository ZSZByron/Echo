## 1. 技术底座与架构特征

- **技术栈**：Vite + React 19 + TypeScript + Tailwind CSS v4（`@theme` 内嵌配置，无独立 config）+ React Flow（图谱画布）
- **测试**：Vitest（单测）+ Playwright（E2E）；Linter：oxlint
- **架构三特征**（审计 §1）：
  1. **无路由库**——`window.location.pathname` if/else 手动分发（App.tsx:25-29）
  2. **无状态库**——原生 fetch 封装 + useState，package.json 无 react-query/SWR
  3. **A1 主线为单文件三态状态机**——A1Workspace.tsx 1567 行 / 39 个 useState

**src 目录速览**：

```
frontend/src/
├── App.tsx                 # 手动路由分发（CRT Demo 壳）
├── index.css               # CRT 赛博朋克皮肤（全局注入，含扫描线/霓虹）
├── api/  hooks/  labels/  types/  assets/
├── pages/
│   ├── a1/                 # A1 主线四件：A1Workspace / CopyrightDialog / IPPoster / UploadToolbar
│   └── graph/              # 遗留三页：GraphEditor / AssetReview / GraphAssetReview
└── components/
    ├── theme.css           # 「Starry Parallel Universe」星空皮肤令牌（组件级 import）
    ├── guided/             # 访谈屏：GuidedChat / ProposalCard / ProposalTray / QuestionHint
    ├── structured/         # 右栏面板：StructuredFilePanel / DimensionProgress / DiffHighlight
    ├── graph/              # 图谱屏：A1KnowledgeGraph / A1GraphSection / EdgeReviewPanel / NodeDetailPanel / NodeBadge / PromptPreview / WaveDivider
    ├── poster/             # PosterBoard
    ├── terminal/           # CRT Demo：Terminal / SceneView / SceneObject / StatusPanel / GodWatchIndicator / ActionHints / TypewriterText
    └── shared/             # AssetPlaceholder / ResetButton
```

## 3. 逐页功能详解

### 3.1 `/` 回声终端（CRT Demo）

四层绝对定位叠加（App.tsx:72-102）：场景层（可点击对象回填输入）→ 全屏红光干涉指示 z-50（GodWatchIndicator）→ 顶栏（标题+重置，右侧让位 320px）→ 底部 45% 高终端区（自然语言输入 → 打字机输出，Terminal/TypewriterText）+ 右侧 300px 全高状态面板（生命值/力量/物品栏，StatusPanel）。

后端对接：`/api/action`（指令解析）、`/api/scene`、`/api/state`、`/api/reset`。

**09-17 变更**：D11 已裁决此页迁 `/demo`，新 landing（规格 v0.1）接管 `/`。

### 3.2 `/a1` 世界观工坊——三态状态机

状态定义于 A1Workspace.tsx:261，`a1_workspace_state` 持久化 + 挂载水合恢复（:277-293），含 stale fileId 404 自愈（:397-408）。

**态一 · seed_selector（选种屏）**：居中单列 max-w-6xl——① 玻璃卡标题「世界观工坊」+ 英文副标；② 加载/错误态；③ 种子卡网格（唯一响应式断点 1/2/4 列，:1004），整卡点击开始会话；④ 上传工具栏（UploadToolbar，主按钮「⇪ 上传世界观文档」，三阶段轮播文案每 1.5s 切换）；⑤ 自定义输入区（英文 placeholder + Start 按钮）。上传命中版权检测弹全屏模态（CopyrightDialog.tsx:29-96：⚠ 版权风险 + 三列匹配表 + 转换使用/取消）。

**态二 · guided_chat（访谈屏）**：双栏 h-screen——左 flex-1 聊天区（顶栏 IP Code+种子名+返回；消息气泡流，user 靛蓝右/assistant 深灰左，**混用 slate/indigo 逸出星空令牌**，GuidedChat.tsx:152,165-168；AI 填空提案前 3 条内联 + 其余入托盘抽屉 max 60vh；提案含「原设定 vs 新内容」双盒对照 + 替换/合并/放弃三动作；提案在场时挂起下一问）；右固定 400px 面板（① StructuredFilePanel 10 模块分层字段+行级红绿 diff；② DimensionProgress 10 格进度网格；③ 创新建议卡；④ 定稿 409 黄框；⑤ footer 主按钮「定稿并生成知识图谱」）。

**态三 · graph_view（定稿产物，双 Tab）**：FullscreenShell 56px 工具栏（返回访谈 / 行政树·概念网双视图切换 / 「已定稿 vX ✓」徽章 / 重新定稿 / 待确认·已确认·待问三色计数 / **warning ledger 角标**——warn 琥珀·info 灰底，点击弹降级明细 popover 按五源分组〔组装/定稿/图谱化/失效边/上传〕）。
- **知识图谱 Tab**（A1KnowledgeGraph，React Flow）：行政树=双树层级视图；概念网=tier 七层纵向分带布局（340×220，tier 0-6：本体根基→符号学→地理→历史→社会→组织→其他）；画布顶部搜索 + 底部图例（★铁律/◆联想/◇结构拆解）；左侧待问浮层（「去回答 →」跳回访谈）；右侧 340px EdgeReviewPanel（确认/拒绝 AI 推断概念边）；点击节点出 NodeDetailPanel；stale 黄条提示重定稿。
- **展板预览 Tab**：poster 数据只读预览。

### 3.3 `/a1/poster` IP 展板独立页

与 graph_view 展板 Tab 同数据双渲染，多出：① 顶栏「← 返回世界观工坊（继续深化）」（经 `a1_return_intent` 键）；② 右下 Visual BG 面板——Generate AI Image + 5s 轮询至完成（10 分钟超时保护）。内容：星野背景 + 星点闪烁 + 玻璃浮卡网格（✦+标题+内容，1/2/3 列交错浮动）+ 底部渐隐 + 背景图轮播（5s、圆点指示器）。

### 3.4 `/graph/editor` 知识图谱编辑器（遗留）

六维管线时代产物。React Flow 编辑 + `/api/graph/extract|validate|save` 对接。与 A1 主线无依赖关系；幽灵路由，D10 回检队列在案（导航与幽灵路由处置）。

### 3.5 `/admin/graph-assets` 图谱资产生成（遗留，Mock 数据）

Wave 串行生成触发（`/api/graph/generate`）；部分 Mock。

### 3.6 `/admin/assets` 资产审核（遗留）

生成/审批/拒绝/更新提示词（`/api/assets/*`）；可用但无入口。

## 4. 设计系统现状（F1 取证校准版，2026-09-17）

### 4.1 令牌表（theme.css @theme L40-91 实测值）

| 令牌组 | 实值 | 状态 |
|---|---|---|
| space-950/900/800/700/600 | #0a0a1a / #13132a / #1c1c3d / #2a2a5a / #3a3a7a | ✅ 深空背景五段梯度 |
| stardust-400/300/200 | #fbbf24 / #fcd34d / #fde68a | ✅ 星光金主强调 |
| nebula-500/400/300 | #8b5cf6 / #a78bfa / #c4b5fd | ✅ 星云紫次强调 |
| void-600/500/400 | #52525b / #737373 / #a1a1aa | ✅ 中性灰 |
| starlight-300/400/500 | #fcd34d / #fbbf24 / #f59e0b | 🔴 **冗余待删**（300/400 ≡ stardust，500 ≡ cosmos-warning；组件零引用，见规格 §10 F1 回报） |
| cosmos-success/warning/error/info | #34d399 / #f59e0b / #f43f5e / #22d3ee | ✅ 语义四色 |

其他：间距 --space-glass-{sm..2xl}=8/16/24/32/48px；圆角 {sm,md,lg,full}=4/8/16/9999px；阴影 4 枚（glow-soft 金 15% / glow-strong 金 30% / glow-purple 紫 20% / glass 黑 30%）；过渡 200/300ms。

**待新增（D1 令牌五件套，规格 §1）**：primitive `--color-space-1000: #050508`、`--color-energy-cyan: #00F0FF`；semantic 层七枚（surface / text-primary / text-secondary / accent / bubble-user / bubble-ai / glass，组件只准用本层）。

**双青边界（09-17 精确化，规格 §10）**：energy-cyan #00F0FF 独占「秩序能量」语用（流光/充能/CTA）；cosmos-info #22d3ee 仅限「信息语义」（info 状态提示），互不越界。物理合一需产品方另裁。

### 4.2 双皮肤割裂

两套互不兼容视觉语言按路由硬编码分布，无切换机制：
- **皮肤 A · Starry Parallel Universe**（theme.css，A1 全系，经 A1Workspace.tsx:20 组件级 import 非全局注入）：深空蓝紫底 × 星光金强调 × 星云紫辅助 × 毛玻璃面板 × 微弱星象动效（twinkle 透明度呼吸 2s / float-glow 上浮 8px 4s）+ 自定义星光滚动条
- **皮肤 B · CRT 赛博朋克**（index.css，仅 `/` Demo）：无令牌体系纯 hex 硬编码——黑底 #0a0a0a × 霓虹绿 #00ff41 × 系统等宽字体栈 × 全页扫描线（repeating-gradient 8s 位移）× 文字三层霓虹光晕 × flicker/glitch/border-pulse 四动画
- App.css 为 Vite 模板残留尸体（.counter/.hero）

### 4.3 字体真相（审计 §4.4，Q4 病根）

全局唯一 font-family = `ui-monospace, Consolas, monospace`（index.css:4，CRT 皮肤）。**无自定义 webfont、无 @font-face、无中文字体声明**——星空皮肤中文回退宋体/微软雅黑随系统。D1 五件套已排定修复：标题 Noto Serif SC（CDN + font-display: swap，仅标题/slogan）；正文 system-ui + PingFang SC + Microsoft YaHei（零下载）。

### 4.4 元信息缺口（审计 §4.5）

index.html：title="frontend"（模板默认名未改）、lang="en"（中文产品）、无 description/theme-color/字体预加载。D1 交付项将修复（title「ECHO · 回声工坊」候选名 / lang zh-CN）。

### 4.5 色彩纪律（台账 P2 + 规格 §1，09-17 立）

混沌体（几何体+粒子）= nebula/stardust 系；秩序能量（流光/充能/CTA）= energy-cyan 全站唯一。**裸值 #7000FF / #FFD700 弃用**（F1 取证：仓内本就零命中），分别由 nebula-500 / stardust-400 承担。

## 5. 前端检查基线（2026-09-16 审计要点）

### 5.1 异步操作三态覆盖矩阵（审计 §5.1）

| 操作 | Loading | Error | Empty |
|---|---|---|---|
| 种子加载 | ✅ 纯文案 | ✅ 面板 | ❌ 无空态 |
| 发消息 | ✅ 禁用+内联 | ✅ 面板（回滚用户消息） | — |
| 上传 | ✅ 三阶段轮播 | ✅ 503/422 中文分支 | — |
| 定稿 | ✅ 按钮文案切换 | ✅ 409 黄框列缺板块 | — |
| 图谱加载 | ✅ spinner shell | ✅ 全屏错误+重试 | ⚠️ 一行字无 CTA |
| 展板 | ✅ spinner | ✅ 面板 | ❌ |
| 边确认 | ❌ 无独立 loading | ✅ 面板 | — |

模式总结：error 覆盖最全（统一 cosmos-error 面板）；**empty 系统性缺失**；loading 均裸 spinner，无骨架屏。

### 5.2 微文案语言

中英混杂：按钮/导航中文为主，**系统级错误文案约 60% 英文**（如 "Failed to send message..." A1Workspace.tsx:663、"Loading seeds..." :995）；console.error ~25 处是唯一错误日志通道。规格 v0.1 §6 已立全中文 + 称呼「你/你的世界」条款（P3）。

### 5.3 响应式与可访问性（审计 §6）

- A1 全线仅 1 处断点（种子卡 grid）；访谈右栏写死 400px、h-screen 双栏无窄屏降级——**窄屏必破版**
- ARIA 全线仅 7 处；**键盘交互 0 处**（无 onKeyDown/tabIndex，图谱节点无键盘导航）；对比度风险：void-400/500 深灰小字、nebula-400 元信息小字、stardust-300 小标题
- 仅暗色（color-scheme: dark）

### 5.4 工程技术债（审计 §7）

| 项 | 事实 |
|---|---|
| 巨石组件 | A1KnowledgeGraph.tsx 66KB / A1Workspace.tsx 55KB（1567 行）/ A1GraphSection.tsx 35KB |
| 类型健康 | **tsc 存量 16 错误**，`npm run build`（tsc -b && vite build）被拦 exit 2；Docker 绕道 `npx vite build` |
| 测试存量 | vitest 185 过 + 6 存量失败（useTypewriter）+ 1 收集错误（e2e spec 误收）；Playwright E2E 存量 |
| 色板纪律 | GuidedChat 气泡 slate/indigo 逸出（D1 semantic 层 bubble-user/bubble-ai 承接修复） |
| 状态管理 | 39 useState 单文件，无 useReducer/Context，prop drilling 深 |
