# 🗺️ Echo UGC 文档中心 (MOC)

> **用法**: 用 Obsidian 打开——推荐**仓库根**作 Vault（一个文件夹看所有内容：PROJECT_STATE/证据/代码全进图谱）；嫌 node_modules 噪音就开 `docs/`（库外文件用路径链接兜底）。
> 所有文档通过 `[[]]` 双链互联，从本页出发可到达任何文档。
> **链接规则**: 本页一律使用文件名链接（不带路径）——Obsidian 按文件名全库解析，文档移入 `archive/` 也不会断链。
>
> **⚡ 嫌散就看 [[HUB]]**: `docs/HUB.md` = 总目录·唯一入口（进度/决策/架构/治理/证据五大类 `[[双链]]` 索引——本页可跳过）。
>
> **进度真相源**: [PROJECT_STATE.md](../PROJECT_STATE.md)（仓库根，每次会话更新）。本页只做导航，不承载进度。
