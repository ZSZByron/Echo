## H. 架构设计经验（触发场景：设计实体类型/图谱结构/管线分工/设计文档审计）

| # | 经验 | 一句话 |
|---|------|--------|
| H1 | 设计文档内部矛盾检测 | 规范定义 N 种实体但采集入口只覆盖 M 种（M<N）时，先审计覆盖缺口，再写代码——缺口是设计规格问题，不是实现问题 |
| H2 | 实体语义分层 | "地名标签"(Location) 和"地理结构关系系统"(Geography) 是两个层级——前者是社会关系投影，后者是世界规则在空间维度的因果投影，不可混用 |
| H3 | 边类型词典封闭枚举+版本化 | 图谱边类型必须是 StrEnum 封闭枚举 + 版本号；新增类型需升级词典版本并强制设计评审——结构常量不可随意扩展，与 ConstraintLevel(CORE/MODULE/SCENARIO) 同理 |
| H4 | 管线阶段拓扑分工 | A1 建立"结构拓扑"（节点+边=不可覆写常量），A2/A3 在拓扑内"填充细节"（可扩展变量）——边是结构常量，节点是阶段变量 |
| H5 | 因果链边归属阶段 | "规则→地理"因果边（RULE_SHAPES_GEO / POWER_SATURATES_GEO）只能由 A1 建立——A2/A3 不重新定义世界规则，故不可新建此类边，只能在已有拓扑内追加细节节点 |
| H6 | EntityNode vs GraphNode 职责分离 | EntityNode = 世界知识本体（type/name/faction/race 等实体语义），GraphNode = 资产生成依赖树（层级编码/拓扑排序）——两者职责不同，强行合并会破坏 Wave 串行生成逻辑 |
| H7 | 数据来源路径验证 | 每种实体类型必须标注"首次出现阶段"和"数据来源路径"；来源断裂的实体（如无问卷入口）要么补采集入口，要么标注为 AI 推理生成+厂家确认 |
| H8 | 骨架语义澄清 | "骨架级 KG"是模糊说法——正确表述是"A1 建立结构拓扑（节点+边），边是不可覆写的结构常量"；节点数量不是关键，边的语义定义才是 |

## 本次设计决策快照（2026-08-05）

### 决策 1：Location → Geography 升级
- **原设计**: `Location` 实体 = 地名标签（"银月城"），属性只有 name + 一句话描述
- **新设计**: `Geography` 实体 = 地理结构关系系统，表达"世界规则如何塑造地形"
- **理由**: Location 是社会关系投影（谁占领这里），Geography 是因果链投影（什么规则造就了这里）——后者才是 A1 应该产出的结构拓扑

### 决策 2：边类型词典 v0.1（封闭枚举）
四类边，共 14 种：
1. **地理层内部**（4种）: GEO_CONTAINS / GEO_BORDERS / GEO_ABOVE / GEO_BELOW
2. **规则/力量→地理**（3种，A1 独有）: RULE_SHAPES_GEO / POWER_SATURATES_GEO / POWER_SOURCES_FROM_GEO
3. **地理→势力/事件**（3种）: GEO_SEPARATES / GEO_NOURISHES / GEO_HOSTS_EVENT
4. **势力/事件/概念层内部**（4种）: FACTION_ALLIED / FACTION_OPPOSES / EVENT_CAUSED_BY / CONCEPT_MANIFESTS_AS / CONSTRAINT_LIMITS

### 决策 3：实体首次出现阶段标注
- **A1 产出**: Geography / Faction / Event / Concept / Constraint（骨架节点 + 结构拓扑边）
- **A2 补充**: Culture（在 A1 拓扑内填充文化体）
- **A3 补充**: Character / Item / Scene（在 A2 区域拓扑内填充具体实体）

### 决策 4：A1 KG 数据来源
- Geography 不走问卷直采，走"AI 设计顾问从模块2（世界本体）+模块3（力量体系）推理+厂家确认"
- 符合 A1"专业问卷+AI 设计顾问"的产品定位

## 适用判断清单（下次设计实体/图谱时逐条过）

- [ ] 每种实体是否标注了"首次出现阶段"？（H7）
- [ ] 实体的数据来源路径是否闭合？（H7）
- [ ] 实体是"地名标签"还是"结构关系系统"？（H2）
- [ ] 边类型是否封闭枚举+版本化？（H3）
- [ ] 哪些边是 A1 独有的因果链？（H5）
- [ ] A2/A3 是否只能追加细节节点，不能新建结构边？（H4）
- [ ] EntityNode 和 GraphNode 是否分离？（H6）
- [ ] "骨架"这个词是否被误用——应说"结构拓扑（节点+边）"？（H8）
