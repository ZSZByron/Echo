## 1. 4套维度各自的角色定位

| # | 维度体系 | 回答的问题 | 作用时机 | 产出物 |
|---|---------|-----------|---------|--------|
| **4** | 世界观拓扑维度 | "这个世界长什么样？" | **设计师输入时**（A1问卷） | 设定选择→编译为约束 |
| **1** | 6维约束 (RED/LAW/ACT/NAR/WST/SOC) | "这个对象服从什么规则？" | **编译阶段**（问卷→Schema） | Constraint 节点 |
| **2** | 6层生成 (WORLD/REGION/SCENE/CAMPAIGN/NPC/ASSET) | "生成什么层级的内容？" | **生成阶段**（LLM调用） | 内容节点 + 权重分配 |
| **3** | A1/A2/A3 三阶段 | "谁有权创建这个节点？" | **全生命周期**（权限控制） | source_stage 标记 |

**执行顺序**：4 → 1 → (1×2) → 生成 → 3 控制权限

## 2. 逐步追踪：从设计师输入到最终生成

### Stage 0：设计师填写世界观（第4套启动）

设计师通过 A1 问卷填写世界观。每一项选择都在**第4套的某个拓扑维度**上做了一个决策。

```
设计师选择了：
  ┌─ 溯源维度：起源=虚空诞生 → 力量=环境汲取（从环境到个体）
  ├─ 机制维度：物质主导 → 等价交换（守恒律）
  ├─ 载体维度：封闭拓扑 → 精英统治，力量稀有难掌握
  ├─ 代价维度：残酷物理 → 肉体损耗
  ├─ 架构维度：世界=浮岛群，边界=虚空
  ├─ 法则维度：能量来源=地脉，神不存在，死后灵魂消散
  ├─ 位面维度：主世界与元素位面有裂缝连接
  ├─ 纪元维度：世界暮年，线性时间，正在崩坏
  ├─ 现实规则→骰子：物质主导→钟形(3d6)，本体天赋→固定骰，封闭→Roll-under
  └─ 玩法行为→骰子：战斗→二元判定
```

**此时产出**：一组拓扑维度选择（纯设计决策，还不是系统可执行的格式）。

---

### Stage 1：编译——第4套转化为第1套（约束）

系统将设计师的每一项拓扑选择**编译为第1套的6维约束**。

```
第4套选择                              第1套约束（编译结果）
─────────────                          ──────────────────
溯源维度：力量=环境汲取        →       Constraint(LAW):
  能量从环境流向个体                      content: "力量从地理环境汲取，非天赋"
  有限资源                                power_source_type: ENVIRONMENTAL
                                          resource_type: FINITE

机制维度：物质主导→等价交换     →       Constraint(LAW):
                                          content: "力量交互遵循守恒律"
                                          interaction_mode: CONSERVATION

载体维度：封闭拓扑→精英统治     →       Constraint(SOC):
                                          content: "力量获取门槛=高，仅精英可掌握"
                                          access_topology: CLOSED
                                          threshold: HIGH

代价维度：残酷物理→肉体损耗     →       Constraint(WST):
                                          content: "力量滥用导致肉体损耗"
                                          cost_type: PHYSICAL
                                          feedback: DEGRADATION

架构维度：浮岛群+虚空边界       →       Constraint(LAW):
                                          content: "世界=浮岛群，边界=不可逾越虚空"
                                          world_structure: FLOATING_ISLANDS
                                          boundary: VOID

法则维度：能量=地脉              →       （编译为边，不是约束）
                                          Concept(POWER_SYSTEM)
                                            –POWER_SOURCES_FROM_GEO→ Geography(地脉)

法则维度：神不存在              →       Constraint(LAW):
                                          content: "无神权干预，世界按自然法则运行"
                                          divine_intervention: NONE

法则维度：死后灵魂消散          →       Constraint(LAW):
                                          content: "死后灵魂消散，不可复生"
                                          afterlife: DISSIPATION

纪元维度：暮年+线性+崩坏        →       Concept(PHILOSOPHY):
                                          era_stage: TWILIGHT
                                          time_mode: LINEAR
                                          trajectory: COLLAPSE

骰子：钟形(3d6)                 →       Constraint(LAW):
                                          dice_distribution: BELL_CURVE
                                          dice_spec: "3d6"

骰子：固定骰                    →       Constraint(ACT):
                                          dice_mode: FIXED
                                          dice_formula: "3d6 + modifier"

骰子：Roll-under                →       Constraint(ACT):
                                          check_direction: UNDER

骰子：二元判定                  →       Constraint(NAR):
                                          success_granularity: BINARY

玩法：战斗为主                  →       Constraint(ACT):
                                          core_action: COMBAT
                                          （权重矩阵中 ACT 权重提升）
```

**Stage 1 产出**：一组完整的 Constraint 节点（第1套约束），覆盖 LAW/ACT/NAR/WST/SOC 五个维度。

> **RED（内容红线）** 在此阶段从模块9（AI生成边界）编译，不在拓扑维度中定义。

### Stage 2：第1套 × 第2套 = 6×6 权重矩阵查表

现在约束准备好了（第1套），要决定**约束施加到什么内容层级**（第2套）。

系统查 `weight_matrix.yaml`：

```
           RED    LAW    ACT    NAR    WST    SOC
WORLD  →    5%    40%    10%    15%    5%    25%
REGION →    5%    20%    10%    15%   15%    35%
SCENE  →    5%    15%    15%    30%   20%    15%
CAMPAIGN→   5%    10%    20%    35%   10%    20%
NPC    →    5%    10%    25%    20%   10%    30%
ASSET  →    5%    20%    25%    15%   15%    20%
```

**这个矩阵的意思**：

> 生成 WORLD 层内容时，LAW 约束占 40% 的 Prompt 篇幅，SOC 占 25%...
> 生成 NPC 层内容时，SOC 约束占 30%，ACT 占 25%...

**同样一组约束（第1套），施加到不同层级（第2套）时，权重不同。**

---

### Stage 3：按第2套层级组装 Prompt → 调用 LLM

对每个要生成的节点，系统执行：

```
Step A：确定节点属于哪个生成层级（第2套）
  → 这个节点是 NPC？那查 npc 行权重

Step B：按权重降序排列约束（第1套），组装 Prompt
  → NPC 层权重排序：SOC(30%) > ACT(25%) > NAR(20%) > LAW(10%) > WST(10%) > RED(5%)
  → Prompt 组装：
     [SOC 段落·30%篇幅] "这个角色属于什么势力？与谁敌对？声望如何？"
        ← 引用 Constraint(SOC): 封闭拓扑→精英掌握力量
     [ACT 段落·25%篇幅] "这个角色的技能检定用 3d6 Roll-under"
        ← 引用 Constraint(ACT): 固定骰+Roll-under
     [NAR 段落·20%篇幅] "描述风格：残酷物理世界观，基调压抑"
        ← 引用 Constraint(NAR): 二元判定+暮年崩坏基调
     [LAW 段落·10%篇幅] "力量从环境汲取，遵循守恒律"
        ← 引用 Constraint(LAW): 环境汲取+等价交换
     [WST 段落·10%篇幅] "力量滥用导致肉体损耗"
        ← 引用 Constraint(WST): 物理代价
     [RED 段落·5%篇幅]  "禁止：过度血腥描写"
        ← 引用 Constraint(RED): 内容红线

Step C：LLM 按权重组装的 Prompt 生成内容
  → 输出一个符合所有约束的 NPC 节点
```

### Stage 4：第3套（A1/A2/A3）控制权限

生成出的节点被打上权限标记：

```
生成的 NPC 节点：
  id: "char_001"
  type: CHARACTER
  detail_level: SCENE        ← 第2套：这是 NPC 层级内容
  source_stage: "A3"          ← 第3套：A3 阶段创建
  attributes:
    faction_id: "fac_001"     ← 关联到 A1 创建的 Faction 骨架
    culture_id: "cul_001"     ← 关联到 A2 创建的 Culture 填充
    dice_spec: "3d6"          ← 继承自第1套 Constraint(ACT)
    power_source: "environmental" ← 继承自第1套 Constraint(LAW)
    cost_type: "physical"     ← 继承自第1套 Constraint(WST)
```

**权限规则**（第3套）：
- `source_stage="A1"` 的节点和边 → A2/A3 **永远不可修改**
- `source_stage="A2"` 的节点 → A3 **不可修改**，但可以沿边下挂子节点
- `source_stage="A3"` 的节点 → 运行时可修改（GM/PC 交互）

## 5. 约束继承：约束如何沿拓扑边传递

> 关联: `3_knowledge-assets.md` §7

生成的节点不是孤立的——它们通过**拓扑边**（第4套定义的结构）连接。约束沿着边**继承传递**：

```
A1 骨架节点                              A3 生成节点
（约束完整）                            （约束按权重过滤继承）

Geography(虚空裂隙)                     NPC(裂隙守望者)
  Constraint(LAW): 力量=环境汲取    ──→  继承 LAW(10%权重) → 完整传递(≥10%)
  Constraint(WST): 肉体损耗         ──→  继承 WST(10%权重) → 完整传递(≥10%)
  Constraint(NAR): 暮年基调         ──→  继承 NAR(20%权重) → 完整传递(≥10%)

Geography(普通村庄)                     NPC(村民)
  Constraint(LAW): 力量=环境汲取    ──→  继承 LAW(10%权重) → 完整传递
  Constraint(WST): 肉体损耗         ──→  继承 WST(10%权重) → 完整传递
  Constraint(ACT): 3d6 Roll-under   ──→  继承 ACT(25%权重) → 完整传递
```

**继承规则**（按约束维度在目标层级的权重）：

| 权重占比 | 继承策略 | 说明 |
|---------|---------|------|
| ≥10% | **完整传递** | 约束原样传递到下游节点 |
| 5-10% | **压缩为摘要** | 约束简化为一句话 |
| <5% | **不传递** | 约束不影响下游 |
| override | **可覆盖不可删除** | 子节点可声明 override，但原约束仍记录 |

## 7. 如果去掉某一套会怎样？

| 去掉哪套 | 后果 |
|---------|------|
| **去掉第4套** | 设计师无法定义世界观结构，系统不知道"世界是什么样" → 无法编译约束 → 所有内容变成无世界观灵魂的随机生成 |
| **去掉第1套** | 第4套的选择无法转化为系统可执行的规则 → LLM 没有约束 → 生成内容可能违反世界观设定 |
| **去掉第2套** | 系统不知道按什么粒度层级生成 → 无法分配权重 → 同一条约束施加到世界级和NPC级时没有区别 → 缺少内容层级秩序 |
| **去掉第3套** | A1/A2/A3 没有权限边界 → GM/PC 可以随意修改世界核心规则 → 世界观IP不一致 → 多人协作时世界崩坏 |

## 8. 总结：4套维度的精确分工

| 维度 | 输入 | 输出 | 影响生成的方式 |
|------|------|------|-------------|
| **第4套** | 设计师的设计决策 | 拓扑选择 → 编译为约束 | **定义生成规则的内容**（规则是什么） |
| **第1套** | 第4套的编译结果 | Constraint 节点 | **约束生成的边界**（什么不能违反） |
| **第2套** | 第1套约束 + 权重矩阵 | Prompt 模板 → LLM 调用 | **控制生成的粒度和权重**（按什么比例组装规则） |
| **第3套** | 第2套的生成结果 | source_stage 标记 | **控制生成的权限**（谁能建谁能改） |

**一句话**：

> **第4套定义规则是什么 → 第1套把规则编译为约束 → 第2套确定约束施加到什么层级并按权重组装 → 第3套控制谁有权创建和修改。四者串联，从设计师的世界观意图，最终变成受控的、自洽的、有层级的内容生成。**
