# Echo UGC「世界观工坊」前端现状基线审计（as-is 基点）

> **文档用途**：本文是当前前端的现状快照（as-is），作为设计方向咨询的事实基点。全部结论均带代码出处（file:line），无主观评价。
> **审计日期**：2026-09-16 · 审计方式：代码级静态审计（三路并行：屏幕结构 / 设计系统 / 交互反馈）

---

## 1. 产品上下文（外部 LLM 先读这段）

- **产品定义**：AI 世界观工坊——创作者带入自己的世界观（上传文档 / 选预设种子 / 一句话灵感）→ AI 引导式访谈补全设定（10 模块问卷）→ 定稿编译为知识图谱（双树 + 概念网）→ 产出 IP 展板与 AI 视觉背景。
- **目标用户（产品方已裁决）**：TRPG 厂商 + 小说作者（个人创作者优先，厂商为 B2B 意向）；独立游戏开发者延后。
- **技术栈**：Vite + React 19 + TypeScript + Tailwind CSS v4（@theme 内嵌配置，无独立 config）+ React Flow（图谱画布）。
- **架构特征**：无路由库（`window.location.pathname` if/else 手动分发，App.tsx:25-29）；无状态库（原生 fetch 封装 + useState，package.json 无 react-query/SWR）；A1 主线为单文件 1567 行三态状态机工作区（A1Workspace.tsx）。

## 3. 逐屏信息结构（区块级）

### 3.1 `/` 回声终端（Demo）
四层绝对定位叠加：场景层（可点击对象回填输入）→ 全屏红光干涉指示（z-50）→ 顶栏（标题+重置，右侧让位 320px）→ 底部 45% 高终端区（自然语言输入→打字机输出）+ 右侧 300px 全高状态面板（生命值/力量/物品栏）（App.tsx:72-102）。

### 3.2 seed_selector（选种屏）
居中单列（max-w-6xl），自上而下：① 玻璃卡标题「世界观工坊」+ 英文副标；② 加载/错误态；③ 种子卡网格（唯一响应式断点：1/2/4 列，:1004），整卡点击开始会话；④ 上传工具栏（玻璃条，主按钮「⇪ 上传世界观文档」，上传中轮播三阶段文案「格式检测中→版权比对中→解析填充中」每 1.5s 切换）；⑤ 自定义输入区（英文 placeholder「Describe your creative concept...」+「Start」按钮）。上传命中版权检测时弹出全屏模态：⚠ 版权风险检测 + 三列匹配表 + 双按钮「转换使用（AI 改编规避）/ 取消上传」（CopyrightDialog.tsx:29-96）。

### 3.3 guided_chat（访谈屏）
**双栏 h-screen**：左 flex-1 聊天区 + 右固定 400px 面板（窄屏无降级）。
- 左栏：顶栏（IP Code + 种子名 + 「← 返回种子选择」）；消息气泡流（user 靛蓝右 / assistant 深灰左——**混用 slate/indigo 原生色，与全线星空色板不同源**，GuidedChat.tsx:152,165-168）；AI 填空提案（fills）以前 3 条内联卡片 + 其余入右下角托盘（⚑ 按钮红色角标 + 底部上滑抽屉 max 60vh）呈现；提案卡含「原设定 vs 新内容」双盒对照 + 三动作「替换 / 合并保留两者 ✓ / 放弃」；提案在场时挂起下一问。
- 右栏：① 结构化文件面板（10 模块分层字段 + 行级红绿 diff 高亮）；② 「Dimension Progress」10 格进度网格（done/total + 完成态发光）；③ 创新建议卡；④ 定稿 409 未完成板块黄框；⑤ 固定 footer 主按钮「定稿并生成知识图谱」（不可用时列未过半板块名）。

### 3.4 graph_view · graph tab（知识图谱）
FullscreenShell：56px 工具栏（「← 返回访谈」/「行政树·概念网」双视图切换 / 「已定稿 vX ✓」绿徽章 /「↻ 重新定稿」/ 待确认·已确认·待问三色计数 / warning ledger 角标——warn 琥珀·info 灰底，点击弹「降级明细」popover 按来源分组〔组装/定稿/图谱化/失效边/上传〕）。画布（React Flow）：行政树=双树层级视图；概念网=**tier 七层纵向分带布局**（层间距 340×220，tier 0-6：本体根基→符号学→地理→历史→社会→组织→其他，未定落「未分组」带，A1KnowledgeGraph.tsx:137-161）。画布自带顶部搜索（命中下拉点击聚焦节点）+ 底部图例（★铁律/◆联想/◇结构拆庆）。左侧待问浮层（每条「去回答 →」跳回访谈）；右侧 340px 边审核面板（确认/拒绝 AI 推断概念边，仅概念网模式）；点击节点出详情面板（跨链接导航）。stale 状态黄条「设定已更新——点此重新定稿」。

### 3.5 graph_view · poster tab 与 `/a1/poster`
同一 poster 数据双渲染：tab 内嵌版为只读预览（无操作）；独立页多 ① 顶栏「← 返回世界观工坊（继续深化）」（经 localStorage 意图键）② 右下「Visual BG」面板——「Generate AI Image」按钮 + 5s 轮询直至完成（10 分钟超时保护）。内容均为：星野背景 + 环境星点闪烁 + 1/2/3 列玻璃浮卡网格（✦+标题+内容，交错浮动动画）+ 底部渐隐 + 背景图轮播（5s 切换、圆点指示器）。

## 4. 视觉设计系统（现状）

### 4.1 核心事实：双皮肤割裂
两套互不兼容的视觉语言并存，无切换机制，按路由硬编码分布：CRT 赛博朋克（index.css，仅首页 Demo）× Starry Parallel Universe（components/theme.css，A1 全系，经 A1Workspace.tsx:20 组件级 import 引入而非全局注入）。App.css 为 Vite 模板残留尸体（.counter/.hero）。

### 4.2 皮肤 A：Starry Parallel Universe（现行主力）设计令牌
Tailwind v4 `@theme` 定义（theme.css:40-91）：

| 令牌组 | 值 | 用途 |
|---|---|---|
| space-950/900/800/700/600 | #0a0a1a / #13132a / #1c1c3d / #2a2a5a / #3a3a7a | 深空蓝紫背景梯度（五段 starry-gradient） |
| stardust-400/300/200 | #fbbf24 / #fcd34d / #fde68a | 星光金主强调 |
| nebula-500/400/300 | #8b5cf6 / #a78bfa / #c4b5fd | 星云紫次强调 |
| void-600/500/400 | #52525b / #737373 / #a1a1aa | 中性灰 |
| starlight-300/400/500 | 与 stardust 完全重复（#fcd34d/#fbbf24/#f59e0b） | **令牌冗余** |
| cosmos-success/warning/error/info | #34d399 / #f59e0b / #f43f5e / #22d3ee | 语义四色 |

间距刻度 --space-glass-{sm..2xl}=8/16/24/32/48px；圆角 {sm,md,lg,full}=4/8/16/9999px；阴影 4 枚（glow-soft 金 15%、glow-strong 金 30%、glow-purple 紫 20%、glass 黑 30%）；过渡 200/300ms。
**玻璃拟态**：.glass-panel = rgba(19,19,42,.3) + backdrop-filter blur(8px)（-webkit 前缀写 blur(12px)，**标准/前缀不一致**）+ 白 8% 边框；.glass-card 同构 + hover 提透明至 0.6 加金边金晕。
**动效**：twinkle（透明度呼吸 2s）、float-glow（上浮 8px 4s）两种环境动效；自定义星光滚动条。
**视觉语言一句话**：深空蓝紫底 × 星光金强调 × 星云紫辅助 × 毛玻璃面板 × 微弱星象动效。

### 4.3 皮肤 B：CRT 赛博朋克（首页 Demo）
无令牌体系，纯 hex 硬编码：黑底 #0a0a0a × 霓虹绿 #00ff41 × 辅助黄/青/红纯色；系统等宽字体栈；body::after 全页扫描线（repeating-gradient + 8s 位移）；文字三层霓虹光晕；flicker/glitch/glitch-slide/border-pulse 四动画。

### 4.4 字体真相
全局唯一 font-family = `ui-monospace, Consolas, monospace`（index.css:4，CRT 皮肤）。**无自定义 webfont、无 @font-face、无中文字体声明**——A1 星空皮肤未定义自己的字体族，中文回退浏览器默认（宋体/微软雅黑随系统），等宽栈对中文字形不生效。

### 4.5 元信息缺口
index.html：title="frontend"（**模板默认名未改**）、lang="en"（中文产品）、无 description/theme-color、无字体预加载。

## 5. 交互模式与反馈

### 5.1 异步操作三态覆盖矩阵

| 操作 | Loading | Error | Empty |
|---|---|---|---|
| 种子加载 | ✅ 纯文案 | ✅ 面板 | ❌ 无空态 |
| 发消息 | ✅ 按钮禁用+内联提示 | ✅ 面板（回滚用户消息） | — |
| 上传 | ✅ 三阶段轮播文案 | ✅ 503/422 分支中文文案 | — |
| 定稿 | ✅ 按钮文案切换 | ✅ 409 黄框列缺板块 | — |
| 图谱加载 | ✅ spinner shell | ✅ 全屏错误 / 存量图 banner+重试 | ⚠️ 一行字无引导 CTA |
| 展板 | ✅ spinner | ✅ 面板 | ❌ |
| 边确认操作 | ❌ 无独立 loading | ✅ 面板 | — |

模式总结：error 覆盖最全（统一 cosmos-error 面板）；empty 系统性缺失；loading 均为裸 spinner/禁用，**无骨架屏**。

### 5.2 微文案语言
中英混杂：按钮/导航中文为主，**系统级错误文案约 60% 为英文**（如 "Failed to send message. Please try again." A1Workspace.tsx:663、"Loading seeds..." :995、"Or start with your own idea" :1031）。console.error ~25 处是唯一错误日志通道。

### 5.3 状态管理
A1Workspace.tsx 单文件 **39 个 useState**，无 useReducer/Context/状态库；prop drilling 深；水合恢复手写（含 stale fileId 404 自愈，:397-408）。

### 5.4 输入与表单
全线 **0 处 maxLength、0 个 `<form>` 元素**（纯 onClick 提交，回车提交不可用）；聊天输入不支持 Enter 发送（仅按钮点击）；空值防护齐全（trim + disabled）。

## 6. 响应式与可访问性

- **响应式**：A1 全线仅 1 处断点（种子卡 grid，A1Workspace.tsx:1004）；访谈屏右栏写死 400px、`h-screen` 双栏、展板 tab 滚动容器均无窄屏降级——**窄屏访谈双栏必然破版**。
- **可访问性**：ARIA 覆盖全线仅 7 处（5 个 aria-pressed 筛选钮 + 1 role="alert" + 1 轮播 alt）；**键盘交互 0 处**（无 onKeyDown/tabIndex，图谱节点无键盘导航）；对比度风险点：void-400/500 深灰小字 on space 深底、nebula-400 元信息小字、stardust-300 小号标题。
- **明暗模式**：仅暗色（color-scheme: dark），无亮色方案。

## 9. as-is 一页画像

一个**功能链路完整但视觉与信息架构未成型**的创作工具：核心旅程（选种→访谈→图谱→展板）四屏全部可用且有结构化反馈，但 ① 产品无门面（首页是旧 Demo）、无导航体系（用户靠按钮逐屏推进+3 处整页刷新）、无 landing；② 视觉层双皮肤割裂 + 星空皮肤有令牌体系但存在冗余/字体缺位/组件逸出；③ 反馈层 error 强、empty 无、loading 裸；④ 交互层无键盘支持、无表单语义、窄屏破版；⑤ 工程层三巨石组件 + tsc 16 错误拦截正式构建。
